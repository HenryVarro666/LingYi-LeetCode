# 如何科学刷题 · 学习笔记

> 根据灵茶山艾府的帖子《分享｜如何科学刷题？》整理的个人笔记（要点转述，不是原文转载）。原文、配图和近千条评论答疑见 [原帖](https://leetcode.cn/discuss/post/3141566/ru-he-ke-xue-shua-ti-by-endlesscheng-q3yd/)。

## 起步之前

语法和常用库函数还不熟的话，先做力扣官方学习计划 [编程入门](https://leetcode.cn/studyplan/primers-list/)，里面两道数据库题可以跳过。有了一些简单题的积累，再进入灵神题单。

「难度分」就是题单里每道题右边的数字（来自周赛数据的题目评分）。没有数字的题一般是非周赛的老题。

### 刷题要点

- **按专题刷，不要随机刷。** 同一专题里一个套路能解一批题，效率高；同时会从多个角度反复接触同一个算法，更容易理解它的本质。
- **螺旋上升。** 先把各题单、各知识点 ≤1700 的基础题过一遍，再回头加难度。低分题通常只考一个知识点，高分题往往是几个知识点的组合。

## 方法 B · 随机训练（过了新手期再用）

专题训练的副作用：做题前就知道考什么，省掉了「判断题型」这一步。可笔试和比赛不会告诉你题型，把 DP 当成贪心做的人很多。

做法：打开 [lc-rating 难度练习](https://huxulm.github.io/lc-rating/v0/zen) → 设置里关掉算法标签 → 选一个适合自己的难度区间。

- 好处：贴近实战，顺便查漏补缺、检验学习成果。
- 代价：知识点零散，不如题单系统。
- 建议：隔一段时间随机刷一轮，作为阶段测验。

## 答疑要点（转述）

- **第一次接触一个专题怎么学？** 把专题里的第一题当例题，认真看题解里的原理讲解；其余题当配套练习。
- **没思路要想多久再看题解？** 十分钟到几小时都可以。看完觉得妙，就是学到了新技巧；觉得自己本该想到，就多想一会儿，或者换个时间段再想——离开问题一段时间后反而冒出思路，心理学上叫「孵化效应」。
- **很多题不会，焦虑怎么办？** 算法需要时间沉淀，坚持就好；现在不会的题过段时间再看会有新理解。刚开始先做 ≤1700 的，暂时看不懂的跳过。
- **怎么根据数据范围反推算法？** 按每秒大约 10⁸ 次基本运算估算（Python 再打个一折），见下表。

### 数据范围 → 复杂度速查（自整理）

| n 的上限 | 能接受的复杂度 | 常见做法 |
|---|---|---|
| ~10 | O(n!) | 全排列回溯、暴搜 |
| ~20 | O(2ⁿ)、O(n·2ⁿ) | 子集枚举、状压 DP |
| ~40 | O(2^(n/2)) | 折半枚举 |
| ~500 | O(n³) | 区间 DP、Floyd、三重循环 |
| ~5000 | O(n²) | 二维 DP、背包、双重循环 |
| ~2×10⁵ | O(n log n) | 排序、二分、堆、树状数组/线段树（最常见的范围） |
| ~10⁶ | O(n) | 滑窗、双指针、前缀和、单调栈、线性 DP |
| ~10⁹ | O(√n) | 试除法判质数、枚举因子 |
| ~10¹⁸ | O(log n) / O(1) | 二分、快速幂、数学公式 |

常数也要留意：例如哈希表比数组慢不少，卡常时优先用数组。
