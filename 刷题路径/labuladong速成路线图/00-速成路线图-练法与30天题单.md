## 怎么练：先学框架，再做配套习题

作者的核心主张：按路线图逐个知识点「读教程 → 存模板 → 做习题」，题单只用来检验和复习，不要上来就刷公司题单。目标是稳定解出中等难度的常考题（他说的「85 分」）。

**选哪条路**

- 时间紧、快要面试/笔试 → 走速成路线图；时间充裕（如在校生）→ 走完整目录。纠结时直接选速成。
- 路线图与速成目录内容完全相同，只是排成树形，更方便追踪进度和复习。全图进度计数为 157 道题。

**每个知识点怎么学**

1. 读教程：每篇带 2~5 道例题，读的时候顺手做掉。
2. 看「代码模板」：滑动窗口、二分、前缀和/差分、层序遍历三种写法、回溯三类模板等，理解后存好。
3. 做该节点习题：都是能直接套框架的题，目的是靠重复练出肌肉记忆。
4. 数据结构类节点（哈希、堆、LinkedHashMap 等）只要求懂原理，代码实现能看懂即可，不必手敲。

**节奏与心态**

- 每篇的建议用时按每天碎片化 1~2 小时估算，偏保守；整块时间会快很多。
- 不要死磕：第一遍以理解和模仿为主，先把体系搭起来，回头再看自然会通。
- 二叉树要格外重视：回溯、DFS、DP、分治都是二叉树遍历的延伸，层序遍历延伸出 BFS 和 Dijkstra。
- 初学阶段坚持同一套代码风格和模板，先不追求一题多解。

**遇到新题的思路**

先判断考的是哪类数据结构（如字符串就是数组），再把该类技巧（二分、快慢/左右指针、滑动窗口、前缀和、差分）逐个比对适用场景，选定后先写框架再往里填细节。

**题单和笔试**

- 公司题单只有两个用处：了解考题难度和范围（如明确不考 DP 就可跳过）；学完框架后独立刷几遍检验效果。
- 笔试技巧：回溯写不出最优解时，暴力穷举也能拿部分用例分。
- 计算器、并查集 UF 类、Dijkstra 模板可以提前存好，允许用 IDE 时直接复用。
- 不少公司机试用 ACM 模式，「数组」节点附了 ACM 模式代码模板。
- 配套插件：Chrome 插件在力扣题目页显示本站思路；VS Code / JetBrains 插件内置速成题单。
