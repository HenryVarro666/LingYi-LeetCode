## 题干（中文）

```text
给你一个字符串 s，找到 s 中最长的 回文 子串。

示例 1：

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

示例 2：

输入：s = "cbbd"
输出："bb"

提示：

- 1 <= s.length <= 1000

- s 仅由数字和英文字母组成
```
## Problem Statement (EN)

```text
Given a string s, return the longest palindromic substring in s.

Example 1:

Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.

Example 2:

Input: s = "cbbd"
Output: "bb"

Constraints:

- 1 <= s.length <= 1000

- s consist of only digits and English letters.
```
