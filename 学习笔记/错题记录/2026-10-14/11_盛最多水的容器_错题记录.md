# LeetCode 11 盛最多水的容器：错题记录

记录日期：2026-10-14（America/Chicago）。

来源：本次对话中粘贴的两版代码与错误分析。正确算法与本地灵茶山艾府题解核对；反例和逐轮结果经过 Python 运行核验。下面为便于阅读补齐缩进，错误版本保留原有语句问题。

> **这次最需要记住的两点**
> 1. 最右侧下标是 `len(height) - 1`。
> 2. **先更新最大面积，再根据两端高度移动较矮的一端。**是否刷新最大面积，不决定移动哪一端。

## 1. 题意与面积公式

`height` 中的每个数字代表一根柱子的高度。选择两根柱子作为容器两侧，能装多少水由较矮的一根限制。

```text
当前面积 = 较矮的高度 × 两根柱子的距离
         = min(height[left], height[right]) × (right - left)
```

例如 `height = [3, 3, 1]`：

```text
下标：  0  1  2
高度：  3  3  1
```

选择下标 `0` 和 `2`：面积是 `min(3, 1) × 2 = 2`。
选择下标 `0` 和 `1`：面积是 `min(3, 3) × 1 = 3`。
本例答案为 `3`。

## 2. 第一版代码：有哪些问题

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        ans = 0
        right = len(height)
        left = 0

        when left < right:
            area = min(height(left), height(right)) * (right - left)
            if area > ans:
                ans = area
                left += 1
            else right -= 1

        return ans
```

原说明把这些问题归纳为“4 处语法错误和 1 处算法逻辑错误”，分类不准确：**有的语句能通过语法解析，却会在执行时出错。**

| 原写法 | 错误类型 | 原因与修正 |
| --- | --- | --- |
| `when left < right:` | 语法错误 | Python 循环使用 `while`，应改为 `while left < right:`。 |
| `else right -= 1` | 语法错误 | `else` 后缺少冒号；推荐写成 `else:`，下一行缩进写 `right -= 1`。 |
| `height(left)`、`height(right)` | 运行时错误：`TypeError` | 圆括号表示调用函数；列表不可调用，取元素用 `height[left]`、`height[right]`。 |
| `right = len(height)` | 后续访问触发 `IndexError` | 这条赋值本身合法，但 `height[len(height)]` 越界。应设为 `len(height) - 1`。 |
| 用 `area > ans` 决定移动哪一端 | 算法逻辑错误 | 是否更新历史最大值，与应该舍弃哪个边界，是两个不同的判断。 |

补充两点：

- 如果实际代码也完全没有缩进，还会有缩进错误；如果只是聊天粘贴丢失格式，则不用把它算成额外错误。
- `else: right -= 1` 在 Python 中也可以合法写在同一行；常规多行缩进写法更清晰。第一版的问题是缺少冒号。

## 3. 第二版代码：仍然存在两个关键问题

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        ans = 0
        right = len(height)
        left = 0

        while left < right:
            area = min(height[left], height[right]) * (right - left)
            if area > ans:
                ans = area
                left += 1
            else:
                right -= 1

        return ans
```

### 问题一：最右侧下标越界

假设 `height = [3, 3, 1]`，长度为 `3`，合法下标只有 `0、1、2`。设 `right = 3` 后，第一轮计算面积会访问 `height[3]`，触发 `IndexError: list index out of range`。

修正为：

```python
right = len(height) - 1
```

### 问题二：指针移动依据错误

下面的判断只能回答“是否需要更新最大面积”：

```python
if area > ans:
    ans = area
```

它不能回答“左指针还是右指针应该移动”。移动指针要单独比较两端高度：

```python
if height[left] < height[right]:
    left += 1
else:
    right -= 1
```

这两个判断依次执行；第二个判断不能放到第一个判断的 `else` 中。

## 4. 最小长度反例：只修复越界，算法仍会算错

取 `height = [3, 3, 1]`，只把第二版的 `right` 修成 `len(height) - 1`，保留其余逻辑：

| 轮次 | `left` | `right` | 左右高度 | 当前面积 | `ans` 变化 | 错误代码的移动 |
| --- | ---: | ---: | --- | ---: | --- | --- |
| 1 | 0 | 2 | 3、1 | `1 × 2 = 2` | `0 → 2` | 因为刷新最大值，左指针移到 1 |
| 2 | 1 | 2 | 3、1 | `1 × 1 = 1` | 保持 2 | 没刷新最大值，右指针移到 1 |

此时 `left == right`，循环结束，错误代码返回 `2`。

但下标 `(0, 1)` 的面积是 `3`。第一轮错误地移走左指针之后，就永远不会检查这个组合。

长度为 `2` 时只有一对柱子，修复越界后会检查到它；因此，长度为 `3` 已是能展示该逻辑错误的最短长度。

## 5. 为什么可以安全移动较矮的一端

假设左边更矮或等高：`height[left] <= height[right]`。

当前面积为：

```text
height[left] × (right - left)
```

如果保留当前左柱，把右端改成任何内部下标 `k`，则：

```text
新高度 = min(height[left], height[k]) <= height[left]
新宽度 = k - left < right - left
```

所以，新面积不会超过当前面积。即使新的右柱更高，也突破不了这根左柱的高度上限。

既然当前面积已经记入 `ans`，继续保留这根左柱与内部柱子配对就无法改善答案，因此可以安全舍弃它，让 `left += 1`。右边较矮时，同理让 `right -= 1`。

> **“移动短板”的准确含义**
> 移动较矮的一端，保留了找到更优解的可能；**并不保证下一轮面积一定变大**。两端等高时，移动任意一端都可以，下面的代码选择移动右端。

## 6. 正确代码

以下依据本地灵茶山艾府的双指针实现，展开 `ans = left = 0` 便于理解，并沿用本次代码的 `list[int]` 类型标注。

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        ans = 0
        left = 0
        right = len(height) - 1

        while left < right:
            area = min(height[left], height[right]) * (right - left)
            ans = max(ans, area)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return ans
```

`ans = max(ans, area)` 与 `if area > ans: ans = area` 的更新效果相同。关键是把“更新答案”和“移动指针”分开。

### 变量与关键语句

| 变量或语句 | 含义 |
| --- | --- |
| `height` | 所有柱子的高度列表。 |
| `left` | 当前左侧柱子的下标，从 0 开始向右移动。 |
| `right` | 当前右侧柱子的下标，从最后一项开始向左移动。 |
| `area` | 当前这一对柱子的面积。 |
| `ans` | 到目前为止检查过的所有组合中的最大面积。 |
| `while left < right` | 两根柱子不同且顺序有效时，继续计算。 |
| `left += 1` | 左指针向右移动一格。 |
| `right -= 1` | 右指针向左移动一格。 |
| `return ans` | 循环全部结束后返回答案；放在 `while` 外面、函数内部。 |

### 正确算法运行同一个反例

| 轮次 | `left` | `right` | 左右高度 | 当前面积 | `ans` 变化 | 正确移动 |
| --- | ---: | ---: | --- | ---: | --- | --- |
| 1 | 0 | 2 | 3、1 | 2 | `0 → 2` | 右柱更矮，`right` 移到 1 |
| 2 | 0 | 1 | 3、3 | 3 | `2 → 3` | 两端等高，`right` 移到 0 |

循环结束，返回正确答案 `3`。

### 复杂度

- 时间复杂度：`O(n)`。每轮恰好移动一个指针，两个指针之间的距离减 1，共计算 `n - 1` 轮。
- 额外空间复杂度：`O(1)`。只使用固定数量的变量。
