## 2. lower_bound / upper_bound

👉 核心技巧（非常重要）

| 需求 | 写法 |
|------|------|
| ≥ x 第一个 | lower_bound(x) |
| > x 第一个 | lower_bound(x+1) |
| ≤ x 最后一个 | lower_bound(x+1)-1 |

📌 本质：
👉 找“边界”

# 🎯 二、二分答案（重点！）

👉 本质：
**不是找位置，而是猜答案**

---

## ⭐ 统一模型（最重要）

👉 转化：
答案空间 + check函数


---

| 需求 | 写法 | 如果不存在 |
|------|------|-----------|
| ≥ x 的第一个元素的下标 | lowerBound(nums, x) | n |
| > x 的第一个元素的下标 | lowerBound(nums, x + 1) | n |
| < x 的最后一个元素的下标 | lowerBound(nums, x) - 1 | -1 |
| ≤ x 的最后一个元素的下标 | lowerBound(nums, x + 1) - 1 | -1 |


| 需求 | 写法 |
|------|------|
| < x 的元素个数 | lowerBound(nums, x) |
| ≤ x 的元素个数 | lowerBound(nums, x + 1) |
| ≥ x 的元素个数 | n - lowerBound(nums, x) |
| > x 的元素个数 | n - lowerBound(nums, x + 1) |
