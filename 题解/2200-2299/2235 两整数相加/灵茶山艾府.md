# 梦开始的地方，附本地测试方法（Python/Java/C++/C/Go/JS/Rust）

> **[2235. 两整数相加](https://leetcode.cn/problems/add-two-integers/solutions/1430335/zhen-meng-kai-shi-de-di-fang-by-endlessc-rwxa/) · Easy**

> **题目描述**
> 给你两个整数 `num1` 和 `num2`，返回这两个整数的和。
>
> **示例 1：**
>
> ```
>
> 输入：num1 = 12, num2 = 5
> 输出：17
> 解释：num1 是 12，num2 是 5 ，它们的和是 12 + 5 = 17 ，因此返回 17 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：num1 = -10, num2 = 4
> 输出：-6
> 解释：num1 + num2 = -6 ，因此返回 -6 。
> ```
>
> **提示：**
>
> - `-100 <= num1, num2 <= 100`

> **题解**
> ## 答疑
>
> **问**：力扣是如何测试题目的？为什么没有 `main` 函数？
>
> **答**：简单来说，力扣评测机内部有 `main` 函数，里面会调用你写的 `sum` 函数（方法），传入相应的测试数据，然后判断 `sum` 的返回值是否等于正确答案。如果对于所有测试数据，返回值都等于正确答案，则判定通过。
>
> 所以，我们**只需编写核心逻辑**，保证返回结果计算正确即可。
>
> ```python
> # 请选择 Python3 提交代码，而不是 Python（即 Python2），后者已经被淘汰了
> class Solution:
>     def sum(self, num1: int, num2: int) -> int:
>         return num1 + num2
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
>
> ## 如何在本地测试代码？
>
> ```python
> class Solution:
>     def sum(self, num1: int, num2: int) -> int:
>         return num1 + num2
>
> # 力扣评测机对每个测试数据，都会重新创建一个 Solution 对象
> print(Solution().sum(12, 5))   # 示例 1
> print(Solution().sum(-10, 4))  # 示例 2
> ```
