# 简单题，简单做。附思考题，欢迎挑战！（Python/Java/C++/C/Go/JS/Rust）

> **[1550. 存在连续三个奇数的数组](https://leetcode.cn/problems/three-consecutive-odds/solutions/3662317/jian-dan-ti-jian-dan-zuo-fu-si-kao-ti-hu-iff8/) · Easy**

> **题目描述**
> 给你一个整数数组 `arr`，请你判断数组中是否存在连续三个元素都是奇数的情况：如果存在，请返回 `true` ；否则，返回 `false` 。
>
> **示例 1：**
>
> ```
> 输入：arr = [2,6,4,1]
> 输出：false
> 解释：不存在连续三个元素都是奇数的情况。
> ```
>
> **示例 2：**
>
> ```
> 输入：arr = [1,2,34,3,4,5,7,23,12]
> 输出：true
> 解释：存在连续三个元素都是奇数的情况，即 [5,7,23] 。
> ```
>
> **提示：**
>
> - `1 <= arr.length <= 1000`
>
> - `1 <= arr[i] <= 1000`

> **题解**
> 枚举 $i=2,3,\ldots,n-1$，如果 $\textit{arr}[i-2],\textit{arr}[i-1],\textit{arr}[i]$ 都是奇数，返回 $\texttt{true}$。
>
> 如果遍历结束也没有找到三连奇，返回 $\texttt{false}$。
>
> ```python
> class Solution:
>     def threeConsecutiveOdds(self, arr: List[int]) -> bool:
>         for i in range(2, len(arr)):
>             if arr[i - 2] % 2 and arr[i - 1] % 2 and arr[i] % 2:
>                 return True
>         return False
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def threeConsecutiveOdds(self, arr: List[int]) -> bool:
> >         return any(arr[i - 2] % 2 and arr[i - 1] % 2 and arr[i] % 2
> >                    for i in range(2, len(arr)))
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{arr}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
>

> 4. 额外输入一个 $\textit{queries}$ 数组，每个询问包含三个数 $[l,r,k]$，你需要（快速地）计算，要让子数组 $[l,r]$ 包含连续 $k$ 个奇数，最少要修改多少个数字。简单版本：所有询问的 $k$ 都相同。
> 5. 在第 $4$ 问的基础上，如果 $\textit{queries}$ 中还包含修改 $\textit{arr}[\textit{index}]=\textit{value}$ 的操作呢？
