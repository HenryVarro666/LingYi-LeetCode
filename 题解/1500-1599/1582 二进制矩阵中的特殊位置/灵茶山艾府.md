# 简单题，简单做，O(N^2) 时间 O(1) 空间（Python/Java/C++/Go）

> **[1582. 二进制矩阵中的特殊位置](https://leetcode.cn/problems/special-positions-in-a-binary-matrix/solutions/3913464/jian-dan-ti-jian-dan-zuo-omn-shi-jian-o1-lv87/) · Easy**

> **题目描述**
> 给定一个 `m x n` 的二进制矩阵 `mat`，返回矩阵 `mat` 中特殊位置的数量。
>
> 如果位置 `(i, j)` 满足 `mat[i][j] == 1` 并且行 `i` 与列 `j` 中的所有其他元素都是 `0`（行和列的下标从 **0** 开始计数），那么它被称为 **特殊** 位置。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/d9181c25b5acd8f3.jpg)
>
> ```
>
> 输入：mat = [[1,0,0],[0,0,1],[1,0,0]]
> 输出：1
> 解释：位置 (1, 2) 是一个特殊位置，因为 mat[1][2] == 1 且第 1 行和第 2 列的其他所有元素都是 0。
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/42dc0b4e5e5e609a.jpg)
>
> ```
>
> 输入：mat = [[1,0,0],[0,1,0],[0,0,1]]
> 输出：3
> 解释：位置 (0, 0)，(1, 1) 和 (2, 2) 都是特殊位置。
> ```
>
> **提示：**
>
> - `m == mat.length`
>
> - `n == mat[i].length`
>
> - `1 <= m, n <= 100`
>
> - `mat[i][j]` 是 `0` 或 `1`。

> **题解**
> 对于矩阵的每一行，如果这一行只有一个 $1$，那么遍历 $1$ 所在的那一列，如果也只有一个 $1$，则把答案加一。
>
> ```python
> class Solution:
>     def numSpecial(self, mat: List[List[int]]) -> int:
>         ans = 0
>         for row in mat:
>             if sum(row) != 1:
>                 continue
>             j = row.index(1)
>             # 计算 j 列的元素和，必须恰好是 1
>             if sum(row[j] for row in mat) == 1:
>                 ans += 1
>         return ans
> ```
>
>
> 优化，中途退出循环的写法：
>
> ```python
> class Solution:
>     def numSpecial(self, mat: List[List[int]]) -> int:
>         ans = 0
>         for row in mat:
>             col = -1
>             for j, x in enumerate(row):
>                 if x == 0:
>                     continue
>                 if col >= 0:  # 这一行有多个 1
>                     col = -1
>                     break  # 检查下一行
>                 col = j  # 记录 1 的列号
>             if col < 0:
>                 continue
>
>             seen1 = 0
>             for r in mat:
>                 if r[col] == 0:
>                     continue
>                 if seen1:  # 这一列有多个 1
>                     seen1 = 0
>                     break  # 检查下一行
>                 seen1 = 1  # 这一列有 1
>             ans += seen1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(m(n+m))$，其中 $m$ 和 $n$ 分别是 $\textit{grid}$ 的行数和列数。
> - 空间复杂度：$\mathcal{O}(1)$。
