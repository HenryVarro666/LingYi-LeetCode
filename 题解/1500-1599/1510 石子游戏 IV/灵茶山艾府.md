# 三种写法：记忆化搜索/查表法/刷表法（Python/Java/C++/Go）

> **[1510. 石子游戏 IV](https://leetcode.cn/problems/stone-game-iv/solutions/4004959/san-chong-xie-fa-ji-yi-hua-sou-suo-cha-b-h7b7/) · Hard · 难度分 1787**

> **题目描述**
> Alice 和 Bob 两个人轮流玩一个游戏，Alice 先手。
>
> 一开始，有 `n` 个石子堆在一起。每个人轮流操作，正在操作的玩家可以从石子堆里拿走 **任意** 非零 **平方数** 个石子。
>
> 如果石子堆里没有石子了，则无法操作的玩家输掉游戏。
>
> 给你正整数 `n` ，且已知两个人都采取最优策略。如果 Alice 会赢得比赛，那么返回 `True` ，否则返回 `False` 。
>
> **示例 1：**
>
> ```
>
> 输入：n = 1
> 输出：true
> 解释：Alice 拿走 1 个石子并赢得胜利，因为 Bob 无法进行任何操作。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：n = 2
> 输出：false
> 解释：Alice 只能拿走 1 个石子，然后 Bob 拿走最后一个石子并赢得胜利（2 -> 1 -> 0）。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：n = 4
> 输出：true
> 解释：n 已经是一个平方数，Alice 可以一次全拿掉 4 个石子并赢得胜利（4 -> 0）。
> ```
>
> **示例 4：**
>
> ```
>
> 输入：n = 7
> 输出：false
> 解释：当 Bob 采取最优策略时，Alice 无法赢得比赛。
> 如果 Alice 一开始拿走 4 个石子， Bob 会拿走 1 个石子，然后 Alice 只能拿走 1 个石子，Bob 拿走最后一个石子并赢得胜利（7 -> 3 -> 2 -> 1 -> 0）。
> 如果 Alice 一开始拿走 1 个石子， Bob 会拿走 4 个石子，然后 Alice 只能拿走 1 个石子，Bob 拿走最后一个石子并赢得胜利（7 -> 6 -> 2 -> 1 -> 0）。
> ```
>
> **示例 5：**
>
> ```
>
> 输入：n = 17
> 输出：false
> 解释：如果 Bob 采取最优策略，Alice 无法赢得胜利。
> ```
>
> **提示：**
>
> - `1 <= n <= 10^5`

> **题解**
> ## 一、寻找子问题
>
> 在示例 4 中，我们要解决的问题（原问题）是：
>
> - 有 $n=7$ 个石子，先手（Alice）能否必胜？
>
> 枚举先手拿了多少个石子（个数必须是 $[1,n]$ 内的平方数）：
>
> - 拿 $1$ 个石子，问题变成：有 $n'=7-1=6$ 个石子，先手（此时 Bob 为先手）能否必胜？
> - 拿 $4$ 个石子，问题变成：有 $n'=7-4=3$ 个石子，先手（此时 Bob 为先手）能否必胜？
>
> 这些问题都是**和原问题相似的、规模更小的子问题**，可以用**递归**解决。
>
> ## 二、状态定义与状态转移方程
>
> 根据上面的讨论，定义 $\textit{dfs}(i)$ 表示在有 $i$ 个石子的情况下，先手能否必胜。
>
> 枚举先手拿了 $x^2$ 个石子，其中 $1\le x^2\le i$，问题变成在有 $i-x^2$ 个石子的情况下，先手能否必胜，即 $\textit{dfs}(i-x^2)$。
>
> 只要有一个 $\textit{dfs}(i-x^2)$ 是 $\texttt{false}$（对手一定输），那么先手必胜，$\textit{dfs}(i)$ 是 $\texttt{true}$，即
>
> $$
> \textit{dfs}(i) = \bigvee_{1\le x^2\le i} \neg \textit{dfs}(i-x^2)
> $$
>
> **递归边界**：$\textit{dfs}(0)=\texttt{false}$。没有石子，先手无法操作，先手必败。
>
> **递归入口**：$\textit{dfs}(n)$，这是原问题，也是答案。
>
> ## 三、递归搜索 + 保存递归返回值 = 记忆化搜索
>
> 考虑到整个递归过程中有大量重复递归调用（递归入参相同）。由于递归函数没有副作用，同样的入参无论计算多少次，算出来的结果都是一样的，因此可以用**记忆化搜索**来优化：
>
> - 如果一个状态（递归入参）是第一次遇到，那么可以在返回前，把状态及其结果记到一个 $\textit{memo}$ 数组中。
> - 如果一个状态不是第一次遇到（$\textit{memo}$ 中保存的结果不等于 $\textit{memo}$ 的初始值），那么可以直接返回 $\textit{memo}$ 中保存的结果。
>
> ⚠**注意**：$\textit{memo}$ 数组的**初始值**一定不能等于要记忆化的值！例如初始值设置为 $0$，并且要记忆化的 $\textit{dfs}(i)$ 也等于 $0$（$\texttt{false}$），那就没法判断 $0$ 到底表示第一次遇到这个状态，还是表示之前遇到过了，从而导致记忆化失效。一般把初始值设置为 $-1$。
>
> > Python 用户可以无视上面这段，直接用 `@cache` 装饰器。
>
> 关于记忆化搜索的原理，请看视频讲解 [动态规划入门：从记忆化搜索到递推【基础算法精讲 17】](https://www.bilibili.com/video/BV1Xj411K7oF/)，其中包含把记忆化搜索 1:1 翻译成递推的技巧。
>
> ```python
> # 把 dfs 写在外面，记忆化的保存的值可以用于后续测试数据
> @cache  # 缓存装饰器，避免重复计算 dfs（一行代码实现记忆化）
> def dfs(i: int) -> int:
>     if i == 0:
>         return False
>     return any(not dfs(i - x * x) for x in range(1, isqrt(i) + 1))
>
> class Solution:
>     def winnerSquareGame(self, n: int) -> bool:
>         return dfs(n)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\sqrt n)$。由于每个状态只会计算一次，记忆化搜索的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题状态个数为 $\mathcal{O}(n)$，单个状态的计算时间为 $\mathcal{O}(\sqrt n)$，所以总的时间复杂度为 $\mathcal{O}(n\sqrt n)$。
> - 空间复杂度：$\mathcal{O}(n)$。保存多少状态，就需要多少空间。
>
> ## 四、1:1 翻译成递推
>
> 我们可以去掉递归中的「递」，只保留「归」的部分，即自底向上计算。
>
> 具体来说，$f[i]$ 的定义和 $\textit{dfs}(i)$ 的定义是完全一样的，都表示在有 $i$ 个石子的情况下，先手能否必胜。
>
> 相应的递推式（状态转移方程）也和 $\textit{dfs}$ 完全一样：
>
> $$
> f[i] = \bigvee_{1\le x^2\le i} \neg f[i-x^2]
> $$
>
> 初始值 $f[0]=\texttt{false}$，翻译自递归边界 $\textit{dfs}(0)=\texttt{false}$。
>
> 答案为 $f[n]$，翻译自递归入口 $\textit{dfs}(n)$。
>
> ```python
> class Solution:
>     def winnerSquareGame(self, n: int) -> bool:
>         # 也可以把 f 写在 class 外面，见【Python3 写法二】
>         f = [False] * (n + 1)
>         for i in range(1, n + 1):
>             f[i] = any(not f[i - x * x] for x in range(1, isqrt(i) + 1))
>         return f[n]
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > f = [False] * 100_001
> > for i in range(1, len(f)):
> >     f[i] = any(not f[i - x * x] for x in range(1, isqrt(i) + 1))
> >
> > class Solution:
> >     def winnerSquareGame(self, n: int) -> bool:
> >         return f[n]
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\sqrt n)$。
> - 空间复杂度：$\mathcal{O}(n)$。
>
> ## 五、刷表法（用当前状态更新其它状态）
>
> 由状态转移方程可知，如果有 $i$ 个石子时先手必败，那么有 $i+x^2$ 个石子时，先手拿出 $x^2$ 个石子，剩下 $i$ 个石子，对手必败，先手必胜。
>
> 据此，如果 $f[i] = \texttt{false}$，那么枚举 $x^2$，更新 $f[i+x^2]$ 为 $\texttt{true}$，其中 $i+x^2\le n$。
>
> 对于 $f[i] = \texttt{true}$ 的状态，由于不影响后续状态，直接 $\texttt{continue}$。
>
> 初始值：所有 $f[i]$ 均为 $\texttt{false}$。
>
> ```python
> class Solution:
>     def winnerSquareGame(self, n: int) -> bool:
>         f = [False] * (n + 1)
>         for i in range(n):
>             if f[i]:
>                 continue
>             for x in range(1, isqrt(n - i) + 1):
>                 f[i + x * x] = True
>         return f[n]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\sqrt n)$。在 $[0,10^5]$ 中只有 $2781$ 个 $f[i] = \texttt{false}$（必败态），占比仅 $2.8\%$，所以刷表法比前一种写法（查表法）快很多。
> - 空间复杂度：$\mathcal{O}(n)$。
