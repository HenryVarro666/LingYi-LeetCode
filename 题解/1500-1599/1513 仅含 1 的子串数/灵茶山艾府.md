# 枚举子串右端点，简洁写法（Python/Java/C++/C/Go/JS/Rust）

> **[1513. 仅含 1 的子串数](https://leetcode.cn/problems/number-of-substrings-with-only-1s/solutions/3820453/mei-ju-zi-chuan-you-duan-dian-jian-ji-xi-f5ry/) · Medium · 难度分 1351**

> **所属题单**
> - [滑动窗口与双指针 · 六、分组循环](../../../刷题路径/灵神原版题单/滑动窗口与双指针/六、分组循环.md)

> **题目描述**
> 给你一个二进制字符串 `s`（仅由 '0' 和 '1' 组成的字符串）。
>
> 返回所有字符都为 1 的子字符串的数目。
>
> 由于答案可能很大，请你将它对 10^9 + 7 取模后返回。
>
> **示例 1：**
>
> ```
> 输入：s = "0110111"
> 输出：9
> 解释：共有 9 个子字符串仅由 '1' 组成
> "1" -> 5 次
> "11" -> 3 次
> "111" -> 1 次
> ```
>
> **示例 2：**
>
> ```
> 输入：s = "101"
> 输出：2
> 解释：子字符串 "1" 在 s 中共出现 2 次
> ```
>
> **示例 3：**
>
> ```
> 输入：s = "111111"
> 输出：21
> 解释：每个子字符串都仅由 '1' 组成
> ```
>
> **示例 4：**
>
> ```
> 输入：s = "000"
> 输出：0
> ```
>
> **提示：**
>
> - `s[i] == '0'` 或 `s[i] == '1'`
>
> - `1 <= s.length <= 10^5`

> **题解**
> 遍历 $s$ 的过程中，记录上一个 $0$ 的位置 $\textit{last}_0$。
>
> 如果 $s[i]=1$，那么对于右端点为 $i$ 的全 $1$ 子串，左端点可以是 
>
> $$
> \textit{last}_0+1,\textit{last}_0+2,\ldots,i-1,i
> $$
>
> 一共有 $i - \textit{last}_0$ 个，加到答案中。
>
> 比如 $\textit{last}_0=2$，现在 $s[5]=1$，那么子串 $[3,5],[4,5],[5,5]$ 都只包含 $1$，有 $5-2=3$ 个以 $5$ 为右端点的全 $1$ 子串。
>
> 可能一开始没有 $0$，为了让公式兼容这种情况，初始化 $\textit{last}_0=-1$。
>
> 注意答案不超过 $64$ 位整数的最大值，可以在最后返回时再取模。
>
> ```python
> class Solution:
>     def numSub(self, s: str) -> int:
>         MOD = 1_000_000_007
>         ans = 0
>         last0 = -1
>         for i, ch in enumerate(s):
>             if ch == '0':
>                 last0 = i  # 记录上个 0 的位置
>             else:
>                 ans += i - last0  # 右端点为 i 的全 1 子串个数
>         return ans % MOD
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
