# 两种方法：二维前缀异或和/列前缀异或和（Python/Java/C++/Go/JS/Rust）

> **[1738. 找出第 K 大的异或坐标值](https://leetcode.cn/problems/find-kth-largest-xor-coordinate-value/solutions/2790359/liang-chong-fang-fa-er-wei-qian-zhui-yi-689bf/) · Medium · 难度分 1671**

> **所属题单**
> - [常用数据结构 · 一、前缀和](../../../刷题路径/灵神原版题单/常用数据结构/一、前缀和.md) · §1.6 二维前缀和

> **题目描述**
> 给你一个二维矩阵 `matrix` 和一个整数 `k` ，矩阵大小为 `m x n` 由非负整数组成。
>
> 矩阵中坐标 `(a, b)` 的 **目标值** 可以通过对所有元素 `matrix[i][j]` 执行异或运算得到，其中 `i` 和 `j` 满足 `0 <= i <= a < m` 且 `0 <= j <= b < n`（**下标从 0 开始计数**）。
>
> 请你找出 `matrix` 的所有坐标中第 `k` 大的目标值（**`k` 的值从 1 开始计数**）。
>
> **示例 1：**
>
> ```
>
> 输入：matrix = [[5,2],[1,6]], k = 1
> 输出：7
> 解释：坐标 (0,1) 的目标值是 5 XOR 2 = 7 ，为最大的目标值。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：matrix = [[5,2],[1,6]], k = 2
> 输出：5
> 解释：坐标 (0,0) 的目标值是 5 = 5 ，为第 2 大的目标值。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：matrix = [[5,2],[1,6]], k = 3
> 输出：4
> 解释：坐标 (1,0) 的目标值是 5 XOR 1 = 4 ，为第 3 大的目标值。
> ```
>
> **示例 4：**
>
> ```
>
> 输入：matrix = [[5,2],[1,6]], k = 4
> 输出：0
> 解释：坐标 (1,1) 的目标值是 5 XOR 2 XOR 1 XOR 6 = 0 ，为第 4 大的目标值。
> ```
>
> **提示：**
>
> - `m == matrix.length`
>
> - `n == matrix[i].length`
>
> - `1 <= m, n <= 1000`
>
> - `0 <= matrix[i][j] <= 10⁶`
>
> - `1 <= k <= m * n`

> **题解**
> ## 方法一：二维前缀异或和
>
> 类似二维前缀和，定义 $s[i+1][j+1]$ 表示左上角在 $(0,0)$，右下角在 $(i,j)$ 的子矩阵异或和，按照[【图解】一张图秒懂二维前缀和](../../0300-0399/0304%20二维区域和检索%20-%20矩阵不可变/灵茶山艾府.md) 中的做法，有
>
> $$
> s[i+1][j+1] = s[i+1][j] \oplus s[i][j+1] \oplus s[i][j] \oplus \textit{matrix}[i][j]
> $$
>
> 由于一个数异或自己等于 $0$，$s[i+1][j] \oplus s[i][j+1]$ 会导致 $s[i][j]$ 这部分被抵消掉，所以要异或进来。
>
> ```python
> class Solution:
>     def kthLargestValue(self, matrix: List[List[int]], k: int) -> int:
>         m, n = len(matrix), len(matrix[0])
>         s = [[0] * (n + 1) for _ in range(m + 1)]
>         for i, row in enumerate(matrix):
>             for j, x in enumerate(row):
>                 s[i + 1][j + 1] = s[i + 1][j] ^ s[i][j + 1] ^ s[i][j] ^ x
>         return sorted(x for row in s[1:] for x in row[1:])[-k]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(mn\log (mn))$ 或 $\mathcal{O}(mn)$，其中 $m$ 和 $n$ 分别为 $\textit{matrix}$ 的行数和列数。快速选择算法可以做到 $\mathcal{O}(mn)$。
> - 空间复杂度：$\mathcal{O}(mn)$。
>
> ## 方法二：列前缀异或和
>
> 遍历 $\textit{matrix}$ 的同时，计算 $\textit{colSum}[j]$，表示第 $j$ 列的**当前遍历过的元素**的异或和。
>
> 那么左上角在 $(0,0)$，右下角在 $(i,j)$ 的子矩阵异或和，就是
>
> $$
> \textit{colSum}[0]\oplus\textit{colSum}[1]\oplus\cdots\oplus\textit{colSum}[j]
> $$
>
> 这也可以一边遍历 $\textit{matrix}$ 一边计算。
>
> ```python
> class Solution:
>     def kthLargestValue(self, matrix: List[List[int]], k: int) -> int:
>         a = []
>         col_sum = [0] * len(matrix[0])
>         for row in matrix:
>             s = 0
>             for j, x in enumerate(row):
>                 col_sum[j] ^= x
>                 s ^= col_sum[j]
>                 a.append(s)
>         a.sort()
>         return a[-k]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(mn\log (mn))$ 或 $\mathcal{O}(mn)$，其中 $m$ 和 $n$ 分别为 $\textit{matrix}$ 的行数和列数。快速选择算法可以做到 $\mathcal{O}(mn)$。
> - 空间复杂度：$\mathcal{O}(mn)$。
