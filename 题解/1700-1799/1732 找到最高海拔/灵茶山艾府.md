# 最大前缀和（Python/Java/C++/C/Go/JS/Rust）

> **[1732. 找到最高海拔](https://leetcode.cn/problems/find-the-highest-altitude/solutions/3985481/zui-da-qian-zhui-he-pythonjavaccgojsrust-7uxe/) · Easy**

> **题目描述**
> 有一个自行车手打算进行一场公路骑行，这条路线总共由 `n + 1` 个不同海拔的点组成。自行车手从海拔为 `0` 的点 `0` 开始骑行。
>
> 给你一个长度为 `n` 的整数数组 `gain` ，其中 `gain[i]` 是点 `i` 和点 `i + 1` 的 **净海拔高度差**（`0 <= i < n`）。请你返回 **最高点的海拔** 。
>
> **示例 1：**
>
> ```
>
> 输入：gain = [-5,1,5,0,-7]
> 输出：1
> 解释：海拔高度依次为 [0,-5,-4,1,1,-6] 。最高海拔为 1 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：gain = [-4,-3,-2,-1,4,3,2]
> 输出：0
> 解释：海拔高度依次为 [0,-4,-7,-9,-10,-6,-3,-1] 。最高海拔为 0 。
> ```
>
> **提示：**
>
> - `n == gain.length`
>
> - `1 <= n <= 100`
>
> - `-100 <= gain[i] <= 100`

> **题解**
> 设 $h$ 为海拔高度数组。根据题意，我们有
>
> - $h[0] = 0$。
> - $h[1] - h[0] = \textit{gain}[0]$。
> - $h[2] - h[1] = \textit{gain}[1]$。
> - ……
> - $h[i] - h[i-1] = \textit{gain}[i-1]$。
>
> 左边累加得
>
> $$
> (h[i]-h[i-1]) + (h[i-1]-h[i-2]) + \cdots + (h[1] - h[0]) + h[0] = h[i]
> $$
>
> 右边累加得
>
> $$
> \textit{gain}[0] + \cdots + \textit{gain}[i-2] + \textit{gain}[i-1]
> $$
>
> 所以 $h$ 是 $\textit{gain}$ 的前缀和数组。
>
> > 本质上，$\textit{gain}$ 是 $h$ 的差分数组。计算差分数组的前缀和，就得到了 $h$。
>
> 最后返回 $\max(h)$。
>
> ```python
> class Solution:
>     def largestAltitude(self, gain: List[int]) -> int:
>         return max(accumulate(gain, initial=0))
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def largestAltitude(self, gain: List[int]) -> int:
> >         ans = h = 0
> >         for d in gain:
> >             h += d
> >             ans = max(ans, h)
> >         return ans
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{gain}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
