# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[1768. 交替合并字符串](https://leetcode.cn/problems/merge-strings-alternately/solutions/2794711/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-mqmy/) · Easy**

> **题目描述**
> 给你两个字符串 `word1` 和 `word2` 。请你从 `word1` 开始，通过交替添加字母来合并字符串。如果一个字符串比另一个字符串长，就将多出来的字母追加到合并后字符串的末尾。
>
> 返回 **合并后的字符串** 。
>
> **示例 1：**
>
> ```
>
> 输入：word1 = "abc", word2 = "pqr"
> 输出："apbqcr"
> 解释：字符串合并情况如下所示：
> word1：  a   b   c
> word2：    p   q   r
> 合并后：  a p b q c r
> ```
>
> **示例 2：**
>
> ```
>
> 输入：word1 = "ab", word2 = "pqrs"
> 输出："apbqrs"
> 解释：注意，word2 比 word1 长，"rs" 需要追加到合并后字符串的末尾。
> word1：  a   b
> word2：    p   q   r   s
> 合并后：  a p b q   r   s
> ```
>
> **示例 3：**
>
> ```
>
> 输入：word1 = "abcd", word2 = "pq"
> 输出："apbqcd"
> 解释：注意，word1 比 word2 长，"cd" 需要追加到合并后字符串的末尾。
> word1：  a   b   c   d
> word2：    p   q
> 合并后：  a p b q c   d
> ```
>
> **提示：**
>
> - `1 <= word1.length, word2.length <= 100`
>
> - `word1` 和 `word2` 由小写英文字母组成

> **题解**
> 从 $i=0$ 开始遍历，每次循环：
>
> - 如果 $i$ 小于 $\textit{word}_1$ 的长度，把 $\textit{word}_1[i]$ 加到答案末尾。
> - 如果 $i$ 小于 $\textit{word}_2$ 的长度，把 $\textit{word}_2[i]$ 加到答案末尾。
>
> 循环直到 $i$ 达到 $\textit{word}_1$ 的长度和 $\textit{word}_2$ 的长度的最大值。
>
> ```python
> class Solution:
>     def mergeAlternately(self, word1: str, word2: str) -> str:
>         ans = []
>         i, n, m = 0, len(word1), len(word2)
>         while i < n or i < m:
>             if i < n:
>                 ans.append(word1[i])
>             if i < m:
>                 ans.append(word2[i])
>             i += 1
>         return "".join(ans)
> ```
>
> > [!example]- Python3 库函数
> > ```python
> > class Solution:
> >     def mergeAlternately(self, word1: str, word2: str) -> str:
> >         return "".join(c for z in zip_longest(word1, word2) for c in z if c)
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n+m)$，其中 $n$ 是 $\textit{word}_1$ 的长度，$m$ 是 $\textit{word}_2$ 的长度。
> - 空间复杂度：$\mathcal{O}(n+m)$ 或 $\mathcal{O}(1)$。C++ 不计入返回值的空间。
