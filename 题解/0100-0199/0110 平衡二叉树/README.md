## 题目描述

给定一个二叉树，判断它是否是 平衡二叉树

**示例 1：**

![](../../_assets/灵茶山艾府/0d1c02dda5dae0f3.jpg)

```

输入：root = [3,9,20,null,null,15,7]
输出：true
```

**示例 2：**

![](../../_assets/灵茶山艾府/4b06aa36e5ae3608.jpg)

```

输入：root = [1,2,2,3,3,null,null,4,4]
输出：false
```

**示例 3：**

```

输入：root = []
输出：true
```

**提示：**

- 树中的节点数在范围 `[0, 5000]` 内

- `-10⁴ <= Node.val <= 10⁴`
