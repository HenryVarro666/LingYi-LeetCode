## 题目描述

给你一个数组 `points` ，其中 `points[i] = [x_i, y_i]` 表示 **X-Y** 平面上的一个点。求最多有多少个点在同一条直线上。

**示例 1：**

![](../../_assets/灵茶山艾府/d6cb113ab36febbc.jpg)

```

输入：points = [[1,1],[2,2],[3,3]]
输出：3
```

**示例 2：**

![](../../_assets/灵茶山艾府/ea823e57500ad9bd.jpg)

```

输入：points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]
输出：4
```

**提示：**

- `1 <= points.length <= 300`

- `points[i].length == 2`

- `-10⁴ <= x_i, y_i <= 10⁴`

- `points` 中的所有点 **互不相同**
