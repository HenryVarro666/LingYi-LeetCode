# 暴力枚举（Python/Java/C++/Go/JS/Rust）

> **[149. 直线上最多的点数](https://leetcode.cn/problems/max-points-on-a-line/solutions/3702301/bao-li-mei-ju-pythonjavacgojsrust-by-end-ggzu/) · Hard**

> **所属题单**
> - [面试经典 150 题 · 数学](../../../刷题路径/灵神原版题单/面试经典%20150%20题/数学.md)

> **题目描述**
> 给你一个数组 `points` ，其中 `points[i] = [x_i, y_i]` 表示 **X-Y** 平面上的一个点。求最多有多少个点在同一条直线上。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/d6cb113ab36febbc.jpg)
>
> ```
>
> 输入：points = [[1,1],[2,2],[3,3]]
> 输出：3
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/ea823e57500ad9bd.jpg)
>
> ```
>
> 输入：points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]
> 输出：4
> ```
>
> **提示：**
>
> - `1 <= points.length <= 300`
>
> - `points[i].length == 2`
>
> - `-10⁴ <= x_i, y_i <= 10⁴`
>
> - `points` 中的所有点 **互不相同**

> **题解**
> 假设直线一定经过 $\textit{points}[i]$，那么最多还能经过多少个点？
>
> 把 $\textit{points}[i] = (x,y)$ 当作坐标原点（所以直线一定经过坐标原点），其余点 $(x_2,y_2)$ 的新坐标为 $(x_2-x,y_2-y)$。
>
> 在直线一定经过坐标原点的情况下，直线斜率为新坐标与原点连线的斜率。斜率相同的点，一定在同一条直线上。
>
> 斜率为
>
> $$
> k =
> \begin{cases}
> \dfrac{y_2-y}{x_2-x}, & x_2\ne x     \\
> \infty, & x_2 = x     \\
> \end{cases}
> $$
>
> 用哈希表统计斜率的出现次数，用出现次数的最大值加一（加上 $\textit{points}[i]$ 这个点），更新答案的最大值。
>
> ## 细节
>
> 1. 本题数据范围小，用浮点数表示斜率是正确的。
> 2. 内层循环只需枚举下标在 $[i+1,n-1]$ 中的点。为什么？因为一条直线上的点一定有一个是下标最小的，外层循环枚举到这个点时，内层循环就能枚举到直线上的其余点了。
>
> ## 答疑
>
> **问**：什么情况下用浮点数是错的？
>
> **答**：取两个接近 $1$ 但不相同的分数 $\dfrac{a}{a+1}$ 和 $\dfrac{a-1}{a}$，根据 IEEE 754，在使用双精度浮点数的情况下，如果这两个数的绝对差 $\dfrac{1}{a(a+1)}$ 比 $2^{-52}$ 还小，那么计算机可能会把这两个数舍入到同一个附近的浮点数上。所以当 $a$ 达到 $2^{26}\approx 6.7\cdot 10^7$ 的时候，用浮点数就不一定对了。本题数据范围只有 $2\cdot 10^4$，可以放心地使用浮点数除法。
>
> ```python
> class Solution:
>     def maxPoints(self, points: List[List[int]]) -> int:
>         ans = 0
>         for i, (x, y) in enumerate(points):  # 假设直线一定经过 points[i]
>             cnt = defaultdict(int)
>             for x2, y2 in points[i + 1:]:
>                 dx, dy = x2 - x, y2 - y
>                 k = dy / dx if dx else inf
>                 cnt[k] += 1
>                 ans = max(ans, cnt[k])  # 这里没有算上 (x,y) 这个点，最后再加一
>         return ans + 1
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 是 $\textit{points}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
