## 题目描述

给定一个非负整数 <em>`numRows`，</em>生成「杨辉三角」的前 <em>`numRows`</em> 行。

在**「杨辉三角」**中，每个数是它左上方和右上方的数的和。

![](../../_assets/灵茶山艾府/2a532708a494ccb8.gif)

**示例 1:**

```

输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2:**

```

输入: numRows = 1
输出: [[1]]
```

**提示:**

- `1 <= numRows <= 30`
