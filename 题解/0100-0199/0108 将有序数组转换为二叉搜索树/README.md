## 题目描述

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 平衡 二叉搜索树。

**示例 1：**

![](../../_assets/灵茶山艾府/a6092bc97d6185b6.jpg)

```

输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,5,null,-3,null,9] 也将被视为正确答案：

![](../../_assets/灵茶山艾府/88a0a40add46b22a.jpg)
```

**示例 2：**

![](../../_assets/灵茶山艾府/cb3cab769d17acab.jpg)

```

输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

**提示：**

- `1 <= nums.length <= 10⁴`

- `-10⁴ <= nums[i] <= 10⁴`

- `nums` 按 **严格递增** 顺序排列
