# 【视频】没想明白？一个视频讲透！（Python/Java/C++/C/Go/JS）

> **[143. 重排链表](https://leetcode.cn/problems/reorder-list/solutions/1999276/mei-xiang-ming-bai-yi-ge-shi-pin-jiang-t-u66q/) · Medium**

> **所属题单**
> - [链表、二叉树与回溯 · 一、链表](../../../刷题路径/灵神原版题单/链表、二叉树与回溯/一、链表.md) · §1.6 快慢指针

> **题目描述**
> 给定一个单链表 `L` 的头节点 `head` ，单链表 `L` 表示为：
>
> ```
>
> L₀ → L₁ → … → L_(n - 1) → L_n
> ```
>
> 请将其重新排列后变为：
>
> ```
>
> L₀ → L_n → L₁ → L_(n - 1) → L₂ → L_(n - 2) → …
> ```
>
> 不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/4bc8e743e76ba7e0.png)
>
> ```
>
> 输入：head = [1,2,3,4]
> 输出：[1,4,2,3]
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/f44a04e64778f73a.png)
>
> ```
>
> 输入：head = [1,2,3,4,5]
> 输出：[1,5,2,4,3]
> ```
>
> **提示：**
>
> - 链表的长度范围为 `[1, 5 * 10⁴]`
>
> - `1 <= node.val <= 1000`

> ### 答疑
>
> **问**：循环条件 `while head2.next` 为什么不能写成 `while head2`？
>
> **答**：如果链表长度为偶数，例如链表由 $[1,2,3,4]$ 四个节点组成，那么找中间节点并反转后，我们得到的两个链表分别为 $\textit{head}=[1,2,3]$ 和 $\textit{head}_2 = [4,3]$。注意它俩都包含节点 $3$，具体请看视频 06:01 处的图。如果写成 `while head2`，会导致最后一轮循环中 $3$ 指向它自己。
>
> ```python
> class Solution:
>     # 876. 链表的中间结点
>     def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         slow = fast = head
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
>         return slow
>
>     # 206. 反转链表
>     def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         pre, cur = None, head
>         while cur:
>             nxt = cur.next
>             cur.next = pre
>             pre = cur
>             cur = nxt
>         return pre
>
>     def reorderList(self, head: Optional[ListNode]) -> None:
>         mid = self.middleNode(head)
>         head2 = self.reverseList(mid)
>         while head2.next:
>             nxt = head.next
>             nxt2 = head2.next
>             head.next = head2
>             head2.next = nxt
>             head = nxt
>             head2 = nxt2
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为链表的长度。
> - 空间复杂度：$\mathcal{O}(1)$，仅用到若干额外变量。
