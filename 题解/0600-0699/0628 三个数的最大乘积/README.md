## 题目描述

给你一个整型数组 `nums`。

在数组中找出由三个数组成的 **最大** 乘积，并返回这个 **最大** 乘积。

**示例 1：**

```

输入：nums = [1,2,3]
输出：6
```

**示例 2：**

```

输入：nums = [1,2,3,4]
输出：24
```

**示例 3：**

```

输入：nums = [-1,-2,-3]
输出：-6
```

**提示：**

- `3 <= nums.length <= 10⁴`

- `-1000 <= nums[i] <= 1000`
