## 题目描述

给定一个二叉树的 `root` ，返回 <em>最长的路径的长度</em> ，这个路径中的 <em>每个节点具有相同值</em> 。 这条路径可以经过也可以不经过根节点。

**两个节点之间的路径长度** 由它们之间的边数表示。

**示例 1:**

![](../../_assets/灵茶山艾府/5faf32611f96cf23.jpg)

```

输入：root = [5,4,5,1,1,5]
输出：2
```

**示例 2:**

![](../../_assets/灵茶山艾府/48496c7b326a641e.jpg)

```

输入：root = [1,4,5,4,4,5]
输出：2
```

**提示:**

- 树的节点数的范围是 `[0, 10⁴]`

- `-1000 <= Node.val <= 1000`

- 树的深度将不超过 `1000`
