# 阅读理解（Python/Java/C++/C/Go/JS/Rust）

> **[1656. 设计有序流](https://leetcode.cn/problems/design-an-ordered-stream/solutions/3087239/yue-du-li-jie-pythonjavaccgojsrust-by-en-l68a/) · Easy**

> **题目描述**
> 有 `n` 个 `(id, value)` 对，其中 `id` 是 `1` 到 `n` 之间的一个整数，`value` 是一个字符串。不存在 `id` 相同的两个 `(id, value)` 对。
>
> 设计一个流，以 **任意** 顺序获取 `n` 个 `(id, value)` 对，并在多次调用时 **按 `id` 递增的顺序** 返回一些值。
>
> 实现 `OrderedStream` 类：
>
> - `OrderedStream(int n)` 构造一个能接收 `n` 个值的流，并将当前指针 `ptr` 设为 `1` 。
>
> - `String[] insert(int id, String value)` 向流中存储新的 `(id, value)` 对。存储后：
>
>     - 如果流存储有 `id = ptr` 的 `(id, value)` 对，则找出从 `id = ptr` 开始的 **最长 id 连续递增序列** ，并 **按顺序** 返回与这些 id 关联的值的列表。然后，将 `ptr` 更新为最后那个  `id + 1` 。
>
>     -
>
> 否则，返回一个空列表。
>
> **示例：**
>
> ![](../../_assets/灵茶山艾府/f2d89bf464c0e605.gif)
>
> ```
>
> 输入
> ["OrderedStream", "insert", "insert", "insert", "insert", "insert"]
> [[5], [3, "ccccc"], [1, "aaaaa"], [2, "bbbbb"], [5, "eeeee"], [4, "ddddd"]]
> 输出
> [null, [], ["aaaaa"], ["bbbbb", "ccccc"], [], ["ddddd", "eeeee"]]
>
> 解释
> OrderedStream os= new OrderedStream(5);
> os.insert(3, "ccccc"); // 插入 (3, "ccccc")，返回 []
> os.insert(1, "aaaaa"); // 插入 (1, "aaaaa")，返回 ["aaaaa"]
> os.insert(2, "bbbbb"); // 插入 (2, "bbbbb")，返回 ["bbbbb", "ccccc"]
> os.insert(5, "eeeee"); // 插入 (5, "eeeee")，返回 []
> os.insert(4, "ddddd"); // 插入 (4, "ddddd")，返回 ["ddddd", "eeeee"]
> ```
>
> **提示：**
>
> - `1 <= n <= 1000`
>
> - `1 <= id <= n`
>
> - `value.length == 5`
>
> - `value` 仅由小写字母组成
>
> - 每次调用 `insert` 都会使用一个唯一的 `id`
>
> - 恰好调用 `n` 次 `insert`

> **题解**
> 解读示例 1。
>
> 有一个长为 $n=5$ 的字符串数组 $a$（下标从 $1$ 开始），一开始没有数据，所有 $a[i]$ 都是空。
>
> 然后往数组 $a$ 中的不同位置，依次填入 $5$ 个字符串。$\textit{idKey}$ 是填入的下标，$\textit{value}$ 是填入的字符串。
>
> `[3, "ccccc"], [1, "aaaaa"], [2, "bbbbb"], [5, "eeeee"], [4, "ddddd"]` 表示我们会依次在下标 $3,1,2,5,4$ 上填入字符串。
>
> 同时，还有一个**只会向右移动的指针** $\textit{ptr}$，初始值为 $1$。
>
> 每次填入字符串后，判断：
>
> - 如果 $a[\textit{ptr}]$ 是空，返回空列表。
> - 否则，不断向右移动 $\textit{ptr}$，直到遇到空或者数组末尾，把经过的字符串加到答案中，最后返回答案。
>
> ⚠**注意**：$\textit{ptr}$ 不会重置为 $1$，而是停在上次 $\texttt{insert}$ 调用后的位置。
>
> 代码实现时，可以用切片简化代码逻辑。
>
> ```python
> class OrderedStream:
>     def __init__(self, n: int):
>         self.a = [""] * (n + 1)
>         self.ptr = 1
>
>     def insert(self, idKey: int, value: str) -> List[str]:
>         self.a[idKey] = value
>         start = self.ptr
>         while self.ptr < len(self.a) and self.a[self.ptr]:
>             self.ptr += 1
>         return self.a[start: self.ptr]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：初始化 $\mathcal{O}(n)$，$\texttt{insert}$ 均摊 $\mathcal{O}(1)$，因为 $\texttt{insert}$ 恰好调用 $n$ 次，所以 $\textit{ptr}$ 一共移动恰好 $n$ 次，平均每次调用移动 $1$ 次。
> - 空间复杂度：初始化 $\mathcal{O}(n)$，$\texttt{insert}$ 是 $\mathcal{O}(n)$ 或者 $\mathcal{O}(1)$，取决于语言。
