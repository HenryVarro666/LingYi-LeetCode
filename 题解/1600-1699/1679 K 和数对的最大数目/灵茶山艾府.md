# O(n) 一次遍历（Python/Java/C++/Go/JS/Rust）

> **[1679. K 和数对的最大数目](https://leetcode.cn/problems/max-number-of-k-sum-pairs/solutions/2701378/on-yi-ci-bian-li-pythonjavacgojsrust-by-r7obc/) · Medium · 难度分 1346**

> **所属题单**
> - [常用数据结构 · 零、常用枚举技巧](../../../刷题路径/灵神原版题单/常用数据结构/零、常用枚举技巧.md) · §0.1 枚举右，维护左 · §0.1.1 基础

> **题目描述**
> 给你一个整数数组 `nums` 和一个整数 `k` 。
>
> 每一步操作中，你需要从数组中选出和为 `k` 的两个整数，并将它们移出数组。
>
> 返回你可以对数组执行的最大操作数。
>
> **示例 1：**
>
> ```
>
> 输入：nums = [1,2,3,4], k = 5
> 输出：2
> 解释：开始时 nums = [1,2,3,4]：
> - 移出 1 和 4 ，之后 nums = [2,3]
> - 移出 2 和 3 ，之后 nums = []
> 不再有和为 5 的数对，因此最多执行 2 次操作。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums = [3,1,3,4,3], k = 6
> 输出：1
> 解释：开始时 nums = [3,1,3,4,3]：
> - 移出前两个 3 ，之后nums = [1,4,3]
> 不再有和为 6 的数对，因此最多执行 1 次操作。
> ```
>
> **提示：**
>
> - `1 <= nums.length <= 10⁵`
>
> - `1 <= nums[i] <= 10⁹`
>
> - `1 <= k <= 10⁹`

> **题解**
> 例如 $\textit{nums}=[1,2,2,1],\ k=3$。
>
> 从左到右遍历数组，同时用一个哈希表统计元素及其出现次数。
>
> 1. 遍历到 $\textit{nums}[0]=1$，加入哈希表。
> 2. 遍历到 $\textit{nums}[1]=2$，查找到哈希表中有数字 $1$ 满足 $1+2=k$，那么从哈希表中去掉一个 $1$，答案加一。注意这一步没有把 $2$ 加入哈希表。
> 3. 遍历到 $\textit{nums}[2]=2$，由于哈希表中没有 $1$，把 $2$ 加入哈希表。
> 4. 遍历到 $\textit{nums}[3]=1$，查找到哈希表中有数字 $2$ 满足 $2+1=k$，那么从哈希表中去掉一个 $2$，答案加一。注意这一步没有把 $1$ 加入哈希表。
>
> 一般地，和 [1. 两数之和](https://leetcode.cn/problems/two-sum/) 一样，每次先看看哈希表中是否有 $k-\textit{nums}[i]$，有就去掉哈希表中的一个 $k-\textit{nums}[i]$，同时把答案加一，没有就把 $\textit{nums}[i]$ 加入哈希表。
>
> ```python
> class Solution:
>     def maxOperations(self, nums: List[int], k: int) -> int:
>         cnt = defaultdict(int)
>         ans = 0
>         for x in nums:
>             if cnt[k - x]:
>                 cnt[k - x] -= 1
>                 ans += 1
>             else:
>                 cnt[x] += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
