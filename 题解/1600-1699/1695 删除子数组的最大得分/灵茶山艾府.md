# 滑动窗口 + 数组 / 哈希集合（Python/Java/C++/Go/JS/Rust）

> **[1695. 删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/solutions/3720052/hua-dong-chuang-kou-bu-er-shu-zu-ha-xi-j-rsvy/) · Medium · 难度分 1529**

> **所属题单**
> - [滑动窗口与双指针 · 二、不定长滑动窗口](../../../刷题路径/灵神原版题单/滑动窗口与双指针/二、不定长滑动窗口.md) · §2.1 越短越合法/求最长/最大 · §2.1.1 基础

> **题目描述**
> 给你一个正整数数组 `nums` ，请你从中删除一个含有 **若干不同元素** 的子数组**。**删除子数组的 **得分** 就是子数组各元素之 **和** 。
>
> 返回 **只删除一个** 子数组可获得的 **最大得分** <em>。</em>
>
> 如果数组 `b` 是数组 `a` 的一个连续子序列，即如果它等于 `a[l],a[l+1],...,a[r]` ，那么它就是 `a` 的一个子数组。
>
> **示例 1：**
>
> ```
>
> 输入：nums = [4,2,4,5,6]
> 输出：17
> 解释：最优子数组是 [2,4,5,6]
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums = [5,2,1,2,5,2,1,2,5]
> 输出：8
> 解释：最优子数组是 [5,2,1] 或 [1,2,5]
> ```
>
> **提示：**
>
> - `1 <= nums.length <= 10⁵`
>
> - `1 <= nums[i] <= 10⁴`

> **题解**
> 本题和 [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) 是一样的，额外维护窗口中的元素和即可。见 [滑动窗口【基础算法精讲 03】](https://www.bilibili.com/video/BV1hd4y1r7Gq/)。
>
> 本题可以用布尔数组实现（更快），也可以用哈希集合实现（更通用，适用于 $\textit{nums}[i]\le 10^9$ 这种值域更大的场景）。
>
> **数组写法**
>
> ```python
> class Solution:
>     def maximumUniqueSubarray(self, nums: List[int]) -> int:
>         has = [False] * (max(nums) + 1)
>         ans = s = left = 0
>         for x in nums:
>             while has[x]:
>                 has[nums[left]] = False
>                 s -= nums[left]
>                 left += 1
>             has[x] = True
>             s += x
>             ans = max(ans, s)
>         return ans
> ```
>
>
> **哈希集合写法**
>
> ```python
> class Solution:
>     def maximumUniqueSubarray(self, nums: List[int]) -> int:
>         st = set()
>         ans = s = left = 0
>         for x in nums:
>             while x in st:
>                 st.remove(nums[left])
>                 s -= nums[left]
>                 left += 1
>             st.add(x)
>             s += x
>             ans = max(ans, s)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。虽然写了个二重循环，但是内层循环中对 $\textit{left}$ 加一的**总**执行次数不会超过 $n$ 次，所以总循环次数为 $\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(n)$。
