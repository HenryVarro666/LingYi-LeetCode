# 格式化一下就能看得更清楚（Python/Java/C++/C/Go/JS/Rust）

> **[1614. 括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/solutions/4035719/ge-shi-hua-yi-xia-jiu-neng-kan-de-geng-q-8h29/) · Easy · 难度分 1323**

> **所属题单**
> - [常用数据结构 · 三、栈](../../../刷题路径/灵神原版题单/常用数据结构/三、栈.md) · §3.4 合法括号字符串（RBS）

> **题目描述**
> 给定 **有效括号字符串** `s`，返回 `s` 的 **嵌套深度**。嵌套深度是嵌套括号的 **最大** 数量。
>
> **示例 1：**
>
> **输入：**s = "(1+(2*3)+((**8**)/4))+1"
>
> **输出：**3
>
> **解释：**数字 8 在嵌套的 3 层括号中。
>
> **示例 2：**
>
> **输入：**s = "(1)+((2))+(((**3**)))"
>
> **输出：**3
>
> **解释：**数字 3 在嵌套的 3 层括号中。
>
> **示例 3：**
>
> **输入：**`s = "()(())((()()))"`
>
> **输出：**`3`
>
> **提示：**
>
> - `1 <= s.length <= 100`
>
> - `s` 由数字 `0-9` 和字符 `'+'`、`'-'`、`'*'`、`'/'`、`'('`、`')'` 组成
>
> - 题目数据保证括号字符串 `s` 是 **有效的括号字符串**

> **题解**
> 把示例 1 的 `(1+(2*3)+((8)/4))+1` 中的 `()` 看成代码中的 `{}`，格式化一下就能看得更清楚：
>
> ```text
> (
>     1 +
>     (
>         2 * 3
>     )
>     +
>     (
>         (
>             8
>         )
>         / 4
>     )
> )
> + 1
> ```
>
> 由此可见，遇到左括号，嵌套深度（嵌套层数）就增加一，遇到右括号，嵌套深度就减少一。
>
> 这也等于当前字符左侧未闭合的左括号的个数。
>
> ```python
> class Solution:
>     def maxDepth(self, s: str) -> int:
>         ans = depth = 0
>         for ch in s:
>             if ch == '(':
>                 depth += 1
>                 ans = max(ans, depth)
>             elif ch == ')':
>                 depth -= 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
