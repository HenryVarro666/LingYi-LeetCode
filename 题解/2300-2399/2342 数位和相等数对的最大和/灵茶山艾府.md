# 枚举右，维护左（Python/Java/C++/Go/JS/Rust）

> **[2342. 数位和相等数对的最大和](https://leetcode.cn/problems/max-sum-of-a-pair-with-equal-sum-of-digits/solutions/2531487/mei-ju-you-wei-hu-zuo-pythonjavacgojsrus-eoys/) · Medium · 难度分 1309**

> **所属题单**
> - [常用数据结构 · 零、常用枚举技巧](../../../刷题路径/灵神原版题单/常用数据结构/零、常用枚举技巧.md) · §0.1 枚举右，维护左 · §0.1.1 基础

> **题目描述**
> 给你一个下标从 **0** 开始的数组 `nums` ，数组中的元素都是 **正** 整数。请你选出两个下标 `i` 和 `j`（`i != j`），且 `nums[i]` 的数位和 与  `nums[j]` 的数位和相等。
>
> 请你找出所有满足条件的下标 `i` 和 `j` ，找出并返回 `nums[i] + nums[j]` 可以得到的 **最大值**<em>。</em>如果不存在这样的下标对，返回 -1。
>
> **示例 1：**
>
> ```
>
> 输入：nums = [18,43,36,13,7]
> 输出：54
> 解释：满足条件的数对 (i, j) 为：
> - (0, 2) ，两个数字的数位和都是 9 ，相加得到 18 + 36 = 54 。
> - (1, 4) ，两个数字的数位和都是 7 ，相加得到 43 + 7 = 50 。
> 所以可以获得的最大和是 54 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums = [10,12,19,14]
> 输出：-1
> 解释：不存在满足条件的数对，返回 -1 。
> ```
>
> **提示：**
>
> - `1 <= nums.length <= 10⁵`
>
> - `1 <= nums[i] <= 10⁹`

> **题解**
> 回想一下力扣第一题的 [哈希表做法](../../0000-0099/0001%20两数之和/灵茶山艾府.md)。
>
> 不妨设 $i<j$。枚举 $\textit{nums}[j]$，设 $\textit{nums}[j]$ 的数位和为 $s$，我们需要知道 $j$ 左边的数位和也等于 $s$ 的**最大**的 $\textit{nums}[i]$。可以用一个哈希表（或者数组）$\textit{mx}[s]$ 记录数位和为 $s$ 对应的最大的 $\textit{nums}[i]$。
>
> 用 $\textit{mx}[s]+\textit{nums}[j]$ 更新答案的最大值。 
>
> 如果不存在两个数位和相同的数，返回 $-1$。
>
> ```python
> class Solution:
>     def maximumSum(self, nums: List[int]) -> int:
>         ans = -1
>         mx = [-inf] * 82  # 至多 9 个 9 相加
>         for num in nums:  # 枚举 num = nums[j]
>             s = sum(map(int, str(num)))  # 更快的写法见【Python3 写法二】
>             ans = max(ans, mx[s] + num)  # 左边找一个数位和也为 s 的最大的 nums[i]
>             mx[s] = max(mx[s], num)  # 维护数位和等于 s 的最大元素
>         return ans
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def maximumSum(self, nums: List[int]) -> int:
> >         ans = -1
> >         mx = [-inf] * 82  # 至多 9 个 9 相加
> >         for num in nums:  # 枚举 num = nums[j]
> >             s = 0
> >             x = num
> >             while x:  # 枚举 num 的每个数位
> >                 s += x % 10
> >                 x //= 10
> >             ans = max(ans, mx[s] + num)  # 左边找一个数位和也为 s 的最大的 nums[i]
> >             mx[s] = max(mx[s], num)  # 维护数位和等于 s 的最大元素
> >         return ans
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log U)$，其中 $n$ 为 $\textit{nums}$ 的长度，$U=\max(\textit{nums})$。
> - 空间复杂度：$\mathcal{O}(D\log U)$，其中 $D=9$。
