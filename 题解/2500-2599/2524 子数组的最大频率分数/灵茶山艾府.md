# 线性做法，不用快速幂（Python/Java/C++/Go）

> **[2524. 子数组的最大频率分数](https://leetcode.cn/problems/maximum-frequency-score-of-a-subarray/solutions/2088763/xian-xing-zuo-fa-bu-yong-kuai-su-mi-pyth-bqhe/) · Hard**

> **题解**
> 本题是一个长度固定为 $k$ 的滑动窗口题。
>
> 对每个 $x=\textit{nums}[i]$ 创建一个栈，每遇到一个 $x$ 就把 $x$ 与栈顶的乘积入栈，滑出窗口时同理。这样就可以 $O(1)$ 地计算分数的变化量了。
>
> ```python
> class Solution:
>     def maxFrequencyScore(self, nums: List[int], k: int) -> int:
>         MOD = 10 ** 9 + 7
>         ans = score = 0
>         st_map = {}
>         for i, x in enumerate(nums):
>             if x not in st_map:
>                 score += x
>                 st_map[x] = [x]
>             else:
>                 last = st_map[x][-1]
>                 cur = last * x % MOD
>                 score += cur - last
>                 st_map[x].append(cur)
>             if i >= k - 1:
>                 ans = max(ans, score % MOD)
>                 x = nums[i - k + 1]
>                 st = st_map[x]
>                 score -= st.pop()
>                 if st: score += st[-1]
>                 else: del st_map[x]
>         return ans
> ```
>
>
> ## 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 为 $\textit{nums}$ 的长度。
> - 空间复杂度：$O(k)$。
