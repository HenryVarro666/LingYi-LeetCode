# 分类讨论（Python/Java/C++/Go/JS/Rust）

> **[2525. 根据规则将箱子分类](https://leetcode.cn/problems/categorize-box-according-to-criteria/solutions/2050458/fen-lei-tao-lun-by-endlesscheng-aerr/) · Easy · 难度分 1301**

> **所属题单**
> - [贪心算法 · 五、思维题](../../../刷题路径/灵神原版题单/贪心算法/五、思维题.md) · §5.8 分类讨论

> **题目描述**
> 给你四个整数 `length` ，`width` ，`height` 和 `mass` ，分别表示一个箱子的三个维度和质量，请你返回一个表示箱子 **类别** 的字符串。
>
> - 如果满足以下条件，那么箱子是 `"Bulky"` 的：
>
>     - 箱子 **至少有一个** 维度大于等于 `10⁴` 。
>
>     - 或者箱子的 **体积** 大于等于 `10⁹` 。
>
> - 如果箱子的质量大于等于 `100` ，那么箱子是 `"Heavy"` 的。
>
> - 如果箱子同时是 `"Bulky"` 和 `"Heavy"` ，那么返回类别为 `"Both"` 。
>
> - 如果箱子既不是 `"Bulky"` ，也不是 `"Heavy"` ，那么返回类别为 `"Neither"` 。
>
> - 如果箱子是 `"Bulky"` 但不是 `"Heavy"` ，那么返回类别为 `"Bulky"` 。
>
> - 如果箱子是 `"Heavy"` 但不是 `"Bulky"` ，那么返回类别为 `"Heavy"` 。
>
> **注意**，箱子的体积等于箱子的长度、宽度和高度的乘积。
>
> **示例 1：**
>
> ```
>
> 输入：length = 1000, width = 35, height = 700, mass = 300
> 输出："Heavy"
> 解释：
> 箱子没有任何维度大于等于 10⁴ 。
> 体积为 24500000 <= 10⁹ 。所以不能归类为 "Bulky" 。
> 但是质量 >= 100 ，所以箱子是 "Heavy" 的。
> 由于箱子不是 "Bulky" 但是是 "Heavy" ，所以我们返回 "Heavy" 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：length = 200, width = 50, height = 800, mass = 50
> 输出："Neither"
> 解释：
> 箱子没有任何维度大于等于 10⁴ 。
> 体积为 8 * 10⁶ <= 10⁹ 。所以不能归类为 "Bulky" 。
> 质量小于 100 ，所以不能归类为 "Heavy" 。
> 由于不属于上述两者任何一类，所以我们返回 "Neither" 。
> ```
>
> **提示：**
>
> - `1 <= length, width, height <= 10⁵`
>
> - `1 <= mass <= 10³`

> **题解**
> 读题题，按照要求分类讨论即可。
>
> 可以用变量名来简化逻辑。
>
> ```python
> class Solution:
>     def categorizeBox(self, length: int, width: int, height: int, mass: int) -> str:
>         x = length >= 10000 or width >= 10000 or height >= 10000 or length * width * height >= 10 ** 9
>         y = mass >= 100
>         if x and y: return "Both"
>         if x: return "Bulky"
>         if y: return "Heavy"
>         return "Neither"
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$，仅用到若干变量。
