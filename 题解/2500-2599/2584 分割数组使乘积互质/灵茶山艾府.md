# 本质是跳跃游戏（Python/Java/C++/Go）

> **[2584. 分割数组使乘积互质](https://leetcode.cn/problems/split-the-array-to-make-coprime-products/solutions/2148324/ben-zhi-shi-tiao-yue-you-xi-by-endlessch-8chd/) · Hard · 难度分 2159**

> **所属题单**
> - [数学算法 · 一、数论](../../../刷题路径/灵神原版题单/数学算法/一、数论.md) · §1.3 质因数分解
> - [贪心算法 · 二、区间贪心](../../../刷题路径/灵神原版题单/贪心算法/二、区间贪心.md) · §2.5 合并区间

> **题目描述**
> 给你一个长度为 `n` 的整数数组 `nums` ，下标从 **0** 开始。
>
> 如果在下标 `i` 处 **分割** 数组，其中 `0 <= i <= n - 2` ，使前 `i + 1` 个元素的乘积和剩余元素的乘积互质，则认为该分割 **有效** 。
>
> - 例如，如果 `nums = [2, 3, 3]` ，那么在下标 `i = 0` 处的分割有效，因为 `2` 和 `9` 互质，而在下标 `i = 1` 处的分割无效，因为 `6` 和 `3` 不互质。在下标 `i = 2` 处的分割也无效，因为 `i == n - 1` 。
>
> 返回可以有效分割数组的最小下标 `i` ，如果不存在有效分割，则返回 `-1` 。
>
> 当且仅当 `gcd(val1, val2) == 1` 成立时，`val1` 和 `val2` 这两个值才是互质的，其中 `gcd(val1, val2)` 表示 `val1` 和 `val2` 的最大公约数。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/9d46e4a3a70068ad.png)
>
> ```
>
> 输入：nums = [4,7,8,15,3,5]
> 输出：2
> 解释：上表展示了每个下标 i 处的前 i + 1 个元素的乘积、剩余元素的乘积和它们的最大公约数的值。
> 唯一一个有效分割位于下标 2 。
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/ad0dfe8060c31733.png)
>
> ```
>
> 输入：nums = [4,7,15,8,3,5]
> 输出：-1
> 解释：上表展示了每个下标 i 处的前 i + 1 个元素的乘积、剩余元素的乘积和它们的最大公约数的值。
> 不存在有效分割。
> ```
>
> **提示：**
>
> - `n == nums.length`
>
> - `1 <= n <= 10⁴`
>
> - `1 <= nums[i] <= 10⁶`

> **题解**
> 对于一个质因子 $p$，设它在数组中的最左和最右的位置为 $\textit{left}$ 和 $\textit{right}$。
>
> 那么答案是不能在区间 $[\textit{left},\textit{right})$ 中的。注意区间右端点可能为答案。
>
> 因此这题本质上和 [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/) 是类似的，找从 $0$ 出发，最远遇到的区间右端点，即为答案。
>
> 附：[视频讲解](https://www.bilibili.com/video/BV1SN411c7eD/)，包含**质因子分解**的讲解。
>
> ```python
> class Solution:
>     def findValidSplit(self, nums: List[int]) -> int:
>         left = {}  # left[p] 表示质数 p 首次出现的下标
>         right = [0] * len(nums)  # right[i] 表示左端点为 i 的区间的右端点的最大值
>
>         def f(p: int, i: int) -> None:
>             if p in left:
>                 right[left[p]] = i  # 记录左端点 l 对应的右端点的最大值
>             else:
>                 left[p] = i  # 第一次遇到质数 p
>
>         for i, x in enumerate(nums):
>             d = 2
>             while d * d <= x:  # 分解质因数
>                 if x % d == 0:
>                     f(d, i)
>                     x //= d
>                     while x % d == 0:
>                         x //= d
>                 d += 1
>             if x > 1: f(x, i)
>
>         max_r = 0
>         for l, r in enumerate(right):
>             if l > max_r:  # 最远可以遇到 max_r
>                 return max_r  # 也可以写 l-1
>             max_r = max(max_r, r)
>         return -1
> ```
>
>
> ### 复杂度分析
>
> - 时间复杂度：$O(n\sqrt U)$，其中 $n$ 为 $\textit{nums}$ 的长度，$U=\max(\textit{nums})$。
> - 空间复杂度：$O\left(n + \dfrac{U}{\log U}\right)$。$U$ 范围内的质数个数有 $O\left(\dfrac{U}{\log U}\right)$ 个。
