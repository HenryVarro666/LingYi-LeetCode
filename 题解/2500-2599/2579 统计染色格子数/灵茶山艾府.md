# 找规律

> **[2579. 统计染色格子数](https://leetcode.cn/problems/count-total-number-of-colored-cells/solutions/2147721/zhao-gui-lu-by-endlesscheng-gksh/) · Medium · 难度分 1356**

> **所属题单**
> - [数学算法 · 七、杂项](../../../刷题路径/灵神原版题单/数学算法/七、杂项.md) · §7.10 其他

> **题目描述**
> 有一个无穷大的二维网格图，一开始所有格子都未染色。给你一个正整数 `n` ，表示你需要执行以下步骤 `n` 分钟：
>
> - 第一分钟，将 **任一** 格子染成蓝色。
>
> - 之后的每一分钟，将与蓝色格子相邻的 **所有** 未染色格子染成蓝色。
>
> 下图分别是 1、2、3 分钟后的网格图。
>
> ![](../../_assets/灵茶山艾府/196cfe2ec0875277.png)
>
> 请你返回 `n` 分钟之后 **被染色的格子** 数目。
>
> **示例 1：**
>
> ```
> 输入：n = 1
> 输出：1
> 解释：1 分钟后，只有 1 个蓝色的格子，所以返回 1 。
> ```
>
> **示例 2：**
>
> ```
> 输入：n = 2
> 输出：5
> 解释：2 分钟后，有 4 个在边缘的蓝色格子和 1 个在中间的蓝色格子，所以返回 5 。
> ```
>
> **提示：**
>
> - `1 <= n <= 10⁵`

> **题解**
> 设答案为 $f(n)$，那么 $f(n)$ 相当于在 $f(n-1)$ 的基础上多了 $4$ 组 $n-1$ 的格子。
>
> ![c2c93618d2a71c5c56054c276f7f89c.png](../../_assets/灵茶山艾府/efcdae82eadd525e.png)
>
> 所以 
>
> $$
> f(n) =
> \begin{cases} 
> 1,&n=1\\
> f(n-1) + 4(n-1),&n \ge 2
> \end{cases}
> $$
>
> 化简得
>
> $$
> f(n) = 1 + 4(1+2+\cdots+ n-1) = 1 + 2n(n-1)
> $$
>
> [视频讲解](https://www.bilibili.com/video/BV1dY4y1C77x/)
>
> ```python
> class Solution:
>     def coloredCells(self, n: int) -> int:
>         return 1 + 2 * n * (n - 1)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
