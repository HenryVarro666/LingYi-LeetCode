# 利用位运算优化（Python/Java/C++/C/Go/JS/Rust）

> **[263. 丑数](https://leetcode.cn/problems/ugly-number/solutions/3007807/li-yong-wei-yun-suan-you-hua-pythonjavac-nlqr/) · Easy**

> **题目描述**
> **丑数** 就是只包含质因数 `2`、`3` 和 `5` 的 <em>正</em> 整数。
>
> 给你一个整数 `n` ，请你判断 `n` 是否为 **丑数** 。如果是，返回 `true` ；否则，返回 `false` 。
>
> **示例 1：**
>
> ```
>
> 输入：n = 6
> 输出：true
> 解释：6 = 2 × 3
> ```
>
> **示例 2：**
>
> ```
>
> 输入：n = 1
> 输出：true
> 解释：1 没有质因数。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：n = 14
> 输出：false
> 解释：14 不是丑数，因为它包含了另外一个质因数 7 。
> ```
>
> **提示：**
>
> - `-2³¹ <= n <= 2³¹ - 1`

> **题解**
> 1. 首先，如果 $n\le 0$，不符合题目**正整数**的要求，返回 $\texttt{false}$。
> 2. 去掉 $n$ 中的因子 $3$，也就是不断把 $n$ 除以 $3$，直到 $n$ 不是 $3$ 的倍数为止。
> 3. 去掉 $n$ 中的因子 $5$，也就是不断把 $n$ 除以 $5$，直到 $n$ 不是 $5$ 的倍数为止。
> 4. 最后，$n$ 必须只剩下因子 $2$，即 $n=2^k$。用 [231. 2 的幂](https://leetcode.cn/problems/power-of-two/) 中的技巧判断，见 [我的题解](../0231%202%20的幂/灵茶山艾府.md)。
>
> ```python
> class Solution:
>     def isUgly(self, n: int) -> bool:
>         if n <= 0:
>             return False
>         while n % 3 == 0:
>             n //= 3
>         while n % 5 == 0:
>             n //= 5
>         return n & (n - 1) == 0
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(\log n)$。有 $\mathcal{O}(\log n)$ 个因子 $3$ 和因子 $5$。
> - 空间复杂度：$\mathcal{O}(1)$。
