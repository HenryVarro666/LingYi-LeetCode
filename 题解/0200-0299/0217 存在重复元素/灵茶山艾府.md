# 简洁写法（Python/Java/C++/Go/JS/Rust）

> **[217. 存在重复元素](https://leetcode.cn/problems/contains-duplicate/solutions/3041934/jian-ji-xie-fa-pythonjavacgojsrust-by-en-fvw5/) · Easy**

> **题目描述**
> 给你一个整数数组 `nums` 。如果任一值在数组中出现 **至少两次** ，返回 `true` ；如果数组中每个元素互不相同，返回 `false` 。
>
> **示例 1：**
>
> **输入：**`nums = [1,2,3,1]`
>
> **输出：**`true`
>
> **解释：**
>
> 元素 1 在下标 0 和 3 出现。
>
> **示例 2：**
>
> **输入：**`nums = [1,2,3,4]`
>
> **输出：**`false`
>
> **解释：**
>
> 所有元素都不同。
>
> **示例 3：**
>
> **输入：**`nums = [1,1,1,3,3,4,3,2,4,2]`
>
> **输出：**`true`
>
> **提示：**
>
> - `1 <= nums.length <= 10⁵`
>
> - `-10⁹ <= nums[i] <= 10⁹`

> **题解**
> ## 写法一
>
> 把 $\textit{nums}$ 中的元素都丢到哈希集合中（去重）。如果哈希集合的大小小于 $n$，则说明有重复元素。
>
> ```python
> class Solution:
>     def containsDuplicate(self, nums: List[int]) -> bool:
>         return len(set(nums)) < len(nums)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
>
> ## 写法二
>
> 遍历数组，一边遍历一边把 $\textit{nums}[i]$ 加到哈希集合中。如果发现 $\textit{nums}[i]$ 已经在哈希集合中，直接返回 $\texttt{true}$。这样可以提前退出循环。
>
> ```python
> class Solution:
>     def containsDuplicate(self, nums: List[int]) -> bool:
>         st = set()
>         for x in nums:
>             if x in st:
>                 return True
>             st.add(x)
>         return False
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
