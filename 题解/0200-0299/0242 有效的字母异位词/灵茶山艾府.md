# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[242. 有效的字母异位词](https://leetcode.cn/problems/valid-anagram/solutions/2802865/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-m89c/) · Easy**

> **所属题单**
> - [面试经典 150 题 · 哈希表](../../../刷题路径/灵神原版题单/面试经典%20150%20题/哈希表.md)

> **题目描述**
> 给定两个字符串 `s` 和 `t` ，编写一个函数来判断 `t` 是否是 `s` 的 字母异位词。
>
> **示例 1:**
>
> ```
>
> 输入: s = "anagram", t = "nagaram"
> 输出: true
> ```
>
> **示例 2:**
>
> ```
>
> 输入: s = "rat", t = "car"
> 输出: false
> ```
>
> **提示:**
>
> - `1 <= s.length, t.length <= 5 * 10⁴`
>
> - `s` 和 `t` 仅包含小写字母
>
> **进阶:** 如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

> **题解**
> 用哈希表或数组统计 $s$ 中每个字母的出现次数，以及 $t$ 中每个字母的出现次数，如果两个数组相同，则返回 $\texttt{true}$，否则返回 $\texttt{false}$。
>
> 由于 $\texttt{a}$ 到 $\texttt{z}$ 的 ASCII 值是连续的，我们可以将字符减去 $\texttt{a}$，转换成 $0$ 到 $25$ 中的数字，即数组下标。
>
> ```python
> class Solution:
>     def isAnagram(self, s: str, t: str) -> bool:
>         return Counter(s) == Counter(t)
> ```
>
> > [!example]- Python3（写法 2）
> > ```python
> > class Solution:
> >     def isAnagram(self, s: str, t: str) -> bool:
> >         cnt_s = [0] * 26
> >         for c in s:
> >             cnt_s[ord(c) - ord('a')] += 1
> >         cnt_t = [0] * 26
> >         for c in t:
> >             cnt_t[ord(c) - ord('a')] += 1
> >         return cnt_s == cnt_t
> > ```
>
>
> ### 优化
>
> 可以只用一个 $\textit{cnt}$ 数组：把 $s[i]$ 的出现次数加一，把 $t[i]$ 的出现次数减一，最后判断 $\textit{cnt}$ 数组是否全为 $0$。
>
> 从数学上来说，就是 $x=y$ 等价于 $x-y=0$ 的意思。
>
> ```python
> class Solution:
>     def isAnagram(self, s: str, t: str) -> bool:
>         cnt = [0] * 26
>         for c in s:
>             cnt[ord(c) - ord('a')] += 1
>         for c in t:
>             cnt[ord(c) - ord('a')] -= 1
>         return all(c == 0 for c in cnt)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n+|\Sigma|)$，其中 $n$ 是 $\textit{nums}$ 的长度，$|\Sigma|$ 为字符集合的大小，本题字符均为小写字母，所以 $|\Sigma|=26$。
> - 空间复杂度：$\mathcal{O}(|\Sigma|)$。
>
> **注**：如果输入字符串包含 unicode 字符，把数组改成哈希表即可。
