## 题目描述

给你一个二叉树的根节点 `root`。

按 **任意顺序** ，返回所有 **从根节点到叶子节点** 的路径。

**叶子节点** 是指没有子节点的节点。

**示例 1：**

![](../../_assets/灵茶山艾府/2cca675434c7cbe1.jpg)

```

输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
```

**示例 2：**

```

输入：root = [1]
输出：["1"]
```

**提示：**

- 树中节点的数目在范围 `[1, 100]` 内

- `-100 <= Node.val <= 100`
