3495.使数组元素都变为零的最少操作次数

[3495. 使数组元素都变为零的最少操作次数 - 力扣（LeetCode）](https://leetcode.cn/problems/minimum-operations-to-make-array-elements-zero/description/)

题目给出一个二维数组queries，其中queries[index]形式为[l, r]，queries的长度可达10^5，而l和r的规模可达10^9。每个queries[index]表示了一个元素范围从l到r（包含l和r）的整数数组nums。

在每次操作中，可以选择同一个查询数组中的两个整数a和b，然后将二者分别替换为a // 4以及b // 4。

问最少需要多少次操作，才能将所有查询数组中的所有元素都变为0。

对于一个数x，通过除以4将其变为0的操作次数取决于其位于哪两个4的幂次之间，例如在1到4^1 - 1之间的元素，只需一次操作就可以变为0；在4^1到4^2 - 1之间的元素，需要两次操作就可以变为0。更一般的，处于4^k到4^(k + 1) - 1之间的元素，需要k + 1次操作才能变为0。

这样一来，可以得到一个操作数数组，为[0, 1, 1, 1, 2, 2, 2, 2, 2, 2, 2, 2, 2, 2, 2, 2, 3, 3, ...]，而原题中的一个查询[l, r]就可以转化为对于数组中l到r这一段，每次可以将其中两个大于0的元素减去1，问至少需要多少次操作才能将这一段全变为0。

对于这个问题，之前应该遇到过一个类似的，也是给出一个数组，每次可以选两个大于0的元素减1，问至少多少次操作才能使得数组变为全0，但是题号忘了。具体做法也很简单，每次都应该选择数组中最大的两个元素执行减1操作。当然，直接模拟的复杂度很高，在这里可以通过分析得到O(n)的算法。

首先，若数组中的最大值大于其他元素之和，那么答案就是这个最大值，因为即使每次都选择这个最大值和其他元素执行操作，在其他元素都变为0时，最大值依然大于0，还是需要执行若干次操作才能使得最大值变为0，因此答案就是最大值。

反之，若数组中的最大值小于等于其他元素之和，那么所需的次数则为数组元素之和除以2向上取整，理由是对于最大值，可以不断与次大值配对执行操作，直到次大值等于第三大值，接下来按照最大值-第一个次大值，最大值-第二个次大值的顺序执行操作，直到这两个次大值都等于第四大值，以此类推。由于最大值小于等于其他所有元素之和，因此在经过一些操作后，最大值必然也会变得和次大值相等。对于若干个相等的元素，只需两个一组轮流执行操作，就可以均衡得消减这些元素的大小。这样一来，就可以不断将数组中的最大值均衡地消减到次大值的水平，直到数组中所有元素都相等，当然根据奇偶性可能会出现某个元素多1或者少1的情况。也就是说，这样操作就可以达成操作次数的下限，即为数组元素之和除以2向上取整。

根据上面的结论，对于本题中的查询，也就是操作数组中l到r这一段，将r变为0所需的操作次数显然是最多的，也就是数组中的最大值，因此只需对比l到r这一段元素之和是否大于等于将r变为0所需操作次数的两倍，若满足，答案就是l到r这一段元素之和除以2向上取整，否则答案就是将r变为0所需的操作次数。

到了这里，问题就变成了如何计算操作数组中l到r这一段的元素之和。对于这类区间和问题，依然是将其转化为前缀和问题进行求解。而对于前缀和，由于其中次数出现的次数都跟4的幂次有关，因此可以一边计算4的幂次，一边计算在当前幂次下的前缀和为多少。

如果不考虑第0项，那么操作数组中的前4^1 - 1项都有1组成，前4^2 - 1项都有1和2组成，以此类推。更一般的，操作数组中的前4^k - 1项都有1到k组成，而其中的1到k - 1都处于前4^(k - 1) - 1项中，因此k出现的次数为3 \* 4^(k - 1)。这样一来，对于某个x，操作数组中的第1到第x项之和就可以通过对比x与4的幂次来进行计算。具体来说，可以让幂次p从1开始向上枚举，若x大于等于4^p，说明这些项中可以包含所有的p，而这些p的总和就是3 \* 4^(p - 1)，可以将其累积到总和中；反之，若x小于4^p，那么只需通过x - 4^(p - 1)来计算p的数量，与p相乘后累加到总和中即可。

最后附上python代码：

```python
class Solution(object):
    def minOperations(self, queries):
        """
        :type queries: List[List[int]]
        :rtype: int
        """
        
        p4 = [1]
        cost = [0]

        while p4[-1] < 10 ** 9:
            p4.append(p4[-1] * 4)
            cost.append(3 * p4[-2] * len(cost))
        
        def calc(x):
            p = 1
            res = 0
            while x >= p4[p]:
                res += cost[p]
                p += 1

            res += (x - p4[p - 1] + 1) * p
            return res

        def get_single(x):
            res = 0
            while x:
                res += 1
                x //= 4
            
            return res

        res = 0
        for left, right in queries:
            tot_cost = calc(right) - calc(left - 1)
            max_cost = get_single(right)
            if max_cost * 2 > tot_cost:
                res += max_cost
            else:
                res += (tot_cost + 1) // 2
        
        return res
```
