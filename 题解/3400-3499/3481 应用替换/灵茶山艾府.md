# 记忆化搜索

> **[3481. 应用替换](https://leetcode.cn/problems/apply-substitutions/solutions/3680990/ji-yi-hua-sou-suo-by-endlesscheng-kn4j/) · Medium**

> **所属题单**
> - [图论算法 · 二、拓扑排序](../../../刷题路径/灵神原版题单/图论算法/二、拓扑排序.md) · §2.1 拓扑排序

> **题解**
> ```python
> class Solution:
>     def applySubstitutions(self, replacements: List[List[str]], text: str) -> str:
>         replace = dict(replacements)
>         @cache
>         def dfs(s: str) -> str:
>             res = []
>             i, n = 0, len(s)
>             while i < n:
>                 if s[i] != '%':
>                     res.append(s[i])
>                     i += 1
>                 else:
>                     res.append(dfs(replace[s[i + 1]]))
>                     i += 3
>             return ''.join(res)
>         return dfs(text)
> ```
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(L2^n)$，其中 $n$ 是 $\textit{replacements}$ 的长度，$L\le 8$。由于 $\textit{value}$ 长度至多为 $8$，至多包含 $2$ 个占位符，在最坏情况下，从一个长为 $L$ 的字符串开始，倍增 $n-1$ 次，生成的字符串长度是指数级的。
> - 空间复杂度：$\mathcal{O}(L2^n)$。
