3448.统计可以被最后一个数位整除的子字符串数目

[3448. 统计可以被最后一个数位整除的子字符串数目 - 力扣（LeetCode）](https://leetcode.cn/problems/count-substrings-divisible-by-last-digit/description/)

题目给出一个只包含数字的字符串s，现在要求返回s中所有最后一位不是0的子串中，可以被子串最后一位整除的数目，这里的子串可以有前导0。

对于s中的某个子串sub，其最后一位只有0到9一共10种可能的情况，且其中某些结尾的数字存在比较好的性质，那么在这里就可以考虑一趟遍历，对于当前遍历到的s[index]，检测以s[index]的子串中有多少可以被s[index]整除。接下来对每种s[index]逐个进行分析：

1、若s[index]为0：

这种情况可以直接跳过，因为题目明确要求了最后一位不能是0。

2、若s[index]为1、2、5其中一个：

这种情况下，任意以s[index]结尾的子串都可以被s[index]整除，因此对于当前的s[index]，一共有index + 1个可用的子串，此时应该将index + 1累加到答案中。

3、若s[index]为3、6、9其中一个：

若某个整数可以被3整除，那么其数位之和也一定可以被3整除。

若某个整数可以被9整除，那么其数位之和也一定可以被9整除。

对于6而言，相当于要求子串既可以被3整除也可以被2整除，而6作为最后一位数字的情况下子串一定可以被2整除，因此实际上同样是考察子串能否被3整除。

也就是说，这三种情况都需要考虑以s[index]结尾的所有子串的数位和，而子串的数位和问题可以认为是某种区间和问题，于是可以想办法转化为前缀和问题进行求解。

使用一个大小为9的数组cnt9来储存前缀和对9取模后的余数出现的次数，其中cnt9[x]表示模9余x的前缀和数量，同时使用一个变量s9来维护当前前缀和模9的余数。对于当前的s[index]，先使用s[index]更新s9，那么cnt9[s9]中对应的所有前缀，到s[index]之间的部分形成的子串的数位之和就必然是9的倍数，因此在这里一共有cnt9[s9]个可以被9整除的子串。

另外对于s[index]为3的情况，可以使用类似的方法计算一组cnt3以及s3，也可以直接复用这个cnt9，即对于当前的s9，先计算其模3的余数x，接下来直接利用cnt9[x]、cnt9[(x + 3) % 9]、cnt[(x + 6) % 9]就行了。

4、若s[index]为4：

由于100 \= 4 \* 25，因此对于所有三位或以上的数字，只需检测最后两位能否被4整除就行了。

对于以s[index]结尾且长度为2的子串，需要检测的同样是最后两位能否被4整除。

最后，s[index]单独形成的子串就是4，显然可以被4整除。

综合起来，在这里就只需额外检测最后两位能否被4整除即可。又由于最后一位已经固定好了是4，因此在这里只需在index > 1的情况下检测倒数第二位是否为偶数，如果满足，那么所有以s[index]结尾的子串就都可以被4整除，一共有index + 1个可行的子串，否则只有s[index]本身形成的这1个子串可以被4整除。

5、若s[index]为8：

与上面类似，由于1000 \= 8 \* 125，因此对于所有四位或以上的数字，只需检测最后三位能否被8整除就行了。

对于以s[index]结尾且长度为3的子串，需要检测的同样是最后三位能否被8整除。

与上面不同，在这里还需要额外考虑以s[index]结尾且长度为2的子串，这种情况下检测的是最后两位能否被8整除。

最后，s[index]单独形成的子串就是8，显然可以被8整除。

综合起来，在这里应该先将答案加上1，表示s[index]单独形成的这1个子串可以被8整除。

接下来，在最后一位已经固定好了是8的前提下，在这里需要检测的是index > 1的情况下倒数第二位能否被4整除，以及在index > 2的情况下倒数第三位以及倒数第二位形成的两位数能否被4整除。

若前者满足，那么说明最后两位形成的这1个子串可以被8整除，应该将答案加上1；若后者满足，那么说明所有以s[index]结尾且长度大于等于3的子串都可以被8整除，应该将答案加上index - 1。

6、若s[index]为7：

7的情况最不好处理，就我所知的，某个数减去最后一位的两位如果可以被7整除，那么这个数就可以被7整除。这个性质不太好利用。

在这里不妨换个思路，不再通过找规律的方法来进行计算，来点更数学点的方法。

对于一个以s[index]结尾的子串，若其起始位置为p，那么这个子串，也就是s[p: index + 1]的数值可以认为是

s[p: index + 1] \= s[:index + 1] - s[:p] \* 10^(index - p + 1)

也就是写成一个前缀字符串，减去另一个前缀字符串乘以10的幂的形式。

若想要s[p: index + 1]可以被7整除，那么在这里就需要右边相减的两个部分模7同余，即

s[:index + 1] ≡ s[:p] \* 10^(index - p + 1) （mod 7）

记10^k模7的乘法逆元为inv[k]，那么在这里将index和p的项分别移动到两侧，就有

s[:index + 1] \* inv[index] ≡ s[:p] \* 10^ inv[p - 1] (mod 7)

可以发现，如果定义x7[index]为s[:index + 1] \* inv[index] (mod 7)，那么问题就转化为了对于当前的index，由多少个前缀满足其对应的prefix值恰好等于x7[index]。而对于这个问题则只需使用一个哈希表cnt7记录每种前缀对应的x7出现的次数就行了。

最后需要处理的是关于x7计算的问题。

其中s[:index] % 7这个部分是很好处理的，使用一个变量pre7记录当前前缀模7的余数，对于当前遍历到的s[index]，将上一轮的pre7乘以10，加上s[index]再对7取模就可以得到新的pre7。

而对于inv[index]这个部分，直接计算当然也是可以的，不过在这里可以先进行观察找找规律。

对于所有的10^k，现在希望找到inv[k]，使得10^k \* inv[k] ≡ 1 (mod 7)

那么可以先把所在10^k先对7取模，得到的是

1 \* inv[0] ≡ 1 (mod 7)

3 \* inv[1] ≡ 1 (mod 7)

2 \* inv[2] ≡ 1 (mod 7)

6 \* inv[3] ≡ 1 (mod 7)

4 \* inv[4] ≡ 1 (mod 7)

5 \* inv[5] ≡ 1 (mod 7)

...

在这里10的幂模7是按照1、3、2、6、4、5的顺序循环出现的，那么其模7对应的逆元也会循环出现。直接手动枚举凑一凑，就可以发现这些inv是按照1、5、4、6、2、3的顺序循环出现的。于是使用一个长度为6的数组inv7记录下这些逆元[1, 5, 4, 6, 2, 3]，接下来对于当前的index，其对应的x7就等于当前的pre7 \* inv[index % 6] % 7。

到了这里，所有的情况就都讨论完了。根据上面的结论，在遍历时分别维护s9和pre7这两个变量，以及cnt7和cnt9这两个计数用的哈希表，就可以在一趟遍历的时间内计算出所有符合条件的子串数目了。

最后附上python代码：

```python
class Solution(object):
    def countSubstrings(self, s):
        """
        :type s: str
        :rtype: int
        """
        
        res = 0
        cnt7 = [0] * 7
        cnt9 = [0] * 9
        cnt7[0] = 1
        cnt9[0] = 1
        s9 = 0
        pre7 = 0

        inv7 = [1, 5, 4, 6, 2, 3]

        for index, char in enumerate(s):
            v = int(char)
            s9 += v
            s9 %= 9
            pre7 = (pre7 * 10 + v) % 7
            x7 = pre7 * inv7[index % 6] % 7

            if v == 0:
                pass
            elif v == 1 or v == 2 or v == 5:
                res += index + 1
            elif v == 3 or v == 6:
                x = s9 % 3
                res += cnt9[x] + cnt9[(x + 3) % 9] + cnt9[(x + 6) % 9]
            elif v == 4:
                res += 1
                if index > 0 and int(s[index - 1]) % 2 == 0:
                    res += index
            elif v == 7:
                res += cnt7[x7]
            elif v == 8:
                res += 1
                if index > 0 and int(s[index - 1]) % 4 == 0:
                    res += 1
                if index > 1 and (int(s[index - 2]) * 10 + int(s[index - 1])) % 4 == 0:
                    res += index - 1
            elif v == 9:
                res += cnt9[s9]
            
            cnt9[s9] += 1
            cnt7[x7] += 1

        return res
```
