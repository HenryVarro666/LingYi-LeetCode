# 别想太复杂，模拟题罢了！（Python/Java/C++/Go）

> **[1419. 数青蛙](https://leetcode.cn/problems/minimum-number-of-frogs-croaking/solutions/2257845/bie-xiang-tai-fu-za-mo-ni-ti-ba-liao-pyt-9t87/) · Medium**

> **题目描述**
> 给你一个字符串 `croakOfFrogs`，它表示不同青蛙发出的蛙鸣声（字符串 `"croak"` ）的组合。由于同一时间可以有多只青蛙呱呱作响，所以 `croakOfFrogs` 中会混合多个 `“croak”` <em>。</em>
>
> 请你返回模拟字符串中所有蛙鸣所需不同青蛙的最少数目。
>
> 要想发出蛙鸣 "croak"，青蛙必须 **依序** 输出 `‘c’, ’r’, ’o’, ’a’, ’k’` 这 5 个字母。如果没有输出全部五个字母，那么它就不会发出声音。如果字符串 `croakOfFrogs` 不是由若干有效的 "croak" 字符混合而成，请返回 `-1` 。
>
> **示例 1：**
>
> ```
>
> 输入：croakOfFrogs = "croakcroak"
> 输出：1
> 解释：一只青蛙 “呱呱” 两次
> ```
>
> **示例 2：**
>
> ```
>
> 输入：croakOfFrogs = "crcoakroak"
> 输出：2
> 解释：最少需要两只青蛙，“呱呱” 声用黑体标注
> 第一只青蛙 "crcoakroak"
> 第二只青蛙 "crcoakroak"
> ```
>
> **示例 3：**
>
> ```
>
> 输入：croakOfFrogs = "croakcrook"
> 输出：-1
> 解释：给出的字符串不是 "croak" 的有效组合。
> ```
>
> **提示：**
>
> - `1 <= croakOfFrogs.length <= 10⁵`
>
> - 字符串中的字符只有 `'c'`, `'r'`, `'o'`, `'a'` 或者 `'k'`

> **题解**
> 将青蛙分成 $5$ 种：
>
> - 刚才发出了 $\texttt{c}$ 的声音。
> - 刚才发出了 $\texttt{r}$ 的声音。
> - 刚才发出了 $\texttt{o}$ 的声音。
> - 刚才发出了 $\texttt{a}$ 的声音。
> - 刚才发出了 $\texttt{k}$ 的声音。
>
> 遍历 $\textit{croakOfFrogs}$，例如当前遍历到 $\texttt{r}$，那么就看看有没有青蛙刚才发出了 $\texttt{c}$ 的声音，如果有，那么让它接着发出 $\texttt{r}$ 的声音。换句话说，我们需要消耗一个 $\texttt{c}$，产生一个 $\texttt{r}$。
>
> 这启发我们使用一个哈希表（数组）$\textit{cnt}$ 来维护这 $5$ 种青蛙的个数，并分类讨论：
>
> - 遍历到 $\texttt{c}$ 时，看看有没有青蛙刚才发出了 $\texttt{k}$ 的声音，如果有，那么**复用**这只青蛙，让它接着发出 $\texttt{c}$ 的声音，即 `cnt['k']--` 和 `cnt['c']++`；如果没有这种青蛙，那么**新产生**一只青蛙发出 $\texttt{c}$ 的声音，即 `cnt['c']++`。
> - 遍历到 $\texttt{r}$ 时，看看有没有青蛙刚才发出了 $\texttt{c}$ 的声音，如果有，那么**复用**这只青蛙，让它接着发出 $\texttt{r}$ 的声音，即 `cnt['c']--` 和 `cnt['r']++`；如果没有这种青蛙，由于题目要求青蛙必须从 $\texttt{c}$ 开始蛙鸣，不能直接从 $\texttt{r}$ 开始，所以返回 $-1$。
> - 遍历到 $\texttt{o},\text{a},\text{k}$ 的情况类似 $\texttt{r}$，找到该字母在 $\texttt{croak}$ 的上一个字母的 $\textit{cnt}$ 值，如果 $\textit{cnt}$ 值大于 $0$，那么将其减一，同时当前字母的 $\textit{cnt}$ 值加一；如果上一个字母的 $\textit{cnt}$ 值等于 $0$，那么就返回 $-1$。
>
> 遍历结束后，所有青蛙必须在最后发出 $\texttt{k}$ 的声音。如果有青蛙在最后发出的声音不是 $\texttt{k}$（也就是 $\textit{cnt}$ 值大于 $0$），那么返回 $-1$，否则返回 $\textit{cnt}[\text{k}]$。
>
> 代码实现时，可以用一个哈希表（数组）$\textit{previous}$ 记录 $\texttt{croak}$ 中的每个字母的上一个字母，从而避免写出大量 `if-else`。
>
> ```python
> # 预处理每个字母在 "croak" 中的上一个字母
> PREVIOUS = dict(pairwise("croakc"[::-1]))
>
> class Solution:
>     def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
>         cnt = defaultdict(int)
>         for ch in croakOfFrogs:
>             pre = PREVIOUS[ch]  # pre 为 ch 在 "croak" 中的上一个字母
>             if cnt[pre]:  # 如果有青蛙发出了 pre 的声音
>                 cnt[pre] -= 1  # 复用一只
>             elif ch != 'c':  # 否则青蛙必须从 'c' 开始蛙鸣
>                 return -1  # 不符合要求
>             cnt[ch] += 1  # 发出了 ch 的声音
>         if any(cnt[ch] for ch in "croa"):
>             return -1  # 有发出其它声音的青蛙，不符合要求
>         return cnt['k']  # 最后青蛙们都发出了 'k' 的声音
> ```
>
>
> ### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为 $\textit{croakOfFrogs}$ 的长度。
> - 空间复杂度：$\mathcal{O}(|\Sigma|)$，其中 $|\Sigma|$ 为字符集合的大小，若采用哈希表实现，则 $|\Sigma|=5$。
