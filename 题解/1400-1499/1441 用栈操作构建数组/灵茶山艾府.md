# 阅读理解，简洁写法（Python/Java/C++/C/Go/JS/Rust）

> **[1441. 用栈操作构建数组](https://leetcode.cn/problems/build-an-array-with-stack-operations/solutions/3830582/yue-du-li-jie-jian-ji-xie-fa-pythonjavac-nys0/) · Medium · 难度分 1180**

> **所属题单**
> - [常用数据结构 · 三、栈](../../../刷题路径/灵神原版题单/常用数据结构/三、栈.md) · §3.1 基础

> **题目描述**
> 给你一个数组 `target` 和一个整数 `n`。
>
> 给你一个空栈和两种操作：
>
> - `"Push"`：将一个整数加到栈顶。
>
> - `"Pop"`：从栈顶删除一个整数。
>
> 同时给定一个范围 `[1, n]` 中的整数流。
>
> 使用两个栈操作使栈中的数字（从底部到顶部）等于 `target`。你应该遵循以下规则：
>
> - 如果整数流不为空，从流中选取下一个整数并将其推送到栈顶。
>
> - 如果栈不为空，弹出栈顶的整数。
>
> - 如果，在任何时刻，栈中的元素（从底部到顶部）等于 `target`，则不要从流中读取新的整数，也不要对栈进行更多操作。
>
> 请返回遵循上述规则构建 `target` 所用的操作序列。如果存在多个合法答案，返回 **任一** 即可。
>
> **示例 1：**
>
> ```
>
> 输入：target = [1,3], n = 3
> 输出：["Push","Push","Pop","Push"]
> 解释：一开始栈为空。最后一个元素是栈顶。
> 从流中读取 1 并推入数组。s = [1]。
> 从流中读取 2 并推入数组。s = [1,2]。
> 从栈顶删除整数。s = [1]。
> 从流中读取 3 并推入数组。s = [1,3]。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：target = [1,2,3], n = 3
> 输出：["Push","Push","Push"]
> 解释：一开始栈为空。最后一个元素是栈顶。
> 从流中读取 1 并推入数组。s = [1]。
> 从流中读取 2 并推入数组。s = [1,2]。
> 从流中读取 3 并推入数组。s = [1,2,3]。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：target = [1,2], n = 4
> 输出：["Push","Push"]
> 解释：一开始栈为空。最后一个元素是栈顶。
> 从流中读取 1 并推入数组。s = [1]。
> 从流中读取 2 并推入数组。s = [1,2]。
> 由于栈（从底部到顶部）等于 target，我们停止栈操作。
> 从流中读取整数 3 的答案不被接受。
> ```
>
> **提示：**
>
> - `1 <= target.length <= 100`
>
> - `1 <= n <= 100`
>
> - `1 <= target[i] <= n`
>
> - `target` 严格递增

> **题解**
> 看示例 1，$n=3$ 意味着我们会依次读取 $1,2,3$ 这三个数。
>
> - $1$ 在 $\textit{target}$ 中，入栈。
> - $2$ 不在 $\textit{target}$ 中，先入栈，再出栈。注意一定要入栈，这是题目要求。
> - $3$ 在 $\textit{target}$ 中，入栈。现在栈等于 $\textit{target}$。
>
> 怎么判断当前读取的数是否在 $\textit{target}$ 中？
>
> 1. 设 $\textit{target}$ 的最后一个数为 $\textit{mx}$。初始化指针 $i=0$，指向 $\textit{target}$ 的第一个数。
> 2. 枚举读取的数为 $x = 1,2,\ldots,\textit{mx}$。
> 3. 先把 $x$ 入栈。
> 4. 如果 $x = \textit{target}[i]$，那么 $x$ 是我们要的数，把 $i$ 加一，指向 $\textit{target}$ 的下一个数。
> 5. 否则 $x < \textit{target}[i]$，那么 $x$ 不是我们要的数，把 $x$ 出栈。
>
> 由于 $\textit{target}$ 是严格递增的，所以 $x \le \textit{target}[i]$ 始终成立。
>
> ```python
> class Solution:
>     def buildArray(self, target: List[int], n: int) -> List[str]:
>         ans = []
>         i = 0
>         for x in range(1, target[-1] + 1):
>             ans.append("Push")  # 先把 x 入栈（题目要求）
>             if x == target[i]:  # x 是我们要的数
>                 i += 1
>             else:  # x 不是我们要的数，出栈
>                 ans.append("Pop")
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(\textit{mx})$，其中 $\textit{mx}$ 是 $\textit{target}$ 的最后一个数。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
