# 两种方法：模拟 / 简洁公式（Python/Java/C++/Go）

> **[1404. 将二进制表示减到 1 的步骤数](https://leetcode.cn/problems/number-of-steps-to-reduce-a-number-in-binary-representation-to-one/solutions/3903881/liang-chong-fang-fa-mo-ni-jian-ji-gong-s-dtlf/) · Medium**

> **题目描述**
> 给你一个以二进制形式表示的数字 `s` 。请你返回按下述规则将其减少到 1 所需要的步骤数：
>
> -
>
> 如果当前数字为偶数，则将其除以 `2` 。
>
> -
>
> 如果当前数字为奇数，则将其加上 `1` 。
>
> 题目保证你总是可以按上述规则将测试用例变为 1 。
>
> **示例 1：**
>
> ```
>
> 输入：s = "1101"
> 输出：6
> 解释："1101" 表示十进制数 13 。
> Step 1) 13 是奇数，加 1 得到 14
> Step 2) 14 是偶数，除 2 得到 7
> Step 3) 7  是奇数，加 1 得到 8
> Step 4) 8  是偶数，除 2 得到 4
> Step 5) 4  是偶数，除 2 得到 2
> Step 6) 2  是偶数，除 2 得到 1
> ```
>
> **示例 2：**
>
> ```
>
> 输入：s = "10"
> 输出：1
> 解释："10" 表示十进制数 2 。
> Step 1) 2 是偶数，除 2 得到 1
> ```
>
> **示例 3：**
>
> ```
>
> 输入：s = "1"
> 输出：0
> ```
>
> **提示：**
>
> - `1 <= s.length <= 500`
>
> - `s` 由字符 `'0'` 或 `'1'` 组成。
>
> - `s[0] == '1'`

> **题解**
> ## 方法一：模拟
>
> 由于除以 $2$、加上 $1$ 这些操作发生在 $s$ 的最低位，所以我们要**从右往左**遍历 $s$，模拟计算过程。
>
> 由于二进制 $1+1 = 10$，会产生进位，可以用一个变量 $\textit{carry}$ 存储进位值，初始值为 $0$。
>
> 从右往左遍历 $s$，对于 $s[i]$：
>
> - 首先计算进位后的结果 $\textit{sum} = s[i] + \textit{carry}$，把 $s[i]$ 变成 $\textit{sum}\bmod 2$。例如 $s[i]$ 和 $\textit{carry}$ 都是 $1$，那么 $1+1 = 10$，所以新的 $s[i] = 0$，新的 $\textit{carry}$ 是 $1$。
> - 如果 $s[i]$ 变成 $0$，那么执行「除以 $2$」，把 $s[i]$ 去掉。
> - 如果 $s[i]$ 变成 $1$，那么要执行「加上 $1$」和「除以 $2$」才能把 $s[i]$ 去掉。由于要执行了「加上 $1$」，$\textit{sum}$ 也增加了 $1$。这说明新的 $\textit{carry}$ 是 $\left\lfloor\dfrac{\textit{sum} + \textit{sum}\bmod 2}{2}\right\rfloor$。由此可知，只要 $\textit{sum} > 0$，那么 $\textit{carry}$ 就会变成 $1$，后续 $\textit{sum}>0$ 始终成立。所以**一旦产生了进位，后续每一位都会产生进位**。
>
> 遍历到 $i=0$（最高位）时，如果 $\textit{carry} = 1$，由于 $1+1=10$，还需要再执行一次「除以 $2$」。
>
> 代码实现时，由于从 $i=n-1$ 到 $i=1$ 的每一步都要执行一次「除以 $2$」，我们可以初始化答案为 $n-1$，这样在循环内只需统计「加上 $1$」的次数。
>
> ```python
> class Solution:
>     def numSteps(self, s: str) -> int:
>         ans = len(s) - 1  # 除了最高位，其余每一位都要执行一次「除以 2」
>         carry = 0
>         for i in range(len(s) - 1, 0, -1):
>             sum_ = int(s[i]) + carry
>             ans += sum_ % 2  # 如果 s[i] 变成 1，需要执行「加上 1」
>             carry = (sum_ + sum_ % 2) // 2
>         # 如果在最高位还有进位，由于 1 + 1 = 10，需要再执行一次「除以 2」
>         return ans + carry
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
>
> ## 方法二：公式
>
> 由方法一的代码可知，只要知道循环内「加上 $1$」执行了多少次，以及最终 $\textit{carry}$ 的值，就得到了答案。
>
> 设 $s$ 最右边的 $1$ 的下标为 $i$。
>
> 1. 初始化答案为 $n-1$。
> 2. 下标范围 $[i+1,n-1]$ 都是 $0$，不会执行加上 $1$。
> 3. $s[i]$ 处执行加上 $1$，答案加 $1$。
> 4. 根据方法一「一旦产生了进位，后续每一位都会产生进位」这个结论，下标范围 $[1,i-1]$ 中的每个 $0$ 进位后变成了 $1$，需要执行加上 $1$；每个 $1$ 进位后变成了 $0$，无需执行加上 $1$。所以答案增加了 $[1,i-1]$ 中的 $0$ 的个数。
> 5. 如果 $i > 0$，那么 $s[0]$ 会进位，需要额外执行一次除以 $2$，答案加 $1$。
>
> 综上所述：
>
> - 如果 $i=0$，答案为 $n-1$（只需执行 $n-1$ 次除以 $2$）。
> - 如果 $i>0$，答案为 $n-1$，加上 $[1,i-1]$ 中的 $0$ 的个数，再加上 $2$（下标 $0$ 和下标 $i$ 的操作）。
>
> ```python
> class Solution:
>     def numSteps(self, s: str) -> int:
>         ans = len(s) - 1
>         i = s.rfind('1')
>         if i > 0:
>             ans += s.count('0', 1, i) + 2
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
