# 三种做法：排序 / 维护最大次大 / 枚举右维护左（Python/Java/C++/Go）

> **[1464. 数组中两元素的最大乘积](https://leetcode.cn/problems/maximum-product-of-two-elements-in-an-array/solutions/4002354/san-chong-zuo-fa-pai-xu-wei-hu-zui-da-ci-c5bg/) · Easy**

> **题目描述**
> 给你一个整数数组 `nums`。
>
> 请你选择数组的两个 **不同** 下标 `i` 和 `j`<em>，</em>
>
> 返回 `(nums[i] - 1) * (nums[j] - 1)` 的 **最大值**。
>
> **示例 1：**
>
> ```
>
> 输入：nums = [3,4,5,2]
> 输出：12
> 解释：如果选择下标 i=1 和 j=2（下标从 0 开始），则可以获得最大值，(nums[1]-1)*(nums[2]-1) = (4-1)*(5-1) = 3*4 = 12 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums = [1,5,4,5]
> 输出：16
> 解释：选择下标 i=1 和 j=3（下标从 0 开始），则可以获得最大值 (5-1)*(5-1) = 16 。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：nums = [3,7]
> 输出：12
> ```
>
> **提示：**
>
> - `2 <= nums.length <= 500`
>
> - `1 <= nums[i] <= 10^3`

> **题解**
> ## 方法一：排序
>
> 由于 $\textit{nums}$ 中的数都是正整数，所以 $\textit{nums}[i]$ 和 $\textit{nums}[j]$ 都越大越好。选 $\textit{nums}$ 中最大的两个数作为 $\textit{nums}[i]$ 和 $\textit{nums}[j]$。
>
> ```python
> class Solution:
>     def maxProduct(self, nums: List[int]) -> int:
>         nums.sort()
>         return (nums[-1] - 1) * (nums[-2] - 1)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{nums}$ 的长度。瓶颈在排序上。
> - 空间复杂度：$\mathcal{O}(1)$。忽略排序的栈开销。
>
> ## 方法二：维护最大次大
>
> ```python
> class Solution:
>     def maxProduct(self, nums: List[int]) -> int:
>         max1 = max2 = 0
>         for x in nums:
>             if x > max1:
>                 max2 = max1
>                 max1 = x
>             elif x > max2:
>                 max2 = x
>         return (max1 - 1) * (max2 - 1)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
>
> ## 方法三：枚举右维护左
>
> 暴力做法是枚举所有的下标对 $(i,j)$，其中 $0\le i<j<n$。
>
> 枚举 $j$，我们需要知道左边 $\textit{nums}[i]$ 的最大值。这可以用一个变量维护。
>
> ```python
> class Solution:
>     def maxProduct(self, nums: List[int]) -> int:
>         ans = mx = 0
>         for x in nums:
>             ans = max(ans, (mx - 1) * (x - 1))
>             mx = max(mx, x)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
