1439.有序矩阵中的第k个最小数组和

[力扣](https://leetcode-cn.com/problems/find-the-kth-smallest-sum-of-a-matrix-with-sorted-rows/)

题目要求找出第k个最小数组和，首先可以明确的是，最小的必然是第零列上的数之和。接下来，第二小的就是将某一行的第一列，加上另外行的第零列，一共有m种候选答案。更进一步的，每当我们得到一个第p小的数组和之后，将任意一行往后移动一列之后得到的新数组都可能成为第p + 1小的数组和的，也就是新增了m中备选答案。

于是我们可以维护一个堆，每次弹出堆顶，作为当前的最小数组和，并将后续的m种备选答案加入到堆中。由于这里的k很小，因此这里的时间和空间复杂度都不是问题。不过需要特别注意的是这种做法可能出现重复的情况。例如样例3：

1 10 10

1 4 5

2 3 6

1、首先选出的是[1, 1, 2]，那么将备选答案[10, 1, 2]、[1, 4, 2]、[1, 1, 3]加入到堆中

2、此时应该选择[1, 1, 3]，那么将备选答案[10, 1, 3]、[1, 4, 3]、[1, 1, 6]加入到堆中。

此时堆中一共有5个备选答案，分别为[10, 1, 2]、[1, 4, 2]、[10, 1, 3]、[1, 4, 3]、[1, 1, 6]

3、此时应该选择[1, 4, 2]，那么将备选答案[10, 4, 2]、[1, 5, 2]、[1, 4, 3]加入到堆中。这里的[1, 4, 3]就与步骤2中出现了重复，因此不能加入到堆中。此时可以直接判断，也可以利用哈希来做。我在实现的时候用的是python，因此去重用的是自带的tuple。

此时堆中一共有6个备选答案，分别为[10, 1, 2]、[10, 1, 3]、[1, 4, 3]、[1, 1, 6]、[10, 4, 2]、[1, 5, 2]

4、此时可以选择[1, 4, 3]、[1, 1, 6]或者[1, 5, 2]，不妨选择[1, 4, 3]，那么将备选答案[10, 4, 3]、[1, 5, 3]、[1, 4, 6]加入到堆中。

此时堆中一共有8个备选答案，分别为[10, 1, 2]、[10, 1, 3]、[1, 1, 6]、[10, 4, 2]、[1, 5, 2]、[10, 4, 3]、[1, 5, 3]、[1, 4, 6]

5、此时可以选择[1, 1, 6]或者[1, 5, 2]，不妨选择[1, 1, 6]。由于6这一行已经到达了尽头，因此只有两个新的备选答案，分别为[10, 1, 6]、[1, 4, 6]。其中[1, 4, 6]出现了重复，不能加入到堆中。

此时堆中一共有7个备选答案，分别为[10, 1, 2]、[10, 1, 3]、[10, 4, 2]、[1, 5, 2]、[10, 4, 3]、[1, 5, 3]、[1, 4, 6]、[10, 1, 6]

6、此时应该选择[1, 5, 2]。由于5这一行已经到达了尽头，因此只有两个新的备选答案，分别为[10, 5, 2]、[1, 5, 3]。其中[1, 5, 3]出现了重复，不能加入到堆中。

此时堆中一共有7个备选答案，分别为[10, 1, 2]、[10, 1, 3]、[10, 4, 2]、[10, 4, 3]、[1, 5, 3]、[1, 4, 6]、[10, 1, 6]、[10, 5, 2]

7、最后一轮应该选择[1, 5, 3]，因此答案就是9。

可以发现，上面的算法很明显有优化的余地。例如步骤2中，将[1, 4, 3]加入到答案时，由于堆中已经有了其前置[1, 4, 2]，那么[1, 4, 3]必然不会被选中。另一方面，当[1, 4, 2]被选择之后，再将[1, 4, 3]加入到堆中可以有效规避掉去重相关的问题。更严谨的说，应该是当[1, 4, 3]的两个前置[1, 1, 3]以及[1, 4, 2]被选择后，我们才应当将[1, 4, 3]加入到堆中。

一般来说，一个候选数组应该有m种前置数组，但是这里的[1, 4, 3]的第0行已经是最左侧，因此在这一行没有前置数组，因此只需要考察[1, 1, 3]以及[1, 4, 2]这两种前置数组。

那么在这里，如果将这个前置关系作为有向图中的边，每种数组选择的方式作为图中的点，就可以利用堆加上拓扑排序的做法来优化候选集的大小。不过加入优化之后候选集的大小上限我也没弄得太清楚，这里就没有加上这个优化了。

最后附上python代码：

```python
class Solution(object):
    def kthSmallest(self, mat, k):
        """
        :type mat: List[List[int]]
        :type k: int
        :rtype: int
        """

        m = len(mat)
        n = len(mat[0])

        s = 0
        for index in range(m):
            s += mat[index][0]
        
        heap = [[s, [0] * m]]
        used = set()
        for _ in range(k):
            while True:
                res, choose = heapq.heappop(heap)
                if tuple(choose) not in used:
                    used.add(tuple(choose))
                    for index in range(m):
                        if choose[index] < n - 1:
                            tmp = choose[:]
                            tmp[index] += 1
                            heapq.heappush(heap, [res - mat[index][choose[index]] + mat[index][choose[index] + 1], tmp])

                    break
        
        return res
```
