# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[14. 最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/solutions/2801713/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-478q/) · Easy**

> **所属题单**
> - [面试经典 150 题 · 数组 / 字符串](../../../刷题路径/灵神原版题单/面试经典%20150%20题/数组%20-%20字符串.md)

> **题目描述**
> 编写一个函数来查找字符串数组中的最长公共前缀。
>
> 如果不存在公共前缀，返回空字符串 `""`。
>
> **示例 1：**
>
> ```
>
> 输入：strs = ["flower","flow","flight"]
> 输出："fl"
> ```
>
> **示例 2：**
>
> ```
>
> 输入：strs = ["dog","racecar","car"]
> 输出：""
> 解释：输入不存在公共前缀。
> ```
>
> **提示：**
>
> - `1 <= strs.length <= 200`
>
> - `0 <= strs[i].length <= 200`
>
> - `strs[i]` 如果非空，则仅由小写英文字母组成

> **题解**
> 看示例 1：
>
> $$
> \begin{align}
> &\texttt{flower}\\
> &\texttt{flow}\\
> &\texttt{flight}\\
> \end{align}
> $$
>
> 从左到右，竖着看，第一列全是 $\texttt{f}$，第二列全是 $\texttt{l}$，第三列就不全一样了，所以「最长公共前缀」是 $\texttt{fl}$。
>
> 具体算法如下：
>
> 1. **从左到右**遍历 $\textit{strs}$ 的每一列。
> 2. 设当前遍历到第 $j$ 列，**从上到下**遍历这一列的字母。
> 3. 设当前遍历到第 $i$ 行，即 $\textit{strs}[i][j]$。如果 $j$ 等于 $\textit{strs}[i]$ 的长度，或者 $\textit{strs}[i][j]\ne \textit{strs}[0][j]$，说明这一列的字母缺失或者不全一样，那么最长公共前缀的长度等于 $j$，返回 $\textit{strs}[0]$ 的长为 $j$ 的前缀。
> 4. 如果没有中途返回，说明所有字符串都有一个等于 $\textit{strs}[0]$ 的前缀，那么最长公共前缀就是 $\textit{strs}[0]$。
>
> ```python
> class Solution:
>     def longestCommonPrefix(self, strs: List[str]) -> str:
>         s0 = strs[0]
>         for j, c in enumerate(s0):  # 从左到右
>             for s in strs:  # 从上到下
>                 if j == len(s) or s[j] != c:  # 这一列有字母缺失或者不同
>                     return s0[:j]  # 0 到 j-1 是公共前缀
>         return s0
> ```
>
> > [!example]- Python3 zip
> > ```python
> > class Solution:
> >     def longestCommonPrefix(self, strs: List[str]) -> str:
> >         lcp = 0
> >         for col in zip(*strs):
> >             if len(set(col)) > 1:
> >                 break
> >             lcp += 1
> >         return strs[0][:lcp]
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(nm)$，其中 $n$ 为 $\textit{strs}$ 的长度，$m$ 为 $\textit{strs}$ 中最短字符串的长度。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
