## 题目描述

实现 [pow(<em>x</em>, <em>n</em>)](https://www.cplusplus.com/reference/valarray/pow/) ，即计算 `x` 的整数 `n` 次幂函数（即，`x^n`<sup> </sup>）。

**示例 1：**

```

输入：x = 2.00000, n = 10
输出：1024.00000
```

**示例 2：**

```

输入：x = 2.10000, n = 3
输出：9.26100
```

**示例 3：**

```

输入：x = 2.00000, n = -2
输出：0.25000
解释：2⁻² = 1/2² = 1/4 = 0.25
```

**提示：**

- `-100.0 < x < 100.0`

- `-2³¹ <= n <= 2³¹-1`

- `n` 是一个整数

- 要么 `x` 不为零，要么 `n > 0` 。

- `-10⁴ <= x^n <= 10⁴`
