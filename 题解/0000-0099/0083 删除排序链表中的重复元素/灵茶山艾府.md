> **题目描述**
> 给定一个已排序的链表的头 `head` ， <em>删除所有重复的元素，使每个元素只出现一次</em> 。返回 <em>已排序的链表</em> 。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/9e1bbdcfcdc628f2.jpg)
>
> ```
>
> 输入：head = [1,1,2]
> 输出：[1,2]
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/c8f66b021ae8d221.jpg)
>
> ```
>
> 输入：head = [1,1,2,3,3]
> 输出：[1,2,3]
> ```
>
> **提示：**
>
> - 链表中节点数目在范围 `[0, 300]` 内
>
> - `-100 <= Node.val <= 100`
>
> - 题目数据保证链表已经按升序 **排列**

> **题解**
> ## 视频讲解
>
> 请看[【基础算法精讲 08】](https://www.bilibili.com/video/BV1VP4y1Q71e/)，制作不易，欢迎点赞~
>
> ```python
> class Solution:
>     def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         if head is None:
>             return None
>         cur = head
>         while cur.next:  # 看看下个节点……
>             if cur.next.val == cur.val:  # 和我一样，删！
>                 cur.next = cur.next.next
>             else:  # 和我不一样，移动到下个节点
>                 cur = cur.next
>         return head
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为链表的长度。
> - 空间复杂度：$\mathcal{O}(1)$，仅用到若干额外变量。
