## 题目描述

给定一个已排序的链表的头 `head` ， <em>删除所有重复的元素，使每个元素只出现一次</em> 。返回 <em>已排序的链表</em> 。

**示例 1：**

![](../../_assets/灵茶山艾府/9e1bbdcfcdc628f2.jpg)

```

输入：head = [1,1,2]
输出：[1,2]
```

**示例 2：**

![](../../_assets/灵茶山艾府/c8f66b021ae8d221.jpg)

```

输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

**提示：**

- 链表中节点数目在范围 `[0, 300]` 内

- `-100 <= Node.val <= 100`

- 题目数据保证链表已经按升序 **排列**
