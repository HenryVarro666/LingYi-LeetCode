> **题目描述**
> 给你两个单词 `word1` 和 `word2`， <em>请返回将 `word1` 转换成 `word2` 所使用的最少操作数</em>  。
>
> 你可以对一个单词进行如下三种操作：
>
> - 插入一个字符
>
> - 删除一个字符
>
> - 替换一个字符
>
> **示例 1：**
>
> ```
>
> 输入：word1 = "horse", word2 = "ros"
> 输出：3
> 解释：
> horse -> rorse (将 'h' 替换为 'r')
> rorse -> rose (删除 'r')
> rose -> ros (删除 'e')
> ```
>
> **示例 2：**
>
> ```
>
> 输入：word1 = "intention", word2 = "execution"
> 输出：5
> 解释：
> intention -> inention (删除 't')
> inention -> enention (将 'i' 替换为 'e')
> enention -> exention (将 'n' 替换为 'x')
> exention -> exection (将 'n' 替换为 'c')
> exection -> execution (插入 'u')
> ```
>
> **提示：**
>
> - `0 <= word1.length, word2.length <= 500`
>
> - `word1` 和 `word2` 由小写英文字母组成

> #### 答疑
>
> **问**：为什么只需考虑从右往左（或者从左往右）操作？我就不能从中间开始操作吗？
>
> **答**：假设两个字符为 $s[i]$ 和 $t[j]$，先操作 $i$ 再操作 $j$，还是先操作 $j$ 再操作 $i$，结果都是一样的。推广，任意一种操作顺序，都可以**重新排列**成从右往左（从左往右）操作。
>
> ## 一、递归搜索 + 保存计算结果 = 记忆化搜索
>
> ```python
> class Solution:
>     def minDistance(self, s: str, t: str) -> int:
>         n, m = len(s), len(t)
>         @cache  # 缓存装饰器，避免重复计算 dfs 的结果（记忆化）
>         def dfs(i: int, j: int) -> int:
>             if i < 0:
>                 return j + 1
>             if j < 0:
>                 return i + 1
>             if s[i] == t[j]:
>                 return dfs(i - 1, j - 1)
>             return min(dfs(i - 1, j), dfs(i, j - 1), dfs(i - 1, j - 1)) + 1
>         return dfs(n - 1, m - 1)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(nm)$，其中 $n$ 为 $s$ 的长度，$m$ 为 $t$ 的长度。
> - 空间复杂度：$\mathcal{O}(nm)$。
>
> ## 二、1:1 翻译成递推
>
> ```python
> class Solution:
>     def minDistance(self, s: str, t: str) -> int:
>         n, m = len(s), len(t)
>         f = [[0] * (m + 1) for _ in range(n + 1)]
>         f[0] = list(range(m + 1))
>         for i, x in enumerate(s):
>             f[i + 1][0] = i + 1
>             for j, y in enumerate(t):
>                 f[i + 1][j + 1] = f[i][j] if x == y else \
>                         min(f[i][j + 1], f[i + 1][j], f[i][j]) + 1
>         return f[n][m]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(nm)$，其中 $n$ 为 $s$ 的长度，$m$ 为 $t$ 的长度。
> - 空间复杂度：$\mathcal{O}(nm)$。
>
> ## 三、空间优化：两个数组（滚动数组）
>
> ```python
> class Solution:
>     def minDistance(self, s: str, t: str) -> int:
>         n, m = len(s), len(t)
>         f = [list(range(m + 1)), [0] * (m + 1)]
>         for i, x in enumerate(s):
>             f[(i + 1) % 2][0] = i + 1
>             for j, y in enumerate(t):
>                 f[(i + 1) % 2][j + 1] = f[i % 2][j] if x == y else \
>                         min(f[i % 2][j + 1], f[(i + 1) % 2][j], f[i % 2][j]) + 1
>         return f[n % 2][m]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(nm)$，其中 $n$ 为 $s$ 的长度，$m$ 为 $t$ 的长度。
> - 空间复杂度：$\mathcal{O}(m)$。
>
> ## 四、空间优化：一个数组
>
> ```python
> class Solution:
>     def minDistance(self, s: str, t: str) -> int:
>         f = list(range(len(t) + 1))
>         for x in s:
>             pre = f[0]
>             f[0] += 1  # f[0] = i + 1
>             for j, y in enumerate(t):
>                 tmp = f[j + 1]
>                 f[j + 1] = pre if x == y else min(f[j + 1], f[j], pre) + 1
>                 pre = tmp
>         return f[-1]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(nm)$，其中 $n$ 为 $s$ 的长度，$m$ 为 $t$ 的长度。
> - 空间复杂度：$\mathcal{O}(m)$。
