# 利用方向向量简化代码（Python/Java/C++/C/Go/JS/Rust）

> **[59. 螺旋矩阵 II](https://leetcode.cn/problems/spiral-matrix-ii/solutions/3059650/jian-ji-xie-fa-pythonjavaccgojsrust-by-e-fhmr/) · Medium**

> **题目描述**
> 给你一个正整数 `n` ，生成一个包含 `1` 到 `n²` 所有元素，且元素按顺时针顺序螺旋排列的 `n x n` 正方形矩阵 `matrix` 。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/c58dcb2bce453a04.jpg)
>
> ```
>
> 输入：n = 3
> 输出：[[1,2,3],[8,9,4],[7,6,5]]
> ```
>
> **示例 2：**
>
> ```
>
> 输入：n = 1
> 输出：[[1]]
> ```
>
> **提示：**
>
> - `1 <= n <= 20`

> **题解**
> ## 思路
>
> ![lc59.jpg](../../_assets/灵茶山艾府/090846ffde612cba.jpg)
>
> 根据题意，我们从左上角 $(0,0)$ 出发，按照「右下左上」的顺序前进：
>
> - 首先向右走，如果到达矩阵边界，则向右转 $90^\circ$，前进方向变为向下。
> - 然后向下走，如果到达矩阵边界，则向右转 $90^\circ$，前进方向变为向左。
> - 然后向左走，如果到达矩阵边界，则向右转 $90^\circ$，前进方向变为向上。
> - 然后向上走，先从 $7$ 走到 $8$，然后从 $8$ 准备向上走，但上面的 $1$ 是一个已经填过数字的位置，那么向右转 $90^\circ$，前进方向变为向右。
> - 重复上述过程，直到填入数字 $n^2$ 为止。
>
> ## 实现细节
>
> 1. 初始化一个 $n\times n$ 的矩阵，一开始所有元素均为 $0$。
> 2. 用一个长为 $4$ 的方向数组 $\textit{DIRS} = [(0, 1), (1, 0), (0, -1), (-1, 0)]$ 分别表示右下左上 $4$ 个方向。同时用一个下标 $\textit{di}$ 表示当前方向，初始值为 $0$，表示一开始向右。
> 3. 每次移动，相当于把行号增加 $\textit{DIRS}[\textit{di}][0]$，把列号增加 $\textit{DIRS}[\textit{di}][1]$。
> 4. 向右转 $90^\circ$，相当于把 $\textit{di}$ 增加 $1$，但在 $\textit{di}=3$ 时要回到 $\textit{di}=0$。两种情况合二为一，把 $\textit{di}$ 更新为 $(\textit{di}+1)\bmod 4$。
>
> ```python
> DIRS = (0, 1), (1, 0), (0, -1), (-1, 0)  # 右下左上
>
> class Solution:
>     def generateMatrix(self, n: int) -> List[List[int]]:
>         ans = [[0] * n for _ in range(n)]
>         i = j = di = 0
>         for val in range(1, n * n + 1):  # 要填入的数
>             ans[i][j] = val
>             x, y = i + DIRS[di][0], j + DIRS[di][1]  # 下一步的位置
>             # 如果 (x, y) 出界或者已经填入数字
>             if x < 0 or x >= n or y < 0 or y >= n or ans[x][y]:
>                 di = (di + 1) % 4  # 右转 90°
>             i += DIRS[di][0]
>             j += DIRS[di][1]  # 走一步
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n^2)$。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
