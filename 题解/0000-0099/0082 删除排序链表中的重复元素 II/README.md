## 题目描述

给定一个 **已排序** 的链表的头节点 `head`。

删除原始链表中所有 **重复** 数字的节点，只留下 **不同** 的数字。

返回 **已排序** 的链表。

**示例 1：**

![](../../_assets/灵茶山艾府/4f6cc87ae5016779.jpg)

```

输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

**示例 2：**

![](../../_assets/灵茶山艾府/8cd3b2c3f71d3364.jpg)

```

输入：head = [1,1,1,2,3]
输出：[2,3]
```

**提示：**

- 链表中节点数目在范围 `[0, 300]` 内

- `-100 <= Node.val <= 100`

- 题目数据保证链表已经按升序 **排列**
