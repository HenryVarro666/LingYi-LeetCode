# 遍历（Python/Java/C++/Go）

> **[3931. 检查相邻数字差](https://leetcode.cn/problems/check-adjacent-digit-differences/solutions/3969736/bian-li-pythonjavacgo-by-endlesscheng-9mh6/) · Easy**

> **题目描述**
> 给你一个由数字组成的字符串 `s`。
>
> 如果每一对 **相邻** 数字之间的 **绝对差** 都至多为 2，则返回 `true`；否则返回 `false`。
>
> `a` 和 `b` 之间的绝对差定义为 `abs(a - b)`。
>
> **示例 1：**
>
> **输入：** `s = "132"`
>
> **输出：** `true`
>
> **解释：**
>
> - `s[0]` 和 `s[1]` 处数字的绝对差为 `abs(1 - 3) = 2`。
>
> - `s[1]` 和 `s[2]` 处数字的绝对差为 `abs(3 - 2) = 1`。
>
> - 由于两个差值都至多为 2，因此答案为 `true`。
>
> **示例 2：**
>
> **输入：** `s = "129"`
>
> **输出：** `false`
>
> **解释：**
>
> - `s[0]` 和 `s[1]` 处数字的绝对差为 `abs(1 - 2) = 1`。
>
> - `s[1]` 和 `s[2]` 处数字的绝对差为 `abs(2 - 9) = 7`，大于 2。
>
> - 因此，答案为 `false`。
>
> **提示：**
>
> - `2 <= s.length <= 100`
>
> - `s` 仅由数字组成。

> **题解**
> 遍历 $s$，如果 $|s[i]-s[i-1]| > 2$，返回 $\texttt{false}$。
>
> 如果正常遍历完毕，返回 $\texttt{true}$。
>
> 下午两点 [B站@灵茶山艾府](https://space.bilibili.com/206214) 直播讲题，欢迎关注~
>
> ```python
> class Solution:
>     def isAdjacentDiffAtMostTwo(self, s: str) -> bool:
>         return all(abs(x - y) <= 2 for x, y in pairwise(map(ord, s)))
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
