# 构造题（Python/Java/C++/Go）

> **[3990. 创建一个恰好有 K 条路径的网格图 II](https://leetcode.cn/problems/create-grid-with-exactly-k-paths-ii/solutions/3995387/gou-zao-ti-by-endlesscheng-r1ve/) · Hard**

> **题解**
> 本题是 [3988. 创建一个恰好有 K 条路径的网格图 I](https://leetcode.cn/problems/create-grid-with-exactly-k-paths-i/) 的加强版，做法见 [我的题解](../3988%20创建一个恰好有%20K%20条路径的网格图%20I/灵茶山艾府.md) 中的「更一般的构造方法」，包含图片解释。
>
> ```python
> class Solution:
>     def createGrid(self, k: int) -> list[str]:
>         w = k.bit_length()
>         m = w * 2
>         n = w + 3
>         a = [['#'] * (n - 1) + ['.'] for _ in range(m)]
>         for j in range(w):
>             i = j * 2
>             a[i][j] = a[i][j + 1] = a[i + 1][j] = a[i + 1][j + 1] = '.'
>
>         for i in range(w):
>             if k >> i & 1:
>                 for j in range(i + 2, n - 1):
>                     a[i * 2][j] = '.'
>
>         return [''.join(row) for row in a]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(\log^2 k)$。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
