# 简单题，简单做（Python/Java/C++/Go）

> **[3978. 唯一中间元素](https://leetcode.cn/problems/unique-middle-element/solutions/3991779/jian-dan-ti-jian-dan-zuo-pythonjavacgo-b-7yxj/) · Easy**

> **题目描述**
> 给你一个长度为奇数 `n` 的整数数组 `nums` 。
>
> 如果 `nums` 的下标中间元素在数组中 **恰好** 出现一次，返回 `true` 。否则返回 `false` 。
>
> **示例 1：**
>
> **输入：** `nums = [1,2,3]`
>
> **输出：** `true`
>
> **解释：**
>
> `nums` 的中间元素是 2 ，它恰好出现一次。
>
> 因此，答案为 `true` 。
>
> **示例 2：**
>
> **输入：** `nums = [1,2,2]`
>
> **输出：** `false`
>
> **解释：**
>
> `nums` 的中间元素是 2 ，它出现了两次。
>
> 因此，答案为 `false` 。
>
> **提示：**
>
> - `1 <= n == nums.length <= 100`
>
> - `n` 是奇数。
>
> - `1 <= nums[i] <= 100`

> **题解**
> 设 $m = \left\lfloor\dfrac{n}{2}\right\rfloor$。
>
> 两种方法：
>
> 1. 统计 $\textit{nums}$ 中的 $\textit{nums}[m]$ 的出现次数，必须恰好为 $1$。
> 2. $[0,m-1]$ 和 $[m+1,n-1]$ 必须都不包含 $\textit{nums}[m]$。这样写可以中途跳出循环，不需要完整遍历 $\textit{nums}$。
>
> 下午两点 [B站@灵茶山艾府](https://space.bilibili.com/206214) 直播讲题，欢迎关注~
>
> ```python
> class Solution:
>     def isMiddleElementUnique(self, nums: list[int]) -> bool:
>         return nums.count(nums[len(nums) // 2]) == 1
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
