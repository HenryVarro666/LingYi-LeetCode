3988.创建一个恰好有K条路径的网格图I

<https://leetcode.cn/problems/create-grid-with-exactly-k-paths-i/description/>

题目给出三个整数m、n和k。其中m和n不超过10，k不超过4。

现在要求构造一个大小为m \* n的网格，该网格仅由'.'以及'\#'构成，其中'.'表示空单元格，'\#'表示障碍物。

一条有效路径指的是从(0, 0)出发，仅通过向右或者向下移动到相邻的空单元格，到(m - 1, n - 1)结束的路径。

要求返回一个网格，其中恰好存在k条有效路径。若不存在，则返回空数组。

为了方便起见，在这里可以先假设m \<\= n。若m > n，则可以交换二者，计算出最终答案后再转置一下就行了。

接下来，由于k的规模较小，因此在这里可以考虑分情况讨论。

首先，当m \= 1时，显然只有华山一条路。若k为1，那么答案就是n个'.'，否则无解。

接下来，当m >\= 2时，可以考虑如下构造。

对于两行的空网格，使用动态规划计算不同列数时的方案数：

1、有一列时，只有一条路：

```
1
↓
1
```

2、有两列时，一共两条路径：

```
1  -> 1
↓    ↓
1  -> 2
```

3、有三列时，有三条路径：

```
1 -> 1 -> 1
↓   ↓   ↓
1 -> 2 -> 3
```

4、有四列时，有四条路径：

```
1 -> 1 -> 1 -> 1
↓   ↓   ↓   ↓
1 -> 2 -> 3 -> 4
```

更进一步的，若n >\= k，那么可以将前两行构造为第一行全空格，第二个前n - k个为障碍，最后k个为空格，那么就会得到

```
1 -> 1 -> 1 -> ... -> 1 -> 1 -> ... -> 1
↓   ↓   ↓          ↓   ↓          ↓
0 -> 0 -> 0 -> ... -> 1 -> 2 -> ... -> k
```

恰好是k条路径。而对于后续的行，则可以构造成最后一列为空格，前面全为障碍，这样从(1, n - 1)开始只能一直往下走直到(m - 1, n - 1)，因此路径数就此定格在k，即

```
1 -> 1 -> 1 -> ... -> 1 -> 1 -> ... -> 1
↓   ↓   ↓          ↓   ↓          ↓
0 -> 0 -> 0 -> ... -> 1 -> 2 -> ... -> k
↓   ↓   ↓          ↓   ↓          ↓
0 -> 0 -> 0 -> ... -> 0 -> 0 -> ... -> k
↓   ↓   ↓          ↓   ↓          ↓
...  ...  ...         ...  ...         ...
↓   ↓   ↓          ↓   ↓          ↓
0 -> 0 -> 0 -> ... -> 0 -> 0 -> ... -> k
```

这样一来，对于所有m >\= 2且n >\= k的情况，就构造出了答案。

最后再考虑漏网之鱼。由于m \<\= n的前提，而这里又有m >\= 2且n \< k，同时题目保证k \<\= 4，因此只存在三种没考虑到的情况：

1、m \= 2，n \= 2，k \= 3：

已知两行两列只有两条路径，因此这种情况无解

2、m \= 2，n \= 3，k \= 4：

同样的，这种情况也无解

3、m \= 3，n \= 3，k \= 4：

这种情况需要单独构造。

首先对于这个k \= 4，可以拆分为4 + 0、3 + 1和2 + 2，表示从两个方向过来的路径数量。默认从上方过去的路径数量比较多，因为此时m \= n，因此是完全对称的，无需考虑另一种情况。

- 4 + 0是不可能的，因为2行3列最多3条路径
- 3 + 1是不可能的，因为当2行3列构造出3条路径时，另一个方向的路径数量要么为0，要么大于等于2，因为此时到达单元格(1, 1)的路径数为2，到达(2, 1)的路径数要么为0，要么大于等于2，无法得到需要的1
- 最后只能考虑2 + 2。基于2行3列的路径构造，此时只能屏蔽掉贴边的路径，否则路径数就不够了，因此在这里可以构造出网格

```
..#
...
#..
```

对应的路径数为

```
1 -> 1 -> 0
↓   ↓   ↓
1 -> 2 -> 2
↓   ↓   ↓
0 -> 2 -> 4
```

最后附上python代码：

```python
class Solution(object):
    def createGrid(self, m, n, k):
        """
        :type m: int
        :type n: int
        :type k: int
        :rtype: List[str]
        """
        
        rev = False
        if m > n:
            m, n = n, m
            rev = True
        
        if m == 1:
            if k == 1:
                res = ['.' * n]
            else:
                res = []
        
        elif n >= k:
            res = ['.' * n, '#' * (n - k) + '.' * k]
            res.extend(['#' * (n - 1) + '.'] * (m - 2))
        
        elif m == 2:
            res = []
        
        elif m == 3:
            res = ['..#', '...', '#..']
        
        if not res:
            return res
            
        if rev:
            rev_res = [['.'] * m for _ in range(n)]
            for i in range(m):
                for j in range(n):
                    rev_res[j][i] = res[i][j]
            
            return [''.join(line) for line in rev_res]
        
        return res
```
