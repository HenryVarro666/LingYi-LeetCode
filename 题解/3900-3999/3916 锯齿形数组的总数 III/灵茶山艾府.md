# 拉格朗日插值

> **[3916. 锯齿形数组的总数 III](https://leetcode.cn/problems/number-of-zigzag-arrays-iii/solutions/3961909/la-ge-lang-ri-cha-zhi-by-endlesscheng-ac1c/) · Hard**

> - [数学算法 · 七、杂项](../../../刷题路径/灵神原版题单/数学算法/七、杂项.md) · §7.6 拉格朗日插值

> **题解**
> **前置题目**：[3699. 锯齿形数组的总数 I](https://leetcode.cn/problems/number-of-zigzag-arrays-i/)
>
> **前置知识**：[拉格朗日插值](https://oi-wiki.org/math/numerical/interp/#lagrange-%E6%8F%92%E5%80%BC%E6%B3%95)
>
> 设 $k=r-\ell+1$。设 $S_n(k)$ 为本题的答案（总方案数）。
>
> 根据 3699 题的转移方程：
>
> - $S_1(x) = x$ 是 $1$ 次多项式。
> - 从 $S_{i-1}(x)$ 到 $S_i(x)$，我们在计算前缀和，这会导致多项式的次数加一。
> - 所以 $S_n(x)$ 是 $n$ 次多项式。
>
> 用 3699 题的算法，算出 $S_n(1),S_n(2),\ldots,S_n(n+1)$，就可以用拉格朗日插值 $\mathcal{O}(n^2)$ 求出 $S_n(x)$ 在 $x=k$ 处的值。
>
> ```python
> class Solution:
>     def zigZagArrays(self, n: int, l: int, r: int) -> int:
>         MOD = 1_000_000_007
>
>         # 3699. 锯齿形数组的总数 I
>         def dp(k: int) -> int:
>             f = [1] * k
>
>             for i in range(1, n):
>                 if i % 2:  # 增
>                     pre = 0
>                     for j, v in enumerate(f):
>                         f[j] = pre % MOD
>                         pre += v
>                 else:  # 减
>                     suf = 0
>                     for j in range(k - 1, -1, -1):
>                         v = f[j]
>                         f[j] = suf % MOD
>                         suf += v
>
>             return sum(f) * 2 % MOD
>
>         k = r - l + 1
>         if k <= n + 1:
>             return dp(k)
>
>         xs = list(range(1, n + 2))
>         ys = [dp(x) for x in xs]
>         return self.lagrange(xs, ys, k)
>
>     # 传入 n 次多项式 f(x) 上的 n+1 个点 (xs[i], ys[i])，返回 f(k)
>     def lagrange(self, xs: list[int], ys: list[int], k: int) -> int:
>         MOD = 1_000_000_007
>         n = len(xs)
>         fk = 0
>         for i in range(n):
>             a, b = ys[i], 1
>             for j in range(n):
>                 if i != j:
>                     a = a * (k - xs[j]) % MOD  # 分子
>                     b = b * (xs[i] - xs[j]) % MOD  # 分母
>             fk += a * pow(b, -1, MOD)
>         return fk % MOD
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n^3)$。
> - 空间复杂度：$\mathcal{O}(n)$。
