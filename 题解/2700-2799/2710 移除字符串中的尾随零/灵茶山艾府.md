# 库函数写法（Python/Java/C++/Go/JS/Rust）

> **[2710. 移除字符串中的尾随零](https://leetcode.cn/problems/remove-trailing-zeros-from-a-string/solutions/2287429/ku-han-shu-xie-fa-pythonjavacgo-by-endle-fjmr/) · Easy**

> **题目描述**
> 给你一个用字符串表示的正整数 `num` ，请你以字符串形式返回不含尾随零的整数 `num` 。
>
> **示例 1：**
>
> ```
> 输入：num = "51230100"
> 输出："512301"
> 解释：整数 "51230100" 有 2 个尾随零，移除并返回整数 "512301" 。
> ```
>
> **示例 2：**
>
> ```
> 输入：num = "123"
> 输出："123"
> 解释：整数 "123" 不含尾随零，返回整数 "123" 。
> ```
>
> **提示：**
>
> - `1 <= num.length <= 1000`
>
> - `num` 仅由数字 `0` 到 `9` 组成
>
> - `num` 不含前导零

> **题解**
> 由于输入保证是**正整数**，所以去掉所有的尾零 $0$ 即可。
>
> ```python
> class Solution:
>     def removeTrailingZeros(self, num: str) -> str:
>         return num.rstrip('0')
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
