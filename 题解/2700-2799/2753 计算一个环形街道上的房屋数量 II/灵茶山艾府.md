# 线性做法（Python/Java/C++/Go/JS）

> **[2753. 计算一个环形街道上的房屋数量 II](https://leetcode.cn/problems/count-houses-in-a-circular-street-ii/solutions/2333549/xian-xing-zuo-fa-pythonjavacgojs-by-endl-w6gs/) · Hard**

> **所属题单**
> - [贪心算法 · 八、其他](../../../刷题路径/灵神原版题单/贪心算法/八、其他.md)

> **题解**
> 1. 不断向右找到一扇开着的门。
> 2. 跳过这扇门，继续向右。每向右一步，计数器 $i$ 就加一。循环至多 $k$ 次。
> 3. 如果遇到开着的门，就把门关上。
> 4. 答案为最后一次遇到的开着的门的 $i$。
>
> ```python
> class Solution:
>     def houseCount(self, s: Optional['Street'], k: int) -> int:
>         while not s.isDoorOpen():
>             s.moveRight()
>         for i in range(1, k + 1):
>             s.moveRight()
>             if s.isDoorOpen():
>                 ans = i
>                 s.closeDoor()
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(k)$。循环次数不会超过 $2k$。
> - 空间复杂度：$\mathcal{O}(1)$。仅用到若干额外变量。
