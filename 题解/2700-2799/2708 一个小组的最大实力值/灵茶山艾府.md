# O(n) 一次遍历，简洁写法（Python/Java/C++/C/Go/JS/Rust）

> **[2708. 一个小组的最大实力值](https://leetcode.cn/problems/maximum-strength-of-a-group/solutions/2897806/on-yi-ci-bian-li-jian-ji-xie-fa-pythonja-xni2/) · Medium**

> **所属题单**
> - [动态规划 · 六、状态机 DP](../../../刷题路径/灵神原版题单/动态规划/六、状态机%20DP.md) · §6.2 基础

> **题目描述**
> 给你一个下标从 **0** 开始的整数数组 `nums` ，它表示一个班级中所有学生在一次考试中的成绩。老师想选出一部分同学组成一个 **非空** 小组，且这个小组的 **实力值** 最大，如果这个小组里的学生下标为 `i₀`, `i₁`, `i₂`, ... , `i_k` ，那么这个小组的实力值定义为 `nums[i₀] * nums[i₁] * nums[i₂] * ... * nums[i_k​]` 。
>
> 请你返回老师创建的小组能得到的最大实力值为多少。
>
> **示例 1：**
>
> ```
> 输入：nums = [3,-1,-5,2,5,-9]
> 输出：1350
> 解释：一种构成最大实力值小组的方案是选择下标为 [0,2,3,4,5] 的学生。实力值为 3 * (-5) * 2 * 5 * (-9) = 1350 ，这是可以得到的最大实力值。
> ```
>
> **示例 2：**
>
> ```
> 输入：nums = [-4,-5,-4]
> 输出：20
> 解释：选择下标为 [0, 1] 的学生。得到的实力值为 20 。我们没法得到更大的实力值。
> ```
>
> **提示：**
>
> - `1 <= nums.length <= 13`
>
> - `-9 <= nums[i] <= 9`

> **题解**
> 从左到右遍历 $\textit{nums}$，考虑 $\textit{nums}[i]$ 选或不选：
>
> - 不选 $\textit{nums}[i]$，那么当前的最大实力值就是前面 $\textit{nums}[0]$ 到 $\textit{nums}[i-1]$ 中所选元素的乘积。
> - 选 $\textit{nums}[i]$，那么有如下情况可以得到最大实力值：
>   - $\textit{nums}[i]$ 单独一个数作为最大实力值。
>   - 如果 $\textit{nums}[i]$ 是正数，把 $\textit{nums}[i]$ 和前面所选元素值的**最大**乘积相乘。
>   - 如果 $\textit{nums}[i]$ 是负数，由于负负得正，把 $\textit{nums}[i]$ 和前面所选元素值的**最小**乘积相乘。
>
> 具体来说，我们需要在遍历 $\textit{nums}$ 的同时，维护所选元素的最小乘积 $\textit{mn}$ 和最大乘积 $\textit{mx}$。
>
> 无论 $x = \textit{nums}[i]$ 是正是负还是零，$\textit{mn}$ 是以下四种情况的最小值：
>
> - 不选，$\textit{mn}$ 不变。
> - $x$ 单独一个数组成子序列。
> - $\textit{mn}\cdot x$。如果 $x$ 是正数，这可能得到最小乘积。
> - $\textit{mx}\cdot x$。如果 $x$ 是负数，这可能得到最小乘积。
>
> ⚠**注意**：不需要考虑 $\textit{mn}$ 和 $\textit{mx}$ 的正负性，只要取到上述四种情况的最小值，就能保证结果一定是最小的。
>
> 同理，$\textit{mx}$ 是以下四种情况的最大值：
>
> - 不选，$\textit{mx}$ 不变。
> - $x$ 单独一个数组成子序列。
> - $\textit{mn}\cdot x$。如果 $x$ 是负数，这可能得到最大乘积。
> - $\textit{mx}\cdot x$。如果 $x$ 是正数，这可能得到最大乘积。
>
> 整理得
>
> $$
> \begin{aligned}
> \textit{mn} &= \min(\textit{mn}, x, \textit{mn}\cdot x, \textit{mx}\cdot x)    \\
> \textit{mx} &= \max(\textit{mx}, x, \textit{mn}\cdot x, \textit{mx}\cdot x)     \\
> \end{aligned}
> $$
>
> 注意这两个式子要同时计算。
>
> 初始值：$\textit{mn}=\textit{mx} = \textit{nums}[0]$。
>
> 答案：$\textit{mx}$。
>
> ```python
> class Solution:
>     def maxStrength(self, nums: List[int]) -> int:
>         mn = mx = nums[0]
>         for x in nums[1:]:
>             mn, mx = min(mn, x, mn * x, mx * x), \
>                      max(mx, x, mn * x, mx * x)
>         return mx
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。Python 忽略切片空间。
