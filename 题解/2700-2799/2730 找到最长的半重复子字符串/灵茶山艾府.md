# 滑动窗口，简洁写法（Python/Java/C++/Go）

> **[2730. 找到最长的半重复子字符串](https://leetcode.cn/problems/find-the-longest-semi-repetitive-substring/solutions/2304713/shuang-zhi-zhen-hua-chuang-pythonjavacgo-nurf/) · Medium**

> **所属题单**
> - [滑动窗口与双指针 · 二、不定长滑动窗口](../../../刷题路径/灵神原版题单/滑动窗口与双指针/二、不定长滑动窗口.md) · §2.1 越短越合法/求最长/最大 · §2.1.2 进阶（选做）

> **题目描述**
> 给你一个下标从 **0** 开始的字符串 `s` ，这个字符串只包含 `0` 到 `9` 的数字字符。
>
> 如果一个字符串 `t` 中至多有一对相邻字符是相等的，那么称这个字符串 `t` 是 **半重复的** 。例如，`"0010"` 、`"002020"` 、`"0123"` 、`"2002"` 和 `"54944"` 是半重复字符串，而 `"00101022"` （相邻的相同数字对是 00 和 22）和 `"1101234883"` （相邻的相同数字对是 11 和 88）不是半重复字符串。
>
> 请你返回 `s` 中最长 **半重复** 子字符串 的长度。
>
> **示例 1：**
>
> **输入：**`s = "52233"`
>
> **输出：**`4`
>
> **解释：**
>
> 最长的半重复子字符串是 "5223"。整个字符串 "52233" 有两个相邻的相同数字对 22 和 33，但最多只能选取一个。
>
> **示例 2：**
>
> **输入：**`s = "5494"`
>
> **输出：**`4`
>
> **解释：**
>
> `s` 是一个半重复字符串。
>
> **示例 3：**
>
> **输入：**`s = "1111111"`
>
> **输出：**`2`
>
> **解释：**
>
> 最长的半重复子字符串是 "11"。子字符串 "111" 有两个相邻的相同数字对，但最多允许选取一个。
>
> **提示：**
>
> - `1 <= s.length <= 50`
>
> - `'0' <= s[i] <= '9'`

> **题解**
> **前置知识**：[滑动窗口【基础算法精讲 03】](https://www.bilibili.com/video/BV1hd4y1r7Gq/)。
>
> 本题维护的是窗口中的相邻字符相等的次数 $\textit{cnt}$。
>
> 1. $s[\textit{right}]$ 进入窗口，检查 $s[\textit{right}]$ 是否等于 $s[\textit{right}-1]$。如果相等，$\textit{cnt}$ 增加 $1$。
> 2. 如果 $\textit{cnt}>1$，则不断右移左指针 $\textit{left}$ 直到 $\textit{cnt}=1$。$s[\textit{left}]$ 离开窗口前，如果其等于 $s[\textit{left}+1]$，则把 $\textit{cnt}$ 减少 $1$。
> 3. 统计子串长度 $\textit{right}-\textit{left}+1$ 的最大值。
>
> ```python
> class Solution:
>     def longestSemiRepetitiveSubstring(self, s: str) -> int:
>         ans = 1
>         cnt = left = 0
>         for right in range(1, len(s)):
>             if s[right] == s[right - 1]:
>                 cnt += 1
>             while cnt > 1:
>                 if s[left] == s[left + 1]:
>                     cnt -= 1  # left 离开窗口后，和 left+1 断开
>                 left += 1
>             ans = max(ans, right - left + 1)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。注意 $\textit{left}$ 只会增加不会减少，所以二重循环的时间复杂度为 $\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(1)$。
