# 三种方法：从 O(nlogn) 到 O(n)（Python/Java/C++/C/Go/JS/Rust）

> **[2007. 从双倍数组中还原原数组](https://leetcode.cn/problems/find-original-array-from-doubled-array/solutions/2744966/san-chong-fang-fa-cong-onlogn-dao-onpyth-irrt/) · Medium**

> **题目描述**
> 一个整数数组 `original` 可以转变成一个 **双倍** 数组 `changed` ，转变方式为将 `original` 中每个元素 **值乘以 2** 加入数组中，然后将所有元素 **随机打乱** 。
>
> 给你一个数组 `changed` ，如果 `change` 是 **双倍** 数组，那么请你返回 `original`数组，否则请返回空数组。`original` 的元素可以以 **任意** 顺序返回。
>
> **示例 1：**
>
> ```
> 输入：changed = [1,3,4,2,6,8]
> 输出：[1,3,4]
> 解释：一个可能的 original 数组为 [1,3,4] :
> - 将 1 乘以 2 ，得到 1 * 2 = 2 。
> - 将 3 乘以 2 ，得到 3 * 2 = 6 。
> - 将 4 乘以 2 ，得到 4 * 2 = 8 。
> 其他可能的原数组方案为 [4,3,1] 或者 [3,1,4] 。
> ```
>
> **示例 2：**
>
> ```
> 输入：changed = [6,3,0,1]
> 输出：[]
> 解释：changed 不是一个双倍数组。
> ```
>
> **示例 3：**
>
> ```
> 输入：changed = [1]
> 输出：[]
> 解释：changed 不是一个双倍数组。
> ```
>
> **提示：**
>
> - `1 <= changed.length <= 10⁵`
>
> - `0 <= changed[i] <= 10⁵`

> **题解**
> ## 方法一：排序 + 哈希表
>
> 看示例 1，$\textit{changed}=[1,3,4,2,6,8]$，其中最小值为 $1$，它一定不是另一个数乘 $2$ 后的值，所以 $1$ 一定在 $\textit{original}$ 中。由于 $2$ 是由 $1$ 乘 $2$ 得到的，所以 $2$ 不在 $\textit{original}$ 中。
>
> 从 $\textit{changed}$ 中去掉 $1$ 和 $2$，剩下 $[3,4,6,8]$，其中最小值为 $3$，它一定不是另一个数乘 $2$ 后的值，所以 $3$ 一定在 $\textit{original}$ 中。由于 $6$ 是由 $3$ 乘 $2$ 得到的，所以 $6$ 不在 $\textit{original}$ 中。
>
> 从 $\textit{changed}$ 中去掉 $3$ 和 $6$，剩下 $[4,8]$，其中最小值为 $4$，它一定不是另一个数乘 $2$ 后的值，所以 $4$ 一定在 $\textit{original}$ 中。由于 $8$ 是由 $4$ 乘 $2$ 得到的，所以 $8$ 不在 $\textit{original}$ 中。
>
> 于是得到 $\textit{original}=[1,3,4]$。
>
> 根据上述做法，可以得到如下算法：
>
> 1. 为了方便求最小值，把 $\textit{changed}$ 从小到大排序。
> 2. 由于直接从数组中删除元素需要 $\mathcal{O}(n)$ 时间，我们可以改成**标记**哪些元素被删除，这可以用一个 $\textit{cnt}$ 哈希表记录元素及其被标记的次数。
> 3. 遍历排序后的 $\textit{changed}$。
> 4. 如果 $x=\textit{changed}[i]$ 不在 $\textit{cnt}$ 中，说明 $x$ 不是某个元素的两倍，所以 $x$ 在 $\textit{original}$ 中，将 $x$ 加入答案，并标记 $2x$，即 $\textit{cnt}[2x]$ 增加 $1$。注意 $x$ 无需标记，因为后面不会再遍历到 $\textit{changed}[i]$。
> 5. 如果 $x$ 在 $\textit{cnt}$ 中，说明 $x$ 是某个元素的两倍，我们清除一个 $x$ 标记，即 $\textit{cnt}[x]$ 减一。如果减一后 $\textit{cnt}[x]=0$，则从 $\textit{cnt}$ 中删除 $x$。
> 6. 遍历结束后，如果 $\textit{cnt}$ 不为空，说明 $\textit{change}$ 不是双倍数组，返回空数组，否则返回答案列表。
>
> 也可以在遍历中途判断，如果在把 $x$ 添加到 $\textit{ans}$ 之前，$\textit{ans}$ 的长度已经达到 $n/2$，则无法一一配对，返回空数组，见 Java 或 C 代码。
>
> ```python
> class Solution:
>     def findOriginalArray(self, changed: List[int]) -> List[int]:
>         changed.sort()
>         ans = []
>         cnt = Counter()
>         for x in changed:
>             if x not in cnt:  # x 不是双倍后的元素
>                 cnt[x * 2] += 1  # 标记一个双倍元素
>                 ans.append(x)
>             else:  # x 是双倍后的元素
>                 cnt[x] -= 1  # 清除一个标记
>                 if cnt[x] == 0:
>                     del cnt[x]
>         # 只有所有双倍标记都被清除掉，才能说明 changed 是一个双倍数组
>         return [] if cnt else ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 为 $\textit{nums}$ 的长度。瓶颈在排序上。
> - 空间复杂度：$\mathcal{O}(n)$。
>
> ## 方法二：排序 + 队列
>
> 在方法一中，我们是小到大遍历 $x=\textit{changed}[i]$ 的，所以加到哈希表中的 $2x$（双倍标记）也是从小到大的，并且最先加到哈希表中的双倍标记，也会最先清除掉。这种「先进先出」的性质启发我们把哈希表替换成更轻量的**队列**，队首就是下一个等待被清除的双倍标记。
>
> 具体来说，在循环中：
>
> 1. 如果队列为空，把 $x$ 加入答案，把 $2x$ 加入队尾。如果后面遍历到一个等于 $2x$ 的元素，则说明 $x$ 和 $2x$ 都在数组中，配对成功。
> 2. 如果队列不为空，并且队首小于 $x$，由于后面遍历到的数只会更大，所以队首无法配对，返回空数组。
> 3. 如果队列不为空，并且队首等于 $x$，配对成功，弹出队首。
> 4. 如果队列不为空，并且队首大于 $x$，把 $x$ 加入答案，把 $2x$ 加入队尾。
>
> ```python
> class Solution:
>     def findOriginalArray(self, changed: List[int]) -> List[int]:
>         changed.sort()
>         ans = []
>         q = deque()
>         for x in changed:
>             if q:
>                 if q[0] < x:  # 无法配对
>                     return []
>                 if q[0] == x:  # 配对成功
>                     q.popleft()  # 清除一个标记
>                     continue
>             ans.append(x)
>             q.append(x * 2)  # 添加双倍标记
>         # 只有所有双倍标记都被清除掉，才能说明 changed 是一个双倍数组
>         return [] if q else ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 为 $\textit{nums}$ 的长度。瓶颈在排序上。
> - 空间复杂度：$\mathcal{O}(n)$。
>
> ## 方法三：消消乐
>
> 做法类似 [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)。
>
> 时间复杂度的瓶颈在排序上，能否不排序呢？
>
> 举例说明，如果 $\textit{changed}=[1,1,2,2,2,4,8,16,3,6,24,48,9,9,18,18]$，我们把 $x$ 和 $2x$ 都放到同一组内，则可以分为如下四组：
>
> - $1,1,2,2,2,4,8,16$。
> - $3,6$。
> - $24,48$。
> - $9,9,18,18$。
>
> **同一组内的数字，可以一并处理**。
>
> 按照方法一的做法，对于 $1,1,2,2,2,4,8,16$ 这组数字，从 $1$ 开始：
>
> - 用两个 $1$ 消掉两个 $2$，把两个 $1$ 加入答案。
> - 用剩下的一个 $2$ 消掉一个 $4$，把一个 $2$ 加入答案。
> - 用一个 $8$ 消掉一个 $16$，把一个 $8$ 加入答案。
>
> 对于其它的组，我们也只需要从 $3,24,9$ 这些数字开始。
>
> 整理一下思路：
>
> 1. 我们是从一组内的最小数字开始的。换句话说，只要 $\dfrac{x}{2}$ 不在数组中，我们就可以从 $x$ 开始。
> 2. 从 $x$ 开始，通过不断地乘二，找到这一组内的其它数字。
>
> 实现以上两点，完全不需要排序！算法如下：
>
> 1. 用哈希表 $\textit{cnt}$ 统计 $\textit{changed}$ 数组的每个元素的出现次数。
> 2. 遍历 $\textit{cnt}$ 中的元素。
> 3. 设当前遍历到元素 $x$。如果 $x$ 是偶数且 $\dfrac{x}{2}$ 在 $\textit{cnt}$ 中，则跳过。
> 4. 否则，我们可以从 $x$ 开始循环，把 $x,2x,4x,8x,\cdots$ 全部消除（配对）。
> 5. 每次循环，把 $\textit{cnt}[x]$ 个 $x$ 和 $\textit{cnt}[x]$ 个 $2x$ 配对。如果 $x$ 的个数比 $2x$ 的个数还多（或者 $2x$ 不在 $\textit{cnt}$ 中），则无法配对，返回空数组。否则把 $\textit{cnt}[x]$ 个 $x$ 加入答案。然后分类讨论：如果 $\textit{cnt}[x] < \textit{cnt}[2x]$，那么 $\textit{cnt}[2x]$ 减少 $\textit{cnt}[x]$，把 $x$ 乘以 $2$，继续循环；如果 $\textit{cnt}[x] = \textit{cnt}[2x]$，说明 $2x$ 也配对完了，把 $x$ 乘以 $4$，继续循环。
> 6. 最后返回答案。
>
> 注意 $0$ 要单独处理，因为一个 $0$ 可以和其它 $0$ 消除。这意味着 $\textit{changed}$ 中必须要有偶数个 $0$。设 $\textit{changed}$ 中有 $\textit{cnt}_0$ 个 $0$，如果 $\textit{cnt}_0$ 是奇数，返回空数组，否则把 $\dfrac{\textit{cnt}_0}{2}$ 个 $0$ 加入答案。
>
> ```python
> class Solution:
>     def findOriginalArray(self, changed: List[int]) -> List[int]:
>         cnt = Counter(changed)
>         # 单独处理 0
>         cnt0 = cnt.pop(0, 0)
>         if cnt0 % 2:
>             return []
>         ans = [0] * (cnt0 // 2)
>
>         for x in cnt:
>             # 如果 x/2 在 cnt 中，则跳过
>             if x % 2 == 0 and x // 2 in cnt:
>                 continue
>             # 把 x, 2x, 4x, 8x, ... 全部配对
>             while x in cnt:
>                 # 每次循环，把 cnt_x 个 x 和 cnt_x 个 2x 配对
>                 cnt_x = cnt[x]
>                 # 无法配对，至少要有 cnt_x 个 2x
>                 if cnt_x > cnt[x * 2]:
>                     return []
>                 ans.extend([x] * cnt_x)
>                 if cnt_x < cnt[x * 2]:
>                     # 还剩下一些 2x
>                     cnt[x * 2] -= cnt_x
>                     x *= 2
>                 else:
>                     x *= 4
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为 $\textit{nums}$ 的长度。对于内层循环，每次都会把一个 $x$ 加入 $\textit{done}$ 中，这个操作至多执行 $n$ 次（因为至多有 $n$ 个不同的数），所以二重循环的时间复杂度为 $\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(n)$。
>
