# 简单题，简单做。附其他趣味写法（Python/Java/C++/C/Go/JS/Rust）

> **[2011. 执行操作后的变量值](https://leetcode.cn/problems/final-value-of-variable-after-performing-operations/solutions/1005998/go-mo-ni-by-endlesscheng-w4it/) · Easy**

> **题目描述**
> 存在一种仅支持 4 种操作和 1 个变量 `X` 的编程语言：
>
> - `++X` 和 `X++` 使变量 `X` 的值 **加** `1`
>
> - `--X` 和 `X--` 使变量 `X` 的值 **减** `1`
>
> 最初，`X` 的值是 `0`
>
> 给你一个字符串数组 `operations` ，这是由操作组成的一个列表，返回执行所有操作后， `X` 的 **最终值** 。
>
> **示例 1：**
>
> ```
>
> 输入：operations = ["--X","X++","X++"]
> 输出：1
> 解释：操作按下述步骤执行：
> 最初，X = 0
> --X：X 减 1 ，X =  0 - 1 = -1
> X++：X 加 1 ，X = -1 + 1 =  0
> X++：X 加 1 ，X =  0 + 1 =  1
> ```
>
> **示例 2：**
>
> ```
>
> 输入：operations = ["++X","++X","X++"]
> 输出：3
> 解释：操作按下述步骤执行：
> 最初，X = 0
> ++X：X 加 1 ，X = 0 + 1 = 1
> ++X：X 加 1 ，X = 1 + 1 = 2
> X++：X 加 1 ，X = 2 + 1 = 3
> ```
>
> **示例 3：**
>
> ```
>
> 输入：operations = ["X++","++X","--X","X--"]
> 输出：0
> 解释：操作按下述步骤执行：
> 最初，X = 0
> X++：X 加 1 ，X = 0 + 1 = 1
> ++X：X 加 1 ，X = 1 + 1 = 2
> --X：X 减 1 ，X = 2 - 1 = 1
> X--：X 减 1 ，X = 1 - 1 = 0
> ```
>
> **提示：**
>
> - `1 <= operations.length <= 100`
>
> - `operations[i]` 将会是 `"++X"`、`"X++"`、`"--X"` 或 `"X--"`

> **题解**
> 根据题意，对每个操作 $s=\textit{operations}[i]$，如果中间字符 $s[1]$ 是 $\texttt{+}$ 号，把答案加一，否则把答案减一。
>
> ```python
> class Solution:
>     def finalValueAfterOperations(self, operations: List[str]) -> int:
>         return sum(1 if s[1] == '+' else -1 for s in operations)
> ```
>
>
> #### 附：其他趣味写法
>
> ```python
> class Solution:
>     def finalValueAfterOperations(self, operations: List[str]) -> int:
>         return sum(int(s[1] + '1') for s in operations)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{operations}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
