# O(n) 滑动窗口（Python/Java/C++/Go）

> **[2062. 统计字符串中的元音子字符串](https://leetcode.cn/problems/count-vowel-substrings-of-a-string/solutions/1088423/on-shuang-zhi-zhen-xie-fa-by-endlesschen-6dkt/) · Easy**

> **所属题单**
> - [滑动窗口与双指针 · 二、不定长滑动窗口](../../../刷题路径/灵神原版题单/滑动窗口与双指针/二、不定长滑动窗口.md) · §2.3 求子数组个数 · §2.3.2 越长越合法

> **题目描述**
> **子字符串** 是字符串中的一个连续（非空）的字符序列。
>
> **元音子字符串** 是 **仅** 由元音（`'a'`、`'e'`、`'i'`、`'o'` 和 `'u'`）组成的一个子字符串，且必须包含 **全部五种** 元音。
>
> 给你一个字符串 `word` ，统计并返回 `word` 中 **元音子字符串的数目** 。
>
> **示例 1：**
>
> ```
>
> 输入：word = "aeiouu"
> 输出：2
> 解释：下面列出 word 中的元音子字符串（斜体加粗部分）：
> - "aeiouu"
> - "aeiouu"
> ```
>
> **示例 2：**
>
> ```
>
> 输入：word = "unicornarihan"
> 输出：0
> 解释：word 中不含 5 种元音，所以也不会存在元音子字符串。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：word = "cuaieuouac"
> 输出：7
> 解释：下面列出 word 中的元音子字符串（斜体加粗部分）：
> - "cuaieuouac"
> - "cuaieuouac"
> - "cuaieuouac"
> - "cuaieuouac"
> - "cuaieuouac"
> - "cuaieuouac"
> - "cuaieuouac"
> ```
>
> **示例 4：**
>
> ```
>
> 输入：word = "bbaeixoubb"
> 输出：0
> 解释：所有包含全部五种元音的子字符串都含有辅音，所以不存在元音子字符串。
> ```
>
> **提示：**
>
> - `1 <= word.length <= 100`
>
> - `word` 仅由小写英文字母组成

> **题解**
> 先考虑一个简单的情况：$\textit{word}$ 中的字母全是元音。
>
> 做法和 [1358. 包含所有三种字符的子字符串数目](https://leetcode.cn/problems/number-of-substrings-containing-all-three-characters/) 是一样的，请先完成这题。[我的题解](../../1300-1399/1358%20包含所有三种字符的子字符串数目/灵茶山艾府.md)。
>
> 本题 $\textit{word}$ 中有辅音，并且要求**子串只包含元音**。
>
> 我们可以在遍历 $\textit{word}$ 的同时，维护子串的最小左端点 $\textit{start}$（初始值为 $0$）。当遍历到辅音 $\textit{word}[i]$ 时，更新 $\textit{start} = i + 1$，表示后续子串的左端点不能小于 $i+1$，否则子串包含辅音 $\textit{word}[i]$，不满足要求。于是，当子串右端点固定时，满足要求的子串左端点的范围是 $[\textit{start},\textit{left}-1]$，这有 $\textit{left}-\textit{start}$ 个，加到答案中。
>
> ```python
> class Solution:
>     def countVowelSubstrings(self, word: str) -> int:
>         cnt = defaultdict(int)
>         ans = start = left = 0
>
>         for i, ch in enumerate(word):
>             if ch not in "aeiou":
>                 cnt.clear()  # 重置
>                 start = left = i + 1
>                 continue
>
>             # 做法类似 1358. 包含所有三种字符的子字符串数目（哈希表写法）
>             cnt[ch] += 1
>             while len(cnt) == 5:  # 窗口包含所有元音
>                 out = word[left]
>                 cnt[out] -= 1
>                 if cnt[out] == 0:
>                     del cnt[out]
>                 left += 1
>             ans += left - start
>
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$ 或 $\mathcal{O}(n|\Sigma|)$，其中 $n$ 是 $\textit{word}$ 的长度，$|\Sigma|=5$ 是元音种类数。
> - 空间复杂度：$\mathcal{O}(|\Sigma|)$。
>
