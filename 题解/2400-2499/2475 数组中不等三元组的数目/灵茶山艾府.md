# 两种非暴力做法：排序 / 哈希表

> **[2475. 数组中不等三元组的数目](https://leetcode.cn/problems/number-of-unequal-triplets-in-array/solutions/1981413/fei-bao-li-zuo-fa-by-endlesscheng-9ekp/) · Easy**

> **题目描述**
> 给你一个下标从 **0** 开始的正整数数组 `nums` 。请你找出并统计满足下述条件的三元组 `(i, j, k)` 的数目：
>
> - `0 <= i < j < k < nums.length`
>
> - `nums[i]`、`nums[j]` 和 `nums[k]` **两两不同** 。
>
>     - 换句话说：`nums[i] != nums[j]`、`nums[i] != nums[k]` 且 `nums[j] != nums[k]` 。
>
> 返回满足上述条件三元组的数目<em>。</em>
>
> **示例 1：**
>
> ```
>
> 输入：nums = [4,4,2,4,3]
> 输出：3
> 解释：下面列出的三元组均满足题目条件：
> - (0, 2, 4) 因为 4 != 2 != 3
> - (1, 2, 4) 因为 4 != 2 != 3
> - (2, 3, 4) 因为 2 != 4 != 3
> 共计 3 个三元组，返回 3 。
> 注意 (2, 0, 4) 不是有效的三元组，因为 2 > 0 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums = [1,1,1,1,1]
> 输出：0
> 解释：不存在满足条件的三元组，所以返回 0 。
> ```
>
> **提示：**
>
> - `3 <= nums.length <= 100`
>
> - `1 <= nums[i] <= 1000`

> # 方法一：排序 + 分组统计
>
> 对于 $x$，设：
>
> - 小于 $x$ 的数有 $a$ 个；
> - 等于 $x$ 的数有 $b$ 个；
> - 大于 $x$ 的数有 $c$ 个。
>
> 那么 $x$ 对答案的贡献是 $abc$。
>
> 累加所有贡献，得到答案。
>
> 代码实现时，通过排序可以快速求出 $a\ b\ c$。
>
> ```python
> class Solution:
>     def unequalTriplets(self, nums: List[int]) -> int:
>         nums.sort()
>         ans = start = 0
>         for i, (x, y) in enumerate(pairwise(nums)):
>             if x != y:
>                 ans += start * (i - start + 1) * (len(nums) - 1 - i)
>                 start = i + 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(n\log n)$，其中 $n$ 为 $\textit{nums}$ 的长度。
> - 空间复杂度：$O(1)$，忽略排序时的栈开销，仅用到若干变量。
>
> # 方法二：利用对称性
>
> 由于元素的位置是不重要的，我们可以直接用哈希表统计，方法一中的 $a\ b\ c$ 重定义为：
>
> - 在 $x$ 之前遍历过的数有 $a$ 个；
> - （当前遍历的）等于 $x$ 的数有 $b$ 个；
> - 在 $x$ 之后遍历过的数有 $c$ 个。
>
> ```python
> class Solution:
>     def unequalTriplets(self, nums: List[int]) -> int:
>         ans, a, c = 0, 0, len(nums)
>         for b in Counter(nums).values():
>             c -= b
>             ans += a * b * c
>             a += b
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 为 $\textit{nums}$ 的长度。
> - 空间复杂度：$O(n)$。
