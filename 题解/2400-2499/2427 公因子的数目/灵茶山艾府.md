# 计算 gcd(a,b) 的因子（Python/Java/C++/Go）

> **[2427. 公因子的数目](https://leetcode.cn/problems/number-of-common-factors/solutions/1864071/mei-ju-yin-zi-by-endlesscheng-v3fb/) · Easy · 难度分 1172**

> **所属题单**
> - [数学算法 · 一、数论](../../../刷题路径/灵神原版题单/数学算法/一、数论.md) · §1.5 因子

> **题目描述**
> 给你两个正整数 `a` 和 `b` ，返回 `a` 和 `b` 的 **公** 因子的数目。
>
> 如果 `x` 可以同时整除 `a` 和 `b` ，则认为 `x` 是 `a` 和 `b` 的一个 **公因子** 。
>
> **示例 1：**
>
> ```
> 输入：a = 12, b = 6
> 输出：4
> 解释：12 和 6 的公因子是 1、2、3、6 。
> ```
>
> **示例 2：**
>
> ```
> 输入：a = 25, b = 30
> 输出：2
> 解释：25 和 30 的公因子是 1、5 。
> ```
>
> **提示：**
>
> - `1 <= a, b <= 1000`

> **题解**
> ### 视频讲解
>
> 见[【周赛 313】](https://www.bilibili.com/video/BV1kd4y1q7fC)
>
> ### 思路
>
> 枚举因子，挨个判断能否整除 $a$ 和 $b$。
>
> 改进方案是枚举 $a$ 和 $b$ 的最大公因数的因子。
>
> ```python
> class Solution:
>     def commonFactors(self, a: int, b: int) -> int:
>         g = gcd(a, b)
>         ans, i = 0, 1
>         while i * i <= g:
>             if g % i == 0:
>                 ans += 1  # i 是公因子
>                 if i * i < g:
>                     ans += 1  # g/i 是公因子
>             i += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(\sqrt{\min(a,b)})$。
> - 空间复杂度：$O(1)$，仅用到若干变量。
