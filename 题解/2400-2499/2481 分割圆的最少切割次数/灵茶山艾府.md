# 根据对称性作答

> **[2481. 分割圆的最少切割次数](https://leetcode.cn/problems/minimum-cuts-to-divide-a-circle/solutions/1993055/gen-ju-dui-cheng-xing-zuo-da-by-endlessc-bzv7/) · Easy**

> **题目描述**
> 圆内一个 **有效切割** ，符合以下二者之一：
>
> - 该切割是两个端点在圆上的线段，且该线段经过圆心。
>
> - 该切割是一端在圆心另一端在圆上的线段。
>
> 一些有效和无效的切割如下图所示。
>
> ![](../../_assets/灵茶山艾府/e3a00c250676684c.png)
>
> 给你一个整数 `n` ，请你返回将圆切割成相等的 `n` 等分的 **最少** 切割次数。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/d75d4dc7a8cd43b6.png)
>
> ```
>
> 输入：n = 4
> 输出：2
> 解释：
> 上图展示了切割圆 2 次，得到四等分。
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/89bc3dfcc0449f89.png)
>
> ```
>
> 输入：n = 3
> 输出：3
> 解释：
> 最少需要切割 3 次，将圆切成三等分。
> 少于 3 次切割无法将圆切成大小相等面积相同的 3 等分。
> 同时可以观察到，第一次切割无法将圆切割开。
> ```
>
> **提示：**
>
> - `1 <= n <= 100`

> **题解**
> **反证法**见 [视频讲解](https://www.bilibili.com/video/BV1uG4y157Rc)，欢迎点赞三连，在评论区分享你对这场双周赛的看法~
>

>
> 根据对称性：
>
> - $n$ 为偶数时，每一块扇形都有对称的扇形，所以是切割 $\dfrac{n}{2}$ 次；
> - $n$ 为奇数时，不存在对称性，所以是切割 $n$ 次。
>
> 注意 $n=1$ 时无需切割。
>
> ```python
> class Solution:
>     def numberOfCuts(self, n: int) -> int:
>         return n if n > 1 and n % 2 else n // 2
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(1)$。
> - 空间复杂度：$O(1)$，仅用到若干变量。
