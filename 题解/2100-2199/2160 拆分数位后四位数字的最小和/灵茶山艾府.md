#  贪心 + 排序

> **[2160. 拆分数位后四位数字的最小和](https://leetcode.cn/problems/minimum-sum-of-four-digit-number-after-splitting-digits/solutions/1247103/tan-xin-pai-xu-by-endlesscheng-dkq1/) · Easy · 难度分 1314**

> **所属题单**
> - [贪心算法 · 四、数学贪心](../../../刷题路径/灵神原版题单/贪心算法/四、数学贪心.md) · §4.1 基础

> **题目描述**
> 给你一个四位 **正** 整数 `num` 。请你使用 `num` 中的 **数位** ，将 `num` 拆成两个新的整数 `new1` 和 `new2` 。`new1` 和 `new2` 中可以有 **前导 0** ，且 `num` 中 **所有** 数位都必须使用。
>
> - 比方说，给你 `num = 2932` ，你拥有的数位包括：两个 `2` ，一个 `9` 和一个 `3` 。一些可能的 `[new1, new2]` 数对为 `[22, 93]`，`[23, 92]`，`[223, 9]` 和 `[2, 329]` 。
>
> 请你返回可以得到的 `new1` 和 `new2` 的 **最小** 和。
>
> **示例 1：**
>
> ```
> 输入：num = 2932
> 输出：52
> 解释：可行的 [new1, new2] 数对为 [29, 23] ，[223, 9] 等等。
> 最小和为数对 [29, 23] 的和：29 + 23 = 52 。
> ```
>
> **示例 2：**
>
> ```
> 输入：num = 4009
> 输出：13
> 解释：可行的 [new1, new2] 数对为 [0, 49] ，[490, 0] 等等。
> 最小和为数对 [4, 9] 的和：4 + 9 = 13 。
> ```
>
> **提示：**
>
> - `1000 <= num <= 9999`

> **题解**
> 通过比对可以发现，拆分成两位数 + 两位数是最优的。因此要使 $\textit{new1}+\textit{new2}$ 最小，应当最小化十位数字。
>
> 我们可以将 $\textit{num}$ 的字符串形式从小到大排序，那么前两个数字为十位数，后两个数字为个位数。
