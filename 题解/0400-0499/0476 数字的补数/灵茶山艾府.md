# 库函数写法（Python/Java/C++/C/Go/JS/Rust）

> **[476. 数字的补数](https://leetcode.cn/problems/number-complement/solutions/1054733/go-yi-xing-by-endlesscheng-bzua/) · Easy**

> **所属题单**
> - [位运算 · 一、基础题](../../../刷题路径/灵神原版题单/位运算/一、基础题.md)

> **题目描述**
> 对整数的二进制表示取反（`0` 变 `1` ，`1` 变 `0`）后，再转换为十进制表示，可以得到这个整数的补数。
>
> - 例如，整数 `5` 的二进制表示是 `"101"` ，取反后得到 `"010"` ，再转回十进制表示得到补数 `2` 。
>
> 给你一个整数 `num` ，输出它的补数。
>
> **示例 1：**
>
> ```
>
> 输入：num = 5
> 输出：2
> 解释：5 的二进制表示为 101（没有前导零位），其补数为 010。所以你需要输出 2 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：num = 1
> 输出：0
> 解释：1 的二进制表示为 1（没有前导零位），其补数为 0。所以你需要输出 0 。
> ```
>
> **提示：**
>
> - `1 <= num < 2³¹`
>
> **注意：**本题与 1009 [https://leetcode.cn/problems/complement-of-base-10-integer/](https://leetcode.cn/problems/complement-of-base-10-integer/) 相同

> **题解**
> 题目让我们把 $\textit{num}$ 取反。
>
> 例如二进制 $\textit{num}=11001$，取反后是 $00110$，即十进制的 $6$。
>
> 看上去，计算 `~num` 就好了？
>
> 但这样做会把更高位的 $0$ 也取反，对于 $32$ 位整数来说，$11001$ 实际是 $00000000000000000000000000011001$，取反后是 $11111111111111111111111111100110$。
>
> 所以对于这个例子，要只把 $\textit{num}$ 的低 $5$ 位取反，也就是计算 $\textit{num}$ 和 $11111$ 的异或。
>
> $11111$ 怎么算？设 $w=5$ 是 $\textit{num}$ 的二进制长度，计算 `1 << w` 可以得到 $100000$，再减去 $1$，得到 $11111$。
>
> ```python
> class Solution:
>     def findComplement(self, num: int) -> int:
>         w = num.bit_length()
>         return ((1 << w) - 1) ^ num
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
