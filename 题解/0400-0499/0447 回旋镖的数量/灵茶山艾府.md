# 简洁写法，附相似题目（Python/Java/C++/Go/JS/Rust）

> **[447. 回旋镖的数量](https://leetcode.cn/problems/number-of-boomerangs/solutions/2595488/jian-ji-xie-fa-fu-xiang-si-ti-mu-pythonj-39p8/) · Medium**

> **题目描述**
> 给定平面上 `n` 对 **互不相同** 的点 `points` ，其中 `points[i] = [x_i, y_i]` 。**回旋镖** 是由点 `(i, j, k)` 表示的元组 ，其中 `i` 和 `j` 之间的欧式距离和 `i` 和 `k` 之间的欧式距离相等（**需要考虑元组的顺序**）。
>
> 返回平面上所有回旋镖的数量。
>
> **示例 1：**
>
> ```
>
> 输入：points = [[0,0],[1,0],[2,0]]
> 输出：2
> 解释：两个回旋镖为 [[1,0],[0,0],[2,0]] 和 [[1,0],[2,0],[0,0]]
> ```
>
> **示例 2：**
>
> ```
>
> 输入：points = [[1,1],[2,2],[3,3]]
> 输出：2
> ```
>
> **示例 3：**
>
> ```
>
> 输入：points = [[1,1]]
> 输出：0
> ```
>
> **提示：**
>
> - `n == points.length`
>
> - `1 <= n <= 500`
>
> - `points[i].length == 2`
>
> - `-10⁴ <= x_i, y_i <= 10⁴`
>
> - 所有点都 **互不相同**

> **题解**
> 枚举「中间」的点 $i$，然后统计有多少对 $j$ 和 $k$，满足点 $i$ 到点 $j$ 的欧式距离等于点 $i$ 到点 $k$ 的欧式距离。
>
> 两个点 $i,j$ 的欧式距离的平方为
>
> $$
> d_2(i,j) = (x_i-x_j)^2 + (y_i-y_j)^2
> $$
>
> 我们需要统计，在 $i$ 固定时，有多少对 $j$ 和 $k$，满足
>
> $$
> d_2(i,j) = d_2(i,k)
> $$
>
> 外层循环枚举点 $i$，内层循环枚举点 $j$，同时用哈希表 $\textit{cnt}$ 维护 $d_2(i,j)$ 的出现次数。
>
> 例如示例 1，固定点 $i=(1,0)$，枚举点 $j=(0,0)$，把 $d_2(i,j) = 1$ 的出现次数加入 $\textit{cnt}$，即 $\textit{cnt}[1]$ 增加一次。然后枚举到 $j=(2,0)$，由于 $d_2(i,j)$ 也是 $1$，这意味着前面遍历到的 $(0,0)$ 可以作为 $k$，和 $j$ 组合，由于题目规定 $(j,k)$ 和 $(k,j)$ 是不同的，所以这有 $2$ 个元组满足要求，加入答案。
>
> 一般地，在枚举 $j$ 时，先把 $2\cdot \textit{cnt}[d_2(i,j)]$ 加入答案，然后把 $\textit{cnt}[d_2(i,j)]$ 加一。
>
> 注意，由于所有点互不相同，当 $j=i$ 时，$d_2(i,j) = 0$，并且只会出现一次，所以对答案的影响为 $0$，所以无需保证 $j\ne i$。
>
> ```python
> class Solution:
>     def numberOfBoomerangs(self, points: List[List[int]]) -> int:
>         ans = 0
>         for x1, y1 in points:
>             cnt = defaultdict(int)
>             for x2, y2 in points:
>                 d2 = (x1 - x2) ** 2 + (y1 - y2) ** 2
>                 ans += cnt[d2] * 2
>                 cnt[d2] += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 为 $\textit{points}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
