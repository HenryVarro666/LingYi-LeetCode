# 两种 DFS 写法（Python/Java/C++/C/Go/JS/Rust）

> **[404. 左叶子之和](https://leetcode.cn/problems/sum-of-left-leaves/solutions/3751068/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-w8st/) · Easy**

> **所属题单**
> - [链表、二叉树与回溯 · 二、二叉树](../../../刷题路径/灵神原版题单/链表、二叉树与回溯/二、二叉树.md) · §2.1 遍历二叉树

> **题目描述**
> 给定二叉树的根节点 `root` ，返回所有左叶子之和。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/7863ad5da8533b05.jpg)
>
> ```
>
> 输入: root = [3,9,20,null,null,15,7]
> 输出: 24
> 解释: 在这个二叉树中，有两个左叶子，分别是 9 和 15，所以返回 24
> ```
>
> **示例 2:**
>
> ```
>
> 输入: root = [1]
> 输出: 0
> ```
>
> **提示:**
>
> - 节点数在 `[1, 1000]` 范围内
>
> - `-1000 <= Node.val <= 1000`

> **题解**
> ## 写法一
>
> 在遍历二叉树的过程中，如果当前节点的左儿子是叶子，即**左儿子的左右儿子均为空**，那么把左儿子的节点值加到答案中。
>
> 晕递归的同学，请先看视频：[深入理解递归【基础算法精讲 09】](https://www.bilibili.com/video/BV1UD4y1Y769/)。
>
> ```python
> class Solution:
>     def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
>         def dfs(node: Optional[TreeNode]) -> None:
>             if node is None:
>                 return
>
>             # 递归，寻找左叶子
>             dfs(node.left)
>             dfs(node.right)
>
>             left = node.left  # 当前节点的左儿子
>             if left and left.left is None and left.right is None:  # 当前节点的左儿子是叶子
>                 nonlocal ans
>                 ans += left.val  # 累加节点值
>
>         ans = 0
>         dfs(root)
>         return ans
> ```
>
>
> ## 写法二
>
> 直接把 $\texttt{sumOfLeftLeaves}$ 当作递归函数使用。
>
> ```python
> class Solution:
>     def sumOfLeftLeaves(self, root: TreeNode) -> int:
>         if root is None:  # 空节点
>             return 0
>
>         # 递归左右子树，收集左右子树中的「节点的左儿子是叶子」的叶子节点值之和
>         ans = self.sumOfLeftLeaves(root.left) + self.sumOfLeftLeaves(root.right)
>
>         left = root.left  # 当前节点的左儿子
>         if left and left.left is None and left.right is None:  # 当前节点的左儿子是叶子
>             ans += left.val  # 累加节点值
>
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是二叉树的节点个数。
> - 空间复杂度：$\mathcal{O}(h)$，其中 $h$ 是二叉树的高度。递归需要 $\mathcal{O}(h)$ 的栈空间。
