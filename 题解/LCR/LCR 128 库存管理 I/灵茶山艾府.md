# 二分查找，一个视频讲透！（Python/Java/C++/Go）

> **[LCR 128. 库存管理 I](https://leetcode.cn/problems/xuan-zhuan-shu-zu-de-zui-xiao-shu-zi-lcof/solutions/2134912/er-fen-cha-zhao-yi-ge-shi-pin-jiang-tou-1kbvh/) · Easy**

> **题目描述**
> 仓库管理员以数组 `stock` 形式记录商品库存表。`stock[i]` 表示商品 `id`，可能存在重复。原库存表按商品 `id` 升序排列。现因突发情况需要进行商品紧急调拨，管理员将这批商品 `id` 提前依次整理至库存表最后。请你找到并返回库存表中编号的 **最小的元素** 以便及时记录本次调拨。
>
> **示例 1：**
>
> ```
>
> 输入：stock = [4,5,8,3,4]
> 输出：3
> ```
>
> **示例 2：**
>
> ```
>
> 输入：stock = [5,7,9,1,2]
> 输出：1
> ```
>
> 提示：
>
> - 1 <= stock.length <= 5000
>
> - -5000 <= stock[i] <= 5000
>
> 注意：本题与主站 154 题相同：[https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii/](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii/)

> **题解**
> 首先你需要完成 153 题，可以看我的[【基础算法精讲 05】](https://www.bilibili.com/video/BV1QK411d76w/)和 [这篇题解](../../0100-0199/0153%20寻找旋转排序数组中的最小值/灵茶山艾府.md)。
>
> 本题与 153 的区别在于有相同元素，这会导致在二分查找时，可能会遇到「恰好」二分元素与数组末尾元素相同的情况，此时无法确定答案在左半区间还是右半区间。
>
> 我们接着 [153 题解](../../0100-0199/0153%20寻找旋转排序数组中的最小值/灵茶山艾府.md) 的代码来实现。本题需要稍加修改，改为与区间右端点处的元素比较（如果你写的是闭区间的话，那就是与右端点 $+1$ 的元素比较）。
>
> 当二分元素 $\textit{nums}[\textit{mid}]$ 与区间右端点元素相同时，既然无法确定最小值所在区间，那么干脆去掉右端点元素，继续二分。对应到代码上，就是 $\textit{right}$ 减一。
>
> 你可能会有疑问：这样做不会碰巧把最小值给去掉吗？
>
> 这是不会的：
>
> - 如果右端点元素就是最小值，那么 $\textit{nums}[\textit{mid}]$ 也是最小值，说明最小值仍然在二分区间中；
> - 如果右端点元素不是最小值，这样做相当于排除了一个错误答案。
>
> 下面的代码用的开区间写法，如果你想了解其它写法，可以看我的[【基础算法精讲 04】](https://www.bilibili.com/video/BV1AP41137w7/)，一个视频讲透二分。
>
> ```python
> class Solution:
>     def stockManagement(self, nums: List[int]) -> int:
>         left, right = -1, len(nums) - 1  # 开区间 (-1, n-1)
>         while left + 1 < right:  # 开区间不为空
>             mid = (left + right) // 2
>             if nums[mid] < nums[right]:  # 蓝色
>                 right = mid
>             elif nums[mid] > nums[right]:  # 红色
>                 left = mid
>             else:
>                 right -= 1
>         return nums[right]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 为 $\textit{nums}$ 的长度。最坏情况下，数组元素均相同，循环内会一直执行 $\textit{right}$ 减一，此时循环会执行 $O(n)$ 次。
> - 空间复杂度：$O(1)$，仅用到若干额外变量。
