# BFS 为什么要用队列？一个视频讲透！（Python/Java/C++/Go）

> **[LCR 045. 找树左下角的值](https://leetcode.cn/problems/LwUNpT/solutions/2064635/bfs-wei-shi-yao-yao-yong-dui-lie-yi-ge-s-loh4/) · Medium**

> **题目描述**
> 给定一个二叉树的 **根节点** `root`，请找出该二叉树的 **最底层 最左边** 节点的值。
>
> 假设二叉树中至少有一个节点。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/337aa5c4efba8684.jpg)
>
> ```
>
> 输入: root = [2,1,3]
> 输出: 1
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/44b47aca8df1686b.jpg)
>
> ```
>
> 输入: [1,2,3,4,null,5,6,null,null,7]
> 输出: 7
> ```
>
> **提示：**
>
> - 二叉树的节点个数的范围是 `[1,10⁴]`
>
> - `-2³¹ <= Node.val <= 2³¹ - 1`
>
> 注意：本题与主站 513 题相同： [https://leetcode.cn/problems/find-bottom-left-tree-value/](https://leetcode.cn/problems/find-bottom-left-tree-value/)

> **题解**
> 视频讲解：[【基础算法精讲 13】](https://www.bilibili.com/video/BV1hG4y1277i/)，制作不易，欢迎点赞~
>
> ```python
> class Solution:
>     def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
>         q = deque([root])
>         while q:
>             node = q.popleft()
>             if node.right: q.append(node.right)
>             if node.left:  q.append(node.left)
>         return node.val
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 为二叉树的节点个数。
> - 空间复杂度：$O(n)$。满二叉树（每一层都填满）最后一层有大约 $n/2$ 个节点，因此队列中最多有 $O(n)$ 个元素，所以空间复杂度是 $O(n)$ 的。
