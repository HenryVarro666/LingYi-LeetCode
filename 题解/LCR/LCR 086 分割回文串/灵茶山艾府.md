# 回溯不会写？套路在此！（Python/Java/C++/Go/JS/Rust）

> **[LCR 086. 分割回文串](https://leetcode.cn/problems/M99OJA/solutions/2156948/hui-su-bu-hui-xie-tao-lu-zai-ci-pythonja-q1yu/) · Medium**

> **题目描述**
> 给定一个字符串 `s` ，请将 `s` 分割成一些子串，使每个子串都是 **回文串** ，返回 s 所有可能的分割方案。
>
> **回文串** 是正着读和反着读都一样的字符串。
>
> **示例 1：**
>
> ```
>
> 输入：s = "google"
> 输出：[["g","o","o","g","l","e"],["g","oo","g","l","e"],["goog","l","e"]]
> ```
>
> **示例 2：**
>
> ```
>
> 输入：s = "aab"
> 输出：[["a","a","b"],["aa","b"]]
> ```
>
> **示例 3：**
>
> ```
>
> 输入：s = "a"
> 输出：[["a"]]
> ```
>
> **提示：**
>
> - `1 <= s.length <= 16`
>
> - `s `仅由小写英文字母组成
>
> 注意：本题与主站 131 题相同： [https://leetcode.cn/problems/palindrome-partitioning/](https://leetcode.cn/problems/palindrome-partitioning/)
