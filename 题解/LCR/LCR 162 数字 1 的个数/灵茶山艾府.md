# 数位 DP 通用模板，附题单（Python/Java/C++/Go）

> **[LCR 162. 数字 1 的个数](https://leetcode.cn/problems/1nzheng-shu-zhong-1chu-xian-de-ci-shu-lcof/solutions/2681837/shu-wei-dp-tong-yong-mo-ban-fu-ti-dan-py-rsw2/) · Hard**

> **题目描述**
> 给定一个整数 `num`，计算所有小于等于 `num` 的非负整数中数字 `1` 出现的个数。
>
> **示例 1：**
>
> ```
>
> 输入：num = 0
> 输出：0
> ```
>
> **示例 2：**
>
> ```
>
> 输入：num = 13
> 输出：6
> ```
>
> **提示：**
>
> - `0 <= num < 10⁹`
>
> 注意：本题与主站 233 题相同：[https://leetcode.cn/problems/number-of-digit-one/](https://leetcode.cn/problems/number-of-digit-one/)

> **题解**
> 请看 [视频讲解](https://www.bilibili.com/video/BV1rS4y1s721/?t=20m05s)。
>
> 下文把 $\textit{num}$ 记作 $n$。
>
> 将 $n$ 转换成字符串 $s$，定义 $f(i,\textit{cnt}_1, \textit{isLimit})$ 表示构造到从左往右第 $i$ 位，已经出现了 $\textit{cnt}_1$ 个 $1$，在这种情况下，继续构造最终会得到的 $1$ 的个数（你可以直接从回溯的角度理解这个过程，只不过是多了个记忆化）。
>
> 其余参数的含义为：
>
> - $\textit{cnt}_1$ 表示左边填了多少个 $1$。
> - $\textit{isLimit}$ 表示当前是否受到了 $n$ 的约束（我们要构造的数字不能超过 $\textit{n}$）。若为真，则第 $i$ 位填入的数字至多为 $\textit{n}[i]$，否则至多为 $9$，这个数记作 $\textit{hi}$。如果在受到约束的情况下填了 $\textit{n}[i]$，那么后续填入的数字仍会受到 $\textit{n}$ 的约束。例如 $\textit{n}=123$，那么 $i=0$ 填的是 $1$ 的话，$i=1$ 的这一位至多填 $2$。
>
> 递归边界：当所有数字填完时，返回 $\textit{cnt}_1$。
>
> 递归入口：$f(0,0,\texttt{true})$，一开始没有填数字，并且会受到 $n$ 的约束。
>
> #### 答疑
>
> **问**：记忆化三个状态有点麻烦，可以不记录 $\textit{isLimit}$ 吗？
>
> **答**：可以。想一想 $\textit{isLimit}=\texttt{true}$ 只在什么情况下成立？只在我们填入的数字都等于 $n$ 对应位置的数字时成立。比如 $\textit{n}=234$，第一位填 $2$，第二位填 $3$，此时 $\textit{isLimit}=\texttt{true}$。但我们不会再次递归到第一位填 $2$，第二位填 $3$ 的情况，记忆化这样的状态是没有意义的。
>
> 根据这个例子，我们可以只记录不受到 $n$ 约束时的状态 $(i, \textit{cnt}_1)$。相当于记忆化的是 $(i,\textit{cnt}_1,\texttt{false})$ 这个状态。比如 $\textit{n}=234$，第一位填 $1$，第二位填 $2$，或者第一位填 $2$，第二位填 $1$，都会递归到 $(2,1,\texttt{false})$ 这个状态，那么第二次递归到这个状态时，就可以直接返回第一次递归记忆化的结果了。
>
> ```python
> class Solution:
>     def digitOneInNumber(self, n: int) -> int:
>         s = str(n)
>         @cache
>         def f(i: int, cnt1: int, is_limit: bool) -> int:
>             if i == len(s):
>                 return cnt1
>             res = 0
>             up = int(s[i]) if is_limit else 9
>             for d in range(up + 1):  # 枚举要填入的数字 d
>                 res += f(i + 1, cnt1 + (d == 1), is_limit and d == up)
>             return res
>         return f(0, 0, True)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(m^2D)$，其中 $m=\mathcal{O}(\log n)$，$D=10$。由于每个状态只会计算一次，动态规划的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题状态个数等于 $\mathcal{O}(m^2)$，单个状态的计算时间为 $\mathcal{O}(D)$，所以动态规划的时间复杂度为 $\mathcal{O}(m^2D)$。
> - 空间复杂度：$\mathcal{O}(m^2)$。即状态个数。
