# 【视频】一写就错？请看这！（Python/Java/C++/Go/JS/Rust）

> **[LCR 167. 招式拆解 I](https://leetcode.cn/problems/zui-chang-bu-han-zhong-fu-zi-fu-de-zi-zi-fu-chuan-lcof/solutions/2181636/yi-xie-jiu-cuo-qing-kan-zhe-pythonjavacg-31u3/) · Medium**

> **题目描述**
> 某套连招动作记作序列 `arr`，其中 `arr[i]` 为第 `i` 个招式的名字。请返回 `arr` 中最多可以出连续不重复的多少个招式。
>
> **示例 1：**
>
> ```
>
> 输入：arr = "dbascDdad"
> 输出：6
> 解释：因为连续且最长的招式序列是 "dbascD" 或 "bascDd"，所以其长度为 6。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：arr = "KKK"
> 输出：1
> 解释：因为无重复字符的最长子串是 "K"，所以其长度为 1。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：arr = "pwwkew"
> 输出：3
> 解释：因为连续且最长的招式序列是 "wke"，所以其长度为 3。
> 请注意区分 子串 与 子序列 的概念：你的答案必须是 连续招式 的长度，也就是 子串。而 "pwke" 是一个非连续的 子序列，不是 子串。
> ```
>
> **提示：**
>
> - `0 <= arr.length <= 40000`
>
> - `arr` 由英文字母、数字、符号和空格组成。
>
> 注意：本题与主站 3 题相同：[https://leetcode.cn/problems/longest-substring-without-repeating-characters/](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

> **题解**
> ## 视频讲解
>
> 请看 [滑动窗口【基础算法精讲】](https://www.bilibili.com/video/BV1hd4y1r7Gq/)，制作不易，欢迎点赞！
>
> ```python
> class Solution:
>     def dismantlingAction(self, arr: str) -> int:
>         ans = left = 0
>         window = set()  # 维护从下标 left 到下标 right 的字符
>         for right, c in enumerate(arr):
>             while c in window:  # 加入 c 后，窗口内会有重复元素
>                 window.remove(arr[left])
>                 left += 1  # 缩小窗口
>             window.add(c)
>             ans = max(ans, right - left + 1)  # 更新窗口长度最大值
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 为 $s$ 的长度。注意 $\textit{left}$ 至多增加 $n$ 次，所以整个二重循环至多循环 $O(n)$ 次。
> - 空间复杂度：$O(|\Sigma|)$，其中 $|\Sigma|$ 为字符集合的大小，本题中字符均为 ASCII 字符，所以 $|\Sigma|\le 128$。
