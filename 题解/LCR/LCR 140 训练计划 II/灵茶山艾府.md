# 【视频讲解】前后指针（Python/Java/C++/Go/JS）

> **[LCR 140. 训练计划 II](https://leetcode.cn/problems/lian-biao-zhong-dao-shu-di-kge-jie-dian-lcof/solutions/2372853/shi-pin-jiang-jie-qian-hou-zhi-zhen-pyth-xptk/) · Easy**

> **题目描述**
> 给定一个头节点为 `head` 的链表用于记录一系列核心肌群训练项目编号，请查找并返回倒数第 `cnt` 个训练项目编号对应的节点。
>
> **示例 1：**
>
> ```
>
> 输入：head = [2,4,7,8], cnt = 1
> 输出：8
> ```
>
> **提示：**
>
> - `1 <= head.length <= 100`
>
> - `0 <= head[i] <= 100`
>
> - `1 <= cnt <= head.length`

> **题解**
> ## 视频讲解
>
> 请看[【基础算法精讲 08】](https://www.bilibili.com/video/BV1VP4y1Q71e/)，制作不易，欢迎点赞~
>
> ```python
> class Solution:
>     def trainingPlan(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
>         left = right = head
>         for _ in range(k):
>             right = right.next  # 右指针先向右走 k 步
>         # 然后左右指针一起走，右指针走到空节点时，左指针正好就在倒数第 k 个节点
>         while right:
>             left = left.next
>             right = right.next
>         return left
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为链表的长度。
> - 空间复杂度：$\mathcal{O}(1)$，仅用到若干额外变量。
