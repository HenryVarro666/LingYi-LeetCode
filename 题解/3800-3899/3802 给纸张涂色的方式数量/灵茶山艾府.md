# 排序+相向双指针，O(1) 空间（Python/Java/C++/Go）

> **[3802. 给纸张涂色的方式数量](https://leetcode.cn/problems/number-of-ways-to-paint-sheets/solutions/3873932/pai-xu-xiang-xiang-shuang-zhi-zhen-o1-ko-o6yz/) · Hard**

> **所属题单**
> - [滑动窗口与双指针 · 三、单序列双指针](../../../刷题路径/灵神原版题单/滑动窗口与双指针/三、单序列双指针.md) · §3.2 相向双指针

> **题解**
> 为方便描述，把 $\textit{limit}$ 简称为 $a$。
>
> 问题相当于：
>
> - 先从 $a$ 中选出两个下标不同的元素 $(a_i,a_j)$，满足 $a_i+a_j\ge n$。
> - 再选两个数 $x$ 和 $y$，满足：
>     - $1\le x\le a_i$。
>     - $1\le y\le a_j$。
>     - $x+y=n$。
>     - 联立得 $\max(n-a_j,1)\le x\le \min(a_i,n-1)$。
>
> 根据对称性，我们可以先计算 $i<j$ 时的方案数，再乘以 $2$，即为答案。
>
> 为方便计算，把 $a$ 每一项与 $n-1$ 取最小值，然后从小到大排序。上面的约束化简为
>
> $$
> n-a_j\le x\le a_i
> $$
>
> 相向双指针枚举 $i$ 和 $j$，初始值 $i=0$，$j=|a|-1$。
>
> - 如果 $a_i + a_j < n$，那么 $a_i$ 与其他更小的 $a_j$ 也无法满足要求，所以 $a_i$ 没用，去掉，把 $i$ 加一。
> - 如果 $a_i+a_j\ge n$，那么 $a_j$ 也可以与 $a_i,a_{i+1},\ldots,a_{j-1}$ 满足相加 $\ge n$ 的要求。
>     - 现在问题变成，对于下标在 $[i,j-1]$ 中的每个 $a_k$，计算满足 $n-a_j\le x\le a_k$ 的 $x$ 的个数。
>     - 拆分成 $[1,a_k]$ 中的 $x$ 的个数，也就是 $a_k$，减去 $[1,n-a_j-1]$ 中的 $x$ 的个数，也就是 $n-a_j-1$。
>     - 累加，结果为下标在 $[i,j-1]$ 中的 $a_k$ 之和，减去 $(n-a_j-1)\cdot (j-i)$。
>     - 算完后把 $j$ 减一。 
>
> 所以要额外维护子数组 $[i,j-1]$ 的元素和 $s$。
>
> 代码实现时，注意取模。为什么可以在**中途取模**？原理见 [模运算的世界：当加减乘除遇上取模](https://leetcode.cn/circle/discuss/mDfnkW/)。
>
> ```python
> class Solution:
>     def numberOfWays(self, n: int, a: List[int]) -> int:
>         MOD = 1_000_000_007
>         for i in range(len(a)):
>             a[i] = min(a[i], n - 1)
>         a.sort()
>
>         ans = 0
>         s = sum(a)
>         i, j = 0, len(a) - 1
>         while i < j:
>             if a[i] + a[j] < n:
>                 s -= a[i]
>                 i += 1
>             else:
>                 s -= a[j]
>                 ans += s - (n - a[j] - 1) * (j - i)
>                 j -= 1
>         return ans * 2 % MOD
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{limit}$ 的长度。瓶颈在排序上。
> - 空间复杂度：$\mathcal{O}(1)$。忽略排序的栈开销。
