# 遍历（Python/Java/C++/Go）

> **[3861. 容量最小的箱子](https://leetcode.cn/problems/minimum-capacity-box/solutions/3917789/bian-li-pythonjavacgo-by-endlesscheng-i70n/) · Easy**

> **题目描述**
> 给你一个整数数组 `capacity`，其中 `capacity[i]` 表示第 `i` 个箱子的容量，以及一个整数 `itemSize`，表示一个物品的大小。
>
> 如果第 `i` 个箱子的容量满足 `capacity[i] >= itemSize`，那么该箱子可以存放该物品。
>
> 要求返回可以存放该物品的容量 **最小** 的箱子的下标。如果有多个这样的箱子，返回下标 **最小** 的一个。
>
> 如果没有任何箱子可以存放该物品，则返回 -1。
>
> **示例 1：**
>
> **输入：** `capacity = [1,5,3,7], itemSize = 3`
>
> **输出：** `2`
>
> **解释：**
>
> 下标为 2 的箱子容量为 3，是可以存放该物品的容量最小的箱子，因此答案是 2。
>
> **示例 2：**
>
> **输入：** `capacity = [3,5,4,3], itemSize = 2`
>
> **输出：** `0`
>
> **解释：**
>
> 可以存放该物品的最小容量为 3，出现在下标 0 和 3。由于下标 0 更小，因此答案是 0。
>
> **示例 3：**
>
> **输入：** `capacity = [4], itemSize = 5`
>
> **输出：** `-1`
>
> **解释：**
>
> 没有任何箱子的容量足够存放该物品，因此答案是 -1。
>
> **提示：**
>
> - `1 <= capacity.length <= 100`
>
> - `1 <= capacity[i] <= 100`
>
> - `1 <= itemSize <= 100`

> **题解**
> 从左到右遍历 $\textit{capacity}$ 的过程中，维护满足要求的最小容量，及其对应的下标。
>
> 下午两点 [B站@灵茶山艾府](https://space.bilibili.com/206214) 直播讲题，欢迎关注~
>
> ```python
> class Solution:
>     def minimumIndex(self, capacity: List[int], itemSize: int) -> int:
>         min_c = inf
>         ans = -1
>         for i, c in enumerate(capacity):
>             if itemSize <= c < min_c:
>                 min_c = c
>                 ans = i
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{capacity}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
