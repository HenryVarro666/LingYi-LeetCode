# O(1) 一行代码（Python/Java/C++/Go）

> **[3827. 统计单比特整数](https://leetcode.cn/problems/count-monobit-integers/solutions/3893641/o1-yi-xing-dai-ma-pythonjavacgo-by-endle-ew9k/) · Easy**

> **所属题单**
> - [位运算 · 一、基础题](../../../刷题路径/灵神原版题单/位运算/一、基础题.md)

> **题目描述**
> 给你一个整数 `n`。
>
> 如果一个整数的二进制表示中所有位都相同，则称其为 **单比特数**（**Monobit**）。
>
> 返回范围`[0, n]`（包括两端）内 **单比特数** 的个数。
>
> **示例 1：**
>
> **输入：** `n = 1`
>
> **输出：** `2`
>
> **解释：**
>
> - 范围`[0, 1]`内的整数对应的二进制表示为`"0"`和`"1"`。
>
> - 每个表示都由相同的位组成，因此答案是2。
>
> **示例 2：**
>
> **输入：** `n = 4`
>
> **输出：** `3`
>
> **解释：**
>
> - 范围`[0, 4]`内的整数对应的二进制表示为`"0"`、`"1"`、`"10"`、`"11"`和`"100"`。
>
> - 只有`0`、`1`和`3`满足单比特条件。因此答案是3。
>
> **提示：**
>
> - `0 <= n <= 1000`

> **题解**
> 非负整数 $x$ 二进制的所有位都相同，意味着 $x = 0$ 或者 $x$ 的二进制全为 $1$，即 $x = 2^k - 1$，其中 $k$ 是非负整数。
>
> 问题变成求 $[0,n]$ 中有多少个 $2^k - 1$，或者说有多少个不同的 $k$。
>
> $0\le 2^k -1 \le n$ 即 $1\le 2^k\le n+1$。
>
> 解得 $0\le k\le w-1$，其中 $w$ 是 $n+1$ 的二进制长度。比如 $n+1 = 10110$，二进制长度为 $5$，那么 $2^k\le 10000$，所以 $k\le 4$。
>
> 所以有 $w$ 个不同的 $k$。
>
> [本题视频讲解](https://www.bilibili.com/video/BV1hd64BcEBQ/)，欢迎点赞关注~
>
> ```python
> class Solution:
>     def countMonobit(self, n: int) -> int:
>         return (n + 1).bit_length()
> ```
>
>
