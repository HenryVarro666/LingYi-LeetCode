## 题目描述

给你一个只包含 0、1 和 2 的整数数组 `nums`。

如果 `nums[i] == 1` 且 `nums[j] == 2`，则称下标对 `(i, j)` 为 **有效** 的。

请返回所有有效下标对中 `i` 和 `j` 之间的 **最小** 绝对差。如果不存在有效下标对，则返回 -1。

下标 `i` 和 `j` 之间的绝对差定义为 `abs(i - j)`。

**示例 1：**

**输入：** `nums = [1,0,0,2,0,1]`

**输出：** `2`

**解释：**

有效下标对有：

- (0, 3)，其绝对差为 `abs(0 - 3) = 3`。

- (5, 3)，其绝对差为 `abs(5 - 3) = 2`。

因此，结果是 2。

**示例 2：**

**输入：** `nums = [1,0,1,0]`

**输出：** `-1`

**解释：**

数组中不存在有效下标对，因此结果是 -1。

**提示：**

- `1 <= nums.length <= 100`

- `0 <= nums[i] <= 2`
