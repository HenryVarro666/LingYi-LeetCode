3888.使所有网格元素相等的最小操作次数

<https://leetcode.cn/problems/minimum-operations-to-make-all-grid-elements-equal/description/>

题目给出一个大小为m \* n的二维整数数组grid，以及一个整数k。

在一次操作中，可以选择grid中任意k \* k的子矩阵，并将这个子矩阵中的所有元素都加上1。

问使得网格中所有元素相等所需的最少操作次数。若无法达成，则返回-1。

不妨设最终将矩阵中的所有元素都变成了target，那么：

- 首先对于(0, 0)，只能通过修改以(0, 0)为左上角，边长为k的子矩阵，才能使得(0, 0)这个单元格的元素产生变化
- 接下来对于(0, 1)，这个单元格可能受以(0, 0)为左上角，边长为k的子矩阵的影响，也可能不受其影响。无论哪种，想要在这个基础上修正grid[0][1]，就只能修改以(0, 1)为左上角，边长为k的子矩阵
- 以此类推，也就是说需要从上到下，从左到右，一个一个单元格修正过来

更具体的，对于处于(i, j)的单元格，可以圈出来一个左上角在(i - k + 1, j - k + 1)，右下角在(i, j)的边长为k的子矩阵。对于这个子矩阵中的所有单元格，一旦进行过修正，这次修正就会影响到(i, j)这个单元格。

更进一步的，只需计算出之前这些修正值之和，就可以计算出如何修正(i, j)，才能使得grid[i][j]变成target。对于修正值之和的计算，是一个非常典型的二维前缀和问题，不过与常规的二维前缀和不同，在这里需要先计算出修正值矩阵到(i, j)为止的前缀和数组，然后计算出以(i - k + 1, j - k + 1)为左上角，(i, j)为右下角的修正值子矩阵之和，再通过这个和计算出当前单元格的修正值，最后再用这个修正值来更新这个到(i, j)为止的前缀和。

也就是说，按照上述步骤一个个单元格计算，就可以对每个单元格得到一个等式，有些等式包含target，这些等式将限定target的下界，甚至直接确定唯一可能的target。有些等式则只包含数字，对于这些等式则只需要确保有解就行了。

接下来以样例1为例。

首先修正(0, 0)。这个单元格比较简单，只需要加上target - 3。

接下来修正(0, 1)。这个单元格受到了(0, 0)的影响，实际上当前单元格的值就是target - 3 + 3 \= target，无需修正。

接下来修正(0, 2)。这个单元格受到了(0, 1)的影响，但是(0, 1)没有被修正过，所需需要将这个单元格修正成target。但是需要注意的是，这个单元格处于边界地带，也就是不存在可用的以(0, 2)为左上角，边长为2的子矩阵，也就是说无法主动修正这个单元格，即target在这里已经被限定在了5。

接下来修正(1, 0)。这个单元格受到了(0, 0)的影响，实际上当前单元格的值就是target - 3 + 3 \= target，无需修正。

接下来修正(1, 1)。这个单元格受到了(0, 0)、(0, 1)、(1, 0)的影响，但是后面两个单元格都没有修正，实际上这个单元格的值就是target - 3 + 3 \= target，无需修正。

最后是(1, 2)。这个单元格受到了(0, 1)、(0, 2)、(1, 1)的影响，这三个单元格都没有修正过，因此这个单元格的值还是5。另一方面，这个单元格是处于边界地带，不可以主动修正，因此target必须与单元格的值相同。此时单元格的值也恰好为5，符合之前确定的target，没有产生矛盾。

遍历完成，得到了最优的target为5，接下来只需计算矩阵中全为target的总和，减去原始矩阵的总和，除以k \* k，即为最终答案。

举个更复杂的例子，例如k \= 2，矩阵为

7 5 7

5 1 5

7 5 7

这个矩阵操作后最终的结果是将所有元素都变为9，那么按照以上的步骤，得到的修正值分别为：

- (0, 0)：target - 7
- (0, 1)：target - (target - 7 + 5) \= 2
- (0, 2)：target - (7 + 2) \= target - 9。注意到(0, 2)是不能主动修正的，因此已经确定了target \= 9
- (1, 0)：target - (target - 7 + 5) \= 2
- (1, 1)：target - (target - 7 + 2 + 2 + 1) \= 2
- (1, 2)：target - (2 + 0 + 2 + 5) \= target - 9。(1, 2)是不能主动修正的，而之前已经确定了target \= 9，这里没有出现矛盾
- (2, 0)：target - (2 + 9) \= target - 9。(2, 0)是不能主动修正的，但这里也没有出现矛盾
- (2, 1)：target - (2 + 2 + 0 + 5) \= taregt - 9。(2, 1)是不能主动修正的，但这里也没有出现矛盾
- (2, 2)：target - (2 + 0 + 0 + 7) \= target - 9。(2, 2)是不能主动修正的，但这里也没有出现矛盾

因此得到了target为9，而得到的修正值矩阵为

[target - 7, 2, 0]

[2, 2, 0]

[0, 0, 0]

接下来考察哪些单元格的修正值包含了target，哪些没有。

首先可以确定的是，(0, 0)的修正值一定包含了target，而在(0, 0)的作用下，所有在以(0, 0)为左上角，(k - 1, k - 1)为右下角中的其他单元格，都因为受到了(0, 0)的修正，其主动修正的修正值中必然是不带target的。由于是按照从上到下从左右到的顺序修正的，因此带target的下一个单元格是(0, k)，然后是(0, 2k)，以此类推。接下来则是(k, 0)，(k, k)，...,（2k, 0)，(2k, k), ...

另一方面，对于第0行的单元格，只有(0, 0)到(0, n // k \* k - 1)这些单元格符合上面的推断，而对于(0, n // k \* k)这个单元格，其处于边界地带，即不存在以(0, n // k \* k)为左上角，边长为k的子矩阵，因此不能主动修正这些单元格，这些单元格的修正值也会带着target。

确定了target的系数后，还需要想办法计算出修正常数。

由于在这个过程中需要计算修正值子矩阵之和，因此在这里需要使用二维前缀和来进行优化。具体来说，使用数组f表示二维前缀和，即f[x][y]表示以(1, 1)为左上角，(x, y)为右下角的修正值矩阵之和。这里的下标从1开始，方便计算。需要注意，由于修正值中是否包含target可以直接通过下标为止确定，因此在这里只需要记录常数的修正值就行了。

对于单元格(i, j)，其对应到的修正值矩阵，就是以(i - k + 2, j - k + 2)为左上角，(i + 1, j + 1)为右下角的修正值子矩阵。

不过在此之前，需要先计算得到f[i + 1][j + 1]，因为目前还没有得到(i, j)的修正值，也就是没有填充修正子矩阵中(i + 1,j + 1)这个单元格的值，也就是说还没有计算过f[i + 1][j + 1]。因此首先，需要通过f[i + 1][j] + f[i][j + 1] - f[i][j]计算f[i + 1][j + 1]。

接下来，通过f[i + 1][j + 1] - f[i - k + 1][j + 1] - f[i + 1][j - k + 1] + f[i - k + 1][j - k + 1]计算出影响到(i, j)的修正子矩阵之和v，然后就可以计算出当前单元格目前的真实值，即v + grid[i][j]，那么修正值d就是-v - grid[i][j]。

得到了target的系数以及修正值之后，就可以通过二者的关系，以及(i, j)所处的位置，来检测修正值是否合法，或者限定target的界，甚至唯一确定target。

最后附上python代码：

```python
class Solution(object):
    def minOperations(self, grid, k):
        """
        :type grid: List[List[int]]
        :type k: int
        :rtype: int
        """
        

        m = len(grid)
        n = len(grid[0])

        f = [[0] * (n + 2) for _ in range(m + 2)]

        mi = max([max(row) for row in grid])
        target = None
        for i in range(m):
            for j in range(n):
                x2, y2 = i + 1, j + 1
                x1 = max(0, x2 - k)
                y1 = max(0, y2 - k)

                f[x2][y2] = f[x2][y2 - 1] + f[x2 - 1][y2] - f[x2 - 1][y2 - 1]
                v = f[x2][y2] - f[x1][y2] - f[x2][y1] + f[x1][y1]
                d = -v - grid[i][j]

                if (i % k > 0 or j  % k > 0) and i < m // k * k and j < n // k * k:    
                    if d < 0:
                        return -1

                    if i + k <= m and j + k <= n:
                        f[x2][y2] += d
                    elif d != 0:
                        return -1
                
                elif i + k <= m and j + k <= n:
                    mi = max(mi, -d)
                    f[x2][y2] += d
                elif target is None:
                    target = -d
                elif target != -d:
                    return -1

        if target is None:
            target = mi
        elif target < mi:
            return -1
        
        tot = 0
        for i in range(m):
            for j in range(n):
                tot += target - grid[i][j]
        
        return tot // (k * k)
```
