# O(n) 一次遍历（Python/Java/C++/Go）

> **[3833. 统计主导元素下标数](https://leetcode.cn/problems/count-dominant-indices/solutions/3898742/on-yi-ci-bian-li-pythonjavacgo-by-endles-lda5/) · Easy**

> **题目描述**
> 给你一个长度为 `n` 的整数数组 `nums`。
>
> 当下标 `i` 满足以下条件时，该下标处的元素被称为 **主导元素**：`nums[i] > average(nums[i + 1], nums[i + 2], ..., nums[n - 1])`
>
> 你的任务是统计数组中 **主导元素** 的下标数。
>
> **平均值** 是指一组数的总和除以该组数的个数得到的值。
>
> **注意**：数组的 **最右边元素** 不算作 **主导元素** 。
>
> **示例 1：**
>
> **输入：** `nums = [5,4,3]`
>
> **输出：** `2`
>
> **解释：**
>
> - 在下标 `i = 0` 处，值 5 是主导元素，因为 `5 > average(4, 3) = 3.5`。
>
> - 在下标 `i = 1` 处，值 4 是主导元素，相对于子数组 `[3]`。
>
> - 下标 `i = 2` 不是主导元素，因为它右侧没有元素。因此答案是 2。
>
> **示例 2：**
>
> **输入：** `nums = [4,1,2]`
>
> **输出：** `1`
>
> **解释：**
>
> - 在下标 `i = 0` 处，值 4 是主导元素，相对于子数组 `[1, 2]`。
>
> - 在下标 `i = 1` 处，值 1 不是主导元素。
>
> - 下标 `i = 2` 不是主导元素，因为它右侧没有元素。因此答案是 1。
>
> **提示：**
>
> - `1 <= nums.length <= 100`
>
> - `1 <= nums[i] <= 100`​​​​​​​

> **题解**
> 倒着遍历 $\textit{nums}$，用一个变量 $\textit{sufSum}$ 维护后缀 $[i+1,n-1]$ 的元素和。
>
> 如果发现 $\textit{nums}[i]\cdot(n-1-i) > \textit{sufSum}$，那么答案加一。
>
> 下午两点 [B站@灵茶山艾府](https://space.bilibili.com/206214) 直播讲题，欢迎关注~
>
> ```python
> class Solution:
>     def dominantIndices(self, nums: List[int]) -> int:
>         n = len(nums)
>         suf_sum = ans = 0
>         for i in range(n - 2, -1, -1):
>             suf_sum += nums[i + 1]
>             if nums[i] * (n - 1 - i) > suf_sum:
>                 ans += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
