# 分类讨论（Python/Java/C++/Go）

> **[3894. 交通信号灯的颜色](https://leetcode.cn/problems/traffic-signal-color/solutions/3949841/fen-lei-tao-lun-pythonjavacgo-by-endless-n0t1/) · Easy**

> **题目描述**
> 给你一个整数 `timer`，表示交通信号灯上的剩余时间（以秒为单位）。
>
> 信号灯遵循以下规则：
>
> - 如果 `timer == 0`，信号灯为 `"Green"`
>
> - 如果 `timer == 30`，信号灯为 `"Orange"`
>
> - 如果 `30 < timer <= 90`，信号灯为 `"Red"`
>
> 返回信号灯的当前状态。如果均不满足上述条件，返回 `"Invalid"`。
>
> **示例 1：**
>
> **输入：** `timer = 60`
>
> **输出：** `"Red"`
>
> **解释：**
>
> 因为 `timer = 60`，且 `30 < timer <= 90`，所以答案是 `"Red"`。
>
> **示例 2：**
>
> **输入：** `timer = 5`
>
> **输出：** `"Invalid"`
>
> **解释：**
>
> 因为 `timer = 5`，不满足任何给定的条件，所以答案是 `"Invalid"`。
>
> **提示：**
>
> - `0 <= timer <= 1000`

> **题解**
> 题目怎么说，我们就怎么做。
>
> 下午两点 [B站@灵茶山艾府](https://space.bilibili.com/206214) 直播讲题，欢迎关注~
>
> ```python
> class Solution:
>     def trafficSignal(self, timer: int) -> str:
>         if timer == 0:
>             return "Green"
>         if timer == 30:
>             return "Orange"
>         if 30 < timer <= 90:
>             return "Red"
>         return "Invalid"
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
