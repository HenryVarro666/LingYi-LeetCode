# 一次遍历，简洁写法（Python/Java/C++/Go/JS/Rust）

> **[349. 两个数组的交集](https://leetcode.cn/problems/intersection-of-two-arrays/solutions/3053420/yi-ci-bian-li-pythonjavacgojsrust-by-end-jstx/) · Easy**

> **题目描述**
> 给定两个数组 `nums1` 和 `nums2` ，返回 <em>它们的 交集</em> 。输出结果中的每个元素一定是 **唯一** 的。我们可以 **不考虑输出结果的顺序** 。
>
> **示例 1：**
>
> ```
>
> 输入：nums1 = [1,2,2,1], nums2 = [2,2]
> 输出：[2]
> ```
>
> **示例 2：**
>
> ```
>
> 输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
> 输出：[9,4]
> 解释：[4,9] 也是可通过的
> ```
>
> **提示：**
>
> - `1 <= nums1.length, nums2.length <= 1000`
>
> - `0 <= nums1[i], nums2[i] <= 1000`

> **题解**
> ## 核心思路
>
> 遍历 $\textit{nums}_2$ 的每个数，如果 $\textit{nums}_2[i]$ 在 $\textit{nums}_1$ 中，并且 $\textit{nums}_2[i]$ 不在答案列表中，则加入答案列表。
>
> ## 优化
>
> 1. 把 $\textit{nums}_1$ 中的元素都加到哈希集合 $\textit{st}$ 中，这样可以 $\mathcal{O}(1)$ 判断 $\textit{nums}_2[i]$ 在不在 $\textit{nums}_1$ 中。
> 2. 为了保证答案列表中没有重复元素，在 $\textit{nums}_2[i]$ 加入答案列表的同时，把 $\textit{nums}_2[i]$ 从哈希集合 $\textit{st}$ 中去掉，这样后面遍历到相同的元素时，由于其不在 $\textit{st}$ 中，所以不会加入答案列表。
>
> 这样可以做到**一次遍历**：$\textit{nums}_1$ 和 $\textit{nums}_2$ 都只遍历了一次，并且也没有额外遍历答案列表。
>
> ```python
> # 注意这样写不是一次遍历，请看右边的【一次遍历】写法
> class Solution:
>     def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
>         return list(set(nums1) & set(nums2))
> ```
>
> > [!example]- Py3 一次遍历
> > ```python
> > class Solution:
> >     def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
> >         st = set(nums1)
> >         ans = []
> >         for x in nums2:
> >             if x in st:
> >                 st.remove(x)
> >                 ans.append(x)
> >         return ans
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n+m)$，其中 $n$ 是 $\textit{nums}_1$ 的长度，$m$ 是 $\textit{nums}_2$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。注：可以把长度小的数组转成哈希集合，这样可以做到 $\mathcal{O}(\min(n,m))$ 的空间复杂度。
