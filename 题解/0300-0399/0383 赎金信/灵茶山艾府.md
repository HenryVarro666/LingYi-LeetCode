# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[383. 赎金信](https://leetcode.cn/problems/ransom-note/solutions/3643383/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-nh3q/) · Easy**

> **所属题单**
> - [面试经典 150 题 · 哈希表](../../../刷题路径/灵神原版题单/面试经典%20150%20题/哈希表.md)

> **题目描述**
> 给你两个字符串：`ransomNote` 和 `magazine` ，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。
>
> 如果可以，返回 `true` ；否则返回 `false` 。
>
> `magazine` 中的每个字符只能在 `ransomNote` 中使用一次。
>
> **示例 1：**
>
> ```
>
> 输入：ransomNote = "a", magazine = "b"
> 输出：false
> ```
>
> **示例 2：**
>
> ```
>
> 输入：ransomNote = "aa", magazine = "ab"
> 输出：false
> ```
>
> **示例 3：**
>
> ```
>
> 输入：ransomNote = "aa", magazine = "aab"
> 输出：true
> ```
>
> **提示：**
>
> - `1 <= ransomNote.length, magazine.length <= 10⁵`
>
> - `ransomNote` 和 `magazine` 由小写英文字母组成

> **题解**
> **题意**：判断 $\textit{ransomNote}$ 中的每种字母的出现次数，是否都小于或等于 $\textit{magazine}$ 中的每种字母的出现次数。
>
> 我们可以遍历字符串，用哈希表或者数组 $\textit{cnt}$ 统计每种字母的出现次数之差：
>
> - 对于 $\textit{magazine}$ 中的字母 $c$，每次遇到 $c$ 就把 $\textit{cnt}[c]$ 加一。
> - 对于 $\textit{ransomNote}$ 中的字母 $c$，每次遇到 $c$ 就把 $\textit{cnt}[c]$ 减一。
>
> 如果对于每个 $c$ 都有 $\textit{cnt}[c]\ge 0$，说明 $\textit{ransomNote}$ 中的每种字母的出现次数，都小于或等于 $\textit{magazine}$ 中的每种字母的出现次数，返回 $\texttt{true}$，否则返回 $\texttt{false}$。
>
> 如果 $\textit{ransomNote}$ 的长度比 $\textit{magazine}$ 还长，那么一定无法满足要求，可以提前特判这种情况，无需遍历字符串，返回 $\texttt{false}$。
>
> ```python
> class Solution:
>     def canConstruct(self, ransomNote: str, magazine: str) -> bool:
>         return Counter(ransomNote) <= Counter(magazine)
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def canConstruct(self, ransomNote: str, magazine: str) -> bool:
> >         if len(ransomNote) > len(magazine):
> >             return False
> >         cnt = defaultdict(int)
> >         for c in magazine:
> >             cnt[c] += 1
> >         for c in ransomNote:
> >             cnt[c] -= 1
> >         return all(c >= 0 for c in cnt.values())
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(m)$ 或者 $\mathcal{O}(m + |\Sigma|)$，其中 $m$ 是 $\textit{magazine}$ 的长度，$|\Sigma|=26$ 是字符集合的大小。注意创建大小为 $|\Sigma|$ 的数组需要 $\mathcal{O}(|\Sigma|)$ 的时间。
> - 空间复杂度：$\mathcal{O}(|\Sigma|)$。
