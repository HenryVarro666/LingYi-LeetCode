# 枚举右，维护左（Python/Java/C++/C/Go/JS/Rust）

> **[1128. 等价多米诺骨牌对的数量](https://leetcode.cn/problems/number-of-equivalent-domino-pairs/solutions/3661647/mei-ju-you-wei-hu-zuo-pythonjavaccgojsru-me3c/) · Easy**

> **题目描述**
> 给你一组多米诺骨牌 `dominoes` 。
>
> 形式上，`dominoes[i] = [a, b]` 与 `dominoes[j] = [c, d]` **等价** 当且仅当 (`a == c` 且 `b == d`) 或者 (`a == d` 且 `b == c`) 。即一张骨牌可以通过旋转 `0` 度或 `180` 度得到另一张多米诺骨牌。
>
> 在 `0 <= i < j < dominoes.length` 的前提下，找出满足 `dominoes[i]` 和 `dominoes[j]` 等价的骨牌对 `(i, j)` 的数量。
>
> **示例 1：**
>
> ```
>
> 输入：dominoes = [[1,2],[2,1],[3,4],[5,6]]
> 输出：1
> ```
>
> **示例 2：**
>
> ```
>
> 输入：dominoes = [[1,2],[1,2],[1,1],[1,2],[2,2]]
> 输出：3
> ```
>
> **提示：**
>
> - `1 <= dominoes.length <= 4 * 10⁴`
>
> - `dominoes[i].length == 2`
>
> - `1 <= dominoes[i][j] <= 9`

> **题解**
> 如果要求 $a=c$ 且 $b=d$，那么问题统计的是 $\textit{dominoes}[i] = \textit{dominoes}[j]$ 的个数，这和 [1512. 好数对的数目](https://leetcode.cn/problems/number-of-good-pairs/) 是一样的。
>
> 本题还可以旋转，也就是交换 $\textit{dominoes}[i][0]$ 和 $\textit{dominoes}[i][1]$。
>
> 例如 $[1,2]$ 和 $[2,1]$ 这两个骨牌，我们可以旋转 $[2,1]$ 得到 $[1,2]$，所以 $[1,2]$ 和 $[2,1]$ **本质上是相等的**。
>
> 对于每个 $\textit{dominoes}[i]=[a,b]$，如果 $a > b$，我们就交换 $a$ 和 $b$，从而保证 $a\le b$。这样就可以用 [1512. 好数对的数目](https://leetcode.cn/problems/number-of-good-pairs/) 题的算法了。**注**：这个思路和 [49. 字母异位词分组](../../0000-0099/0049%20字母异位词分组/灵茶山艾府.md) 是一样的，如果两个骨牌在排序后相等，那么就是一对符合题目要求的骨牌对。
>
> 实现细节：可以用哈希表 $\textit{cnt}$ 存储 $\textit{dominoes}[i]$ 的出现次数，也可以利用 $\textit{dominoes}[i][j] \le 9$ 的性质，用 $10\times 10$ 的数组存储 $\textit{dominoes}[i]$ 的出现次数。
>
> **问**：为什么代码要先更新答案，再更新 $\textit{cnt}$？
>
> **答**：本题要求 $i<j$，如果先更新 $\textit{cnt}$，再更新答案，就把 $\textit{dominoes}[j]$ 自己也统计进来了，相当于把 $i=j$ 的情况也认为是好数对。
>
> ```python
> class Solution:
>     def numEquivDominoPairs(self, dominoes: List[List[int]]) -> int:
>         ans = 0
>         cnt = defaultdict(int)
>         for d in dominoes:
>             d = tuple(sorted(d))  # 只有两个数，排序是 O(1) 的
>             ans += cnt[d]
>             cnt[d] += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{dominoes}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
