# 遍历（Python/Java/C++/C/Go/JS/Rust）

> **[1184. 公交站间的距离](https://leetcode.cn/problems/distance-between-bus-stops/solutions/2915481/bian-li-pythonjavaccgojsrust-by-endlessc-te4r/) · Easy**

> **题目描述**
> 环形公交路线上有 `n` 个站，按次序从 `0` 到 `n - 1` 进行编号。我们已知每一对相邻公交站之间的距离，`distance[i]` 表示编号为 `i` 的车站和编号为 `(i + 1) % n` 的车站之间的距离。
>
> 环线上的公交车都可以按顺时针和逆时针的方向行驶。
>
> 返回乘客从出发点 `start` 到目的地 `destination` 之间的最短距离。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/4791ca88eb2fd0b5.jpg)
>
> ```
> 输入：distance = [1,2,3,4], start = 0, destination = 1
> 输出：1
> 解释：公交站 0 和 1 之间的距离是 1 或 9，最小值是 1。
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/1f97acdd3777cb8e.jpg)
>
> ```
> 输入：distance = [1,2,3,4], start = 0, destination = 2
> 输出：3
> 解释：公交站 0 和 2 之间的距离是 3 或 7，最小值是 3。
> ```
>
> **示例 3：**
>
> ![](../../_assets/灵茶山艾府/b4bc29b744b55081.jpg)
>
> ```
> 输入：distance = [1,2,3,4], start = 0, destination = 3
> 输出：4
> 解释：公交站 0 和 3 之间的距离是 6 或 4，最小值是 4。
> ```
>
> **提示：**
>
> - `1 <= n <= 10^4`
>
> - `distance.length == n`
>
> - `0 <= start, destination < n`
>
> - `0 <= distance[i] <= 10^4`

> **题解**
> 为简化描述，把 $\textit{start}$ 记作 $s$，把 $\textit{destination}$ 记作 $t$。不妨设 $s\le t$（如果 $s>t$ 则交换 $s$ 和 $t$）。
>
> 从 $s$ 到 $t$，可以按照 $s,s+1,s+2,\cdots,t$ 的顺序行驶。
>
> 设距离为 $d_1$，那么有
>
> $$
> d_1 = \textit{distance}[s] + \textit{distance}[s+1] + \cdots + \textit{distance}[t-1]
> $$
>
> 也可以按照 $s,s-1,s-2,\cdots,1,0,n-1,n-2,\cdots,t$ 的顺序行驶，其距离等价于从 $0$ 到 $s$ 的距离，加上从 $t$ 到 $n-1$ 的距离，设其为 $d_2$。
>
> 二者取最小值，即为答案。
>
> > 注：$d_2$ 也等于 $\textit{distance}$ 的元素和减去 $d_1$。
>
> ```python
> class Solution:
>     def distanceBetweenBusStops(self, distance: List[int], s: int, t: int) -> int:
>         if s > t:
>             s, t = t, s
>         d1 = sum(distance[s: t])
>         return min(d1, sum(distance) - d1)
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def distanceBetweenBusStops(self, distance: List[int], s: int, t: int) -> int:
> >         if s > t:
> >             s, t = t, s
> >         return min(sum(distance[s: t]), sum(distance[:s]) + sum(distance[t:]))
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{distance}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。忽略切片空间。
>
