# 冰雹猜想，记忆化搜索（Python/Java/C++/Go/JS）

> **[1387. 将整数按权重排序](https://leetcode.cn/problems/sort-integers-by-the-power-value/solutions/3011028/bing-bao-cai-xiang-ji-yi-hua-sou-suo-pyt-q5iz/) · Medium · 难度分 1507**

> **题目描述**
> 我们将整数 `x` 的 **权重** 定义为按照下述规则将 `x` 变成 `1` 所需要的步数：
>
> - 如果 `x` 是偶数，那么 `x = x / 2`
>
> - 如果 `x` 是奇数，那么 `x = 3 * x + 1`
>
> 比方说，x=3 的权重为 7 。因为 3 需要 7 步变成 1 （3 --> 10 --> 5 --> 16 --> 8 --> 4 --> 2 --> 1）。
>
> 给你三个整数 `lo`， `hi` 和 `k` 。你的任务是将区间 `[lo, hi]` 之间的整数按照它们的权重 **升序排序** ，如果大于等于 2 个整数有 **相同** 的权重，那么按照数字自身的数值 **升序排序** 。
>
> 请你返回区间 `[lo, hi]` 之间的整数按权重排序后的第 `k` 个数。
>
> 注意，题目保证对于任意整数 `x` `（lo <= x <= hi）` ，它变成 `1` 所需要的步数是一个 32 位有符号整数。
>
> **示例 1：**
>
> ```
>
> 输入：lo = 12, hi = 15, k = 2
> 输出：13
> 解释：12 的权重为 9（12 --> 6 --> 3 --> 10 --> 5 --> 16 --> 8 --> 4 --> 2 --> 1）
> 13 的权重为 9
> 14 的权重为 17
> 15 的权重为 17
> 区间内的数按权重排序以后的结果为 [12,13,14,15] 。对于 k = 2 ，答案是第二个整数也就是 13 。
> 注意，12 和 13 有相同的权重，所以我们按照它们本身升序排序。14 和 15 同理。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：lo = 7, hi = 11, k = 4
> 输出：7
> 解释：区间内整数 [7, 8, 9, 10, 11] 对应的权重为 [16, 3, 19, 6, 14] 。
> 按权重排序后得到的结果为 [8, 10, 11, 7, 9] 。
> 排序后数组中第 4 个数字为 7 。
> ```
>
> **提示：**
>
> - `1 <= lo <= hi <= 1000`
>
> - `1 <= k <= hi - lo + 1`

> **题解**
> > 数学还没准备好应对这样的问题。
> > 
> > —— 埃尔德什·帕尔
>
> 本题来自 $3n+1$ 猜想，也叫冰雹猜想。
>
> 按照题意写一个递归函数，$\textit{dfs}(i)$ 表示从 $i$ 到 $1$ 的权重。
>
> - 如果 $i$ 是偶数，那么 $\textit{dfs}(i) = \textit{dfs}(i/2)+1$。
> - 如果 $i$ 是奇数，那么 $\textit{dfs}(i) = \textit{dfs}(3i+1)+1$。进一步地，由于 $i$ 是奇数，$3i+1$ 一定是偶数，所以也可以直接走两步，写成 $\textit{dfs}(i) = \textit{dfs}((3i+1)/2)+2$。
>
> 递归边界：$\textit{dfs}(1) = 0$。
>
> 代码实现时，由于会递归到重复的状态，用记忆化搜索优化。进一步地，可以把 $\textit{dfs}$ 写到外面，这样多个测试数据之间可以共享记忆化搜索的结果。
>
> ```python
> @cache  # 缓存装饰器，避免重复计算 dfs 的结果（记忆化）
> def dfs(i: int) -> int:
>     if i == 1:
>         return 0
>     if i % 2:
>         return dfs((i * 3 + 1) // 2) + 2
>     return dfs(i // 2) + 1
>
> class Solution:
>     def getKth(self, lo: int, hi: int, k: int) -> int:
>         # sorted 是稳定排序，我们只需比较 dfs 的返回值
>         return sorted(range(lo, hi + 1), key=dfs)[k - 1]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n + C)$，其中 $n=\textit{hi}-\textit{lo}$，$C$ 为记忆化搜索的状态个数，在本题的数据范围下，$C\le 1625$。若用快速选择算法，可以做到 $\mathcal{O}(n+C)$。
> - 空间复杂度：$\mathcal{O}(n)$。
