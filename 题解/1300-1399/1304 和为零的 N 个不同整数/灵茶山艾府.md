# 两种方法：对称/等差数列和（Python/Java/C++/C/Go/JS/Rust）

> **[1304. 和为零的 N 个不同整数](https://leetcode.cn/problems/find-n-unique-integers-sum-up-to-zero/solutions/3761005/dui-cheng-gou-zao-jian-ji-xie-fa-pythonj-npky/) · Easy · 难度分 1167**

> **所属题单**
> - [贪心算法 · 六、构造题](../../../刷题路径/灵神原版题单/贪心算法/六、构造题.md)

> **题目描述**
> 给你一个整数 `n`，请你返回 **任意** 一个由 `n` 个 **各不相同** 的整数组成的数组，并且这 `n` 个数相加和为 `0` 。
>
> **示例 1：**
>
> ```
> 输入：n = 5
> 输出：[-7,-1,1,3,4]
> 解释：这些数组也是正确的 [-5,-1,1,2,3]，[-3,-1,2,-2,4]。
> ```
>
> **示例 2：**
>
> ```
> 输入：n = 3
> 输出：[-1,0,1]
> ```
>
> **示例 3：**
>
> ```
> 输入：n = 1
> 输出：[0]
> ```
>
> **提示：**
>
> - `1 <= n <= 1000`

> **题解**
> ## 方法一：对称构造
>
> 由于 $x + (-x) = 0$ 恒成立，可以把 $1$ 和 $-1$，$2$ 和 $-2$，$3$ 和 $-3$ 等成对添加到答案中。如果 $n$ 是奇数，就再加个 $0$。
>
> 方便编程实现的一种构造方案如下。其中 $m = \left\lfloor\dfrac{n}{2}\right\rfloor$。
>
> 当 $n$ 为偶数时：
>
> $$
> [1,2,\dots,m-1,m,-1,-2,\dots,-(m-1),-m]
> $$
>
> 当 $n$ 为奇数时：
>
> $$
> [1,2,\dots,m-1,m,-1,-2,\dots,-(m-1),-m,0]
> $$
>
> ```python
> class Solution:
>     def sumZero(self, n: int) -> List[int]:
>         a = [0] * n
>         m = n // 2
>         for i in range(m):
>             a[i] = i + 1
>             a[i + m] = -i - 1
>         return a
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def sumZero(self, n: int) -> List[int]:
> >         m = n // 2
> >         if n % 2:
> >             return list(range(-m, m + 1))
> >         return list(range(-m, 0)) + list(range(1, m + 1))
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
>
> ## 方法二：等差数列和
>
> 设 $S = 1+2+\dots+(n-1) = \dfrac{n(n-1)}{2}$。
>
> 构造方案为：
>
> $$
> [-S,1,2,\dots,n-1]
> $$
>
> ```python
> class Solution:
>     def sumZero(self, n: int) -> List[int]:
>         return [-n * (n - 1) // 2] + list(range(1, n))
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
