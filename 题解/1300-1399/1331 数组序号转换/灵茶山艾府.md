# 【模板】离散化的两种写法：二分查找 / 哈希表（Python/Java/C++/Go）

> **[1331. 数组序号转换](https://leetcode.cn/problems/rank-transform-of-an-array/solutions/3995025/mo-ban-chi-san-hua-de-liang-chong-xie-fa-1i23/) · Easy**

> **题目描述**
> 给你一个整数数组 `arr` ，请你将数组中的每个元素替换为它们排序后的序号。
>
> 序号代表了一个元素有多大。序号编号的规则如下：
>
> - 序号从 1 开始编号。
>
> - 一个元素越大，那么序号越大。如果两个元素相等，那么它们的序号相同。
>
> - 每个数字的序号都应该尽可能地小。
>
> **示例 1：**
>
> ```
> 输入：arr = [40,10,20,30]
> 输出：[4,1,2,3]
> 解释：40 是最大的元素。 10 是最小的元素。 20 是第二小的数字。 30 是第三小的数字。
> ```
>
> **示例 2：**
>
> ```
> 输入：arr = [100,100,100]
> 输出：[1,1,1]
> 解释：所有元素有相同的序号。
> ```
>
> **示例 3：**
>
> ```
> 输入：arr = [37,12,28,9,100,56,80,5,12]
> 输出：[5,3,4,2,8,6,7,1,3]
> ```
>
> **提示：**
>
> - `0 <= arr.length <= 10⁵`
>
> - `-10⁹ <= arr[i] <= 10⁹`

> **题解**
> ## 方法一：二分查找
>
> 例如 $\textit{arr} = [20,20,10,30]$。复制一份，排序去重后，得到 $\textit{sortedArr} = [10,20,30]$。在这个数组上分别**二分查找** $20,20,10,30$ 的下标（加一），就是答案。
>
> 关于二分查找的原理，请看 [二分查找 红蓝染色法【基础算法精讲 04】](https://www.bilibili.com/video/BV1AP41137w7/)。
>
> ```python
> class Solution:
>     def arrayRankTransform(self, arr: List[int]) -> List[int]:
>         # 去重排序
>         sorted_arr = sorted(set(arr))
>
>         for i, x in enumerate(arr):
>             # 二分得到编号
>             arr[i] = bisect_left(sorted_arr, x) + 1
>
>         return arr
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{arr}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
>
> ## 方法二：哈希表
>
> 例如 $\textit{arr} = [20,20,10,30]$。复制一份，排序去重后，得到 $\textit{sortedArr} = [10,20,30]$。然后创建一个哈希表，把 $10,20,30$ 分别映射到 $1,2,3$。最后，查询 $20,20,10,30$ 在哈希表中对应的 value，即为答案。
>
> **注**：关于去重的原理，见 [26. 删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)，[我的题解](../../0000-0099/0026%20删除有序数组中的重复项/灵茶山艾府.md)。
>
> ```python
> class Solution:
>     def arrayRankTransform(self, arr: List[int]) -> List[int]:
>         # 去重排序
>         sorted_arr = sorted(set(arr))
>
>         # 构建哈希表
>         rank = {x: i for i, x in enumerate(sorted_arr, 1)}
>
>         for i, x in enumerate(arr):
>             arr[i] = rank[x]
>
>         return arr
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def arrayRankTransform(self, arr: List[int]) -> List[int]:
> >         # 排序
> >         sorted_arr = sorted(arr)
> >
> >         # 去重的同时构建哈希表
> >         rank = {}
> >         for x in sorted_arr:
> >             if x not in rank:
> >                 rank[x] = len(rank) + 1
> >
> >         for i, x in enumerate(arr):
> >             arr[i] = rank[x]
> >
> >         return arr
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{arr}$ 的长度。瓶颈在排序上。
> - 空间复杂度：$\mathcal{O}(n)$。
