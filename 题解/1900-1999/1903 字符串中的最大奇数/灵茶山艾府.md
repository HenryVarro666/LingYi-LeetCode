# 找最后一个奇数位置（附一行写法）

> **[1903. 字符串中的最大奇数](https://leetcode.cn/problems/largest-odd-number-in-string/solutions/836301/zhao-zui-hou-yi-ge-qi-shu-wei-zhi-by-end-j98d/) · Easy · 难度分 1249**

> **所属题单**
> - [贪心算法 · 五、思维题](../../../刷题路径/灵神原版题单/贪心算法/五、思维题.md) · §5.2 脑筋急转弯

> **题目描述**
> 给你一个字符串 `num` ，表示一个大整数。请你在字符串 `num` 的所有 **非空子字符串** 中找出 **值最大的奇数** ，并以字符串形式返回。如果不存在奇数，则返回一个空字符串 `""` 。
>
> **子字符串** 是字符串中的一个连续的字符序列。
>
> **示例 1：**
>
> ```
>
> 输入：num = "52"
> 输出："5"
> 解释：非空子字符串仅有 "5"、"2" 和 "52" 。"5" 是其中唯一的奇数。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：num = "4206"
> 输出：""
> 解释：在 "4206" 中不存在奇数。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：num = "35427"
> 输出："35427"
> 解释："35427" 本身就是一个奇数。
> ```
>
> **提示：**
>
> - `1 <= num.length <= 10⁵`
>
> - `num` 仅由数字组成且不含前导零

> **题解**
> 由于奇数的最后一个数字是奇数，从后往前找到第一个奇数数字，删掉后面的字符，剩下的就是最大的奇数。
