# 每组恰好选一个的分组背包 + 常数优化至 40ms

> **[1981. 最小化目标值与所选元素的差](https://leetcode.cn/problems/minimize-the-difference-between-target-and-chosen-elements/solutions/951181/fen-zu-bei-bao-by-endlesscheng-fret/) · Medium · 难度分 2010**

> **所属题单**
> - [动态规划 · 三、背包](../../../刷题路径/灵神原版题单/动态规划/三、背包.md) · §3.4 分组背包

> **题目描述**
> 给你一个大小为 `m x n` 的整数矩阵 `mat` 和一个整数 `target` 。
>
> 从矩阵的 **每一行** 中选择一个整数，你的目标是 **最小化** 所有选中元素之 **和** 与目标值 `target` 的 **绝对差** 。
>
> 返回 **最小的绝对差** 。
>
> `a` 和 `b` 两数字的 **绝对差** 是 `a - b` 的绝对值。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/8d06e0a17b492025.png)
>
> ```
>
> 输入：mat = [[1,2,3],[4,5,6],[7,8,9]], target = 13
> 输出：0
> 解释：一种可能的最优选择方案是：
> - 第一行选出 1
> - 第二行选出 5
> - 第三行选出 7
> 所选元素的和是 13 ，等于目标值，所以绝对差是 0 。
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/aabf6ab62ecf77d2.png)
>
> ```
>
> 输入：mat = [[1],[2],[3]], target = 100
> 输出：94
> 解释：唯一一种选择方案是：
> - 第一行选出 1
> - 第二行选出 2
> - 第三行选出 3
> 所选元素的和是 6 ，绝对差是 94 。
> ```
>
> **示例 3：**
>
> ![](../../_assets/灵茶山艾府/17dbfd863fbb87b3.png)
>
> ```
>
> 输入：mat = [[1,2,9,8,7]], target = 6
> 输出：1
> 解释：最优的选择方案是选出第一行的 7 。
> 绝对差是 1 。
> ```
>
> **提示：**
>
> - `m == mat.length`
>
> - `n == mat[i].length`
>
> - `1 <= m, n <= 70`
>
> - `1 <= mat[i][j] <= 70`
>
> - `1 <= target <= 800`

> **题解**
> 把每一行看成一组，物品的体积就是元素值，这样就转化成了一个分组背包的模型。
>
> 定义 $f[i][j]$ 表示能否从前 $i$ 组物品中选出恰好为 $j$ 的重量，且每组都恰好选一个物品。
>
> 转移时可以倒序转移，从而压缩空间。
>
> 注意背包大小至多是 $\textit{target}\cdot 2$：
>
> - 如果每行选最小的，也比 $\textit{target}$ 大，那么最优就是每行选最小的。
> - 否则，最小差值至多为 $\textit{target}$，所以无需考虑元素和大于 $\textit{target}\cdot 2$ 的情况。
>
> 其余优化点见代码注释。
