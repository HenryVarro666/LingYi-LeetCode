# 简单 DFS（Python/Java/C++/Go/JS）

> **[589. N 叉树的前序遍历](https://leetcode.cn/problems/n-ary-tree-preorder-traversal/solutions/2643719/jian-dan-dfspythonjavacgojsrust-by-endle-0sf4/) · Easy**

> **所属题单**
> - [链表、二叉树与回溯 · 二、二叉树](../../../刷题路径/灵神原版题单/链表、二叉树与回溯/二、二叉树.md) · §2.15 N 叉树

> **题目描述**
> 给定一个 n 叉树的根节点  `root` ，返回 <em>其节点值的 **前序遍历**</em> 。
>
> n 叉树 在输入中按层序遍历进行序列化表示，每组子节点由空值 `null` 分隔（请参见示例）。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/7ec1bc7f4cf05111.png)
>
> ```
>
> 输入：root = [1,null,3,2,4,null,5,6]
> 输出：[1,3,5,6,2,4]
> ```
>
> **示例 2：**
>
> ![](../../_assets/灵茶山艾府/4ae921f4b63ae2fb.png)
>
> ```
>
> 输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
> 输出：[1,2,3,6,7,11,14,4,8,12,5,9,13,10]
> ```
>
> **提示：**
>
> - 节点总数在范围 `[0, 10⁴]`内
>
> - `0 <= Node.val <= 10⁴`
>
> - n 叉树的高度小于或等于 `1000`
>
> **进阶：**递归法很简单，你可以使用迭代法完成此题吗?

> **题解**
> 对于二叉树来说，前序遍历的顺序为：根节点 - 递归左儿子（左子树） - 递归右儿子（右子树）。
>
> 推广到 N 叉树，顺序是先访问根节点，再依次递归其 $\textit{children}$ 数组中的节点（子树）。
>
> 不熟悉递归的同学可以看视频讲解：[深刻理解递归【基础算法精讲 09】](https://www.bilibili.com/video/BV1UD4y1Y769/)
>
> ```python
> class Solution:
>     def preorder(self, root: 'Node') -> List[int]:
>         ans = []
>         def dfs(node: 'Node') -> None:
>             if node is None:
>                 return
>             ans.append(node.val)
>             for c in node.children:
>                 dfs(c)
>         dfs(root)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 为树的节点个数。
> - 空间复杂度：$\mathcal{O}(n)$。
