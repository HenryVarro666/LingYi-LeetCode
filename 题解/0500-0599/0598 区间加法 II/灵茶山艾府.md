# 脑筋急转弯（Python/Java/C++/C/Go/JS/Rust）

> **[598. 区间加法 II](https://leetcode.cn/problems/range-addition-ii/solutions/3053429/nao-jin-ji-zhuan-wan-pythonjavaccgojsrus-7166/) · Easy · 难度分 1400**

> **所属题单**
> - [贪心算法 · 五、思维题](../../../刷题路径/灵神原版题单/贪心算法/五、思维题.md) · §5.2 脑筋急转弯

> **题目描述**
> 给你一个 `m x n` 的矩阵 `M` 和一个操作数组 `op` 。矩阵初始化时所有的单元格都为 `0` 。`ops[i] = [ai, bi]` 意味着当所有的 `0 <= x < ai` 和 `0 <= y < bi` 时， `M[x][y]` 应该加 1。
>
> 在 <em>执行完所有操作后</em> ，计算并返回 <em>矩阵中最大整数的个数</em> 。
>
> **示例 1:**
>
> ![](../../_assets/灵茶山艾府/2a92e19ed251a85c.jpg)
>
> ```
>
> 输入: m = 3, n = 3，ops = [[2,2],[3,3]]
> 输出: 4
> 解释: M 中最大的整数是 2, 而且 M 中有4个值为2的元素。因此返回 4。
> ```
>
> **示例 2:**
>
> ```
>
> 输入: m = 3, n = 3, ops = [[2,2],[3,3],[3,3],[3,3],[2,2],[3,3],[3,3],[3,3],[2,2],[3,3],[3,3],[3,3]]
> 输出: 4
> ```
>
> **示例 3:**
>
> ```
>
> 输入: m = 3, n = 3, ops = []
> 输出: 9
> ```
>
> **提示:**
>
> - `1 <= m, n <= 4 * 10⁴`
>
> - `0 <= ops.length <= 10⁴`
>
> - `ops[i].length == 2`
>
> - `1 <= a_i <= m`
>
> - `1 <= b_i <= n`

> **题解**
> 每个 $\textit{ops}[i]$ 会把一个子矩形中的数都加一，那么这些子矩形的**交集**中的数，被加一的次数最多，是最终矩阵中的最大整数。
>
> 矩形的交集仍然是矩形。
>
> 由于子矩形的左上角都是 $(0,0)$，所以交集矩形的左上角也是 $(0,0)$。
>
> 知道了交集矩形的右下角，就知道了交集的大小。
>
> 所有 $\textit{ops}[i][0]$ 的最小值 $\textit{minA}$，是交集的横坐标加一。
>
> 所有 $\textit{ops}[i][1]$ 的最小值 $\textit{minB}$，是交集的纵坐标加一。
>
> 那么交集的大小为
>
> $$
> \textit{minA}\cdot \textit{minB}
> $$
>
> 如果 $\textit{ops}$ 是空的，那么交集大小就是原矩阵的大小 $mn$。
>
> ```python
> class Solution:
>     def maxCount(self, m: int, n: int, ops: List[List[int]]) -> int:
>         min_a = min((op[0] for op in ops), default=m)
>         min_b = min((op[1] for op in ops), default=n)
>         return min_a * min_b
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(k)$，其中 $k$ 是 $\textit{ops}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
