# 库函数简洁写法

> **[2936. 包含相等值数字块的数量](https://leetcode.cn/problems/number-of-equal-numbers-blocks/solutions/2576175/ku-han-shu-jian-ji-xie-fa-by-endlesschen-ajmb/) · Medium**

> **所属题单**
> - [二分算法 · 四、其他](../../../刷题路径/灵神原版题单/二分算法/四、其他.md)
> - [贪心算法 · 七、交互题](../../../刷题路径/灵神原版题单/贪心算法/七、交互题.md)

> **题解**
> 从 $i=0$ 开始循环，每次找后面不等于 $\textit{nums}[i]$ 的数的最小下标，作为下一轮循环的 $i$。
>
> 循环直到 $i=n$ 时停止。循环次数即为答案。
>
> ```python
> class Solution(object):
>     def countBlocks(self, nums: Optional['BigArray']) -> int:
>         ans, i, n = 0, 0, nums.size()
>         while i < n:
>             cur = nums.at(i)
>             i += bisect_left(range(i, n), True, key=lambda j: nums.at(j) != cur)
>             ans += 1
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(\sqrt{S}\log S)$，其中 $S$ 为 $\textit{nums}$ 的元素和。不妨假设所有块的大小均为 $1$，在这种情况下，$\textit{nums}=[1,2,3,4,\cdots]$，数组长度至多为 $\mathcal{O}(\sqrt{S})$，每次二分需要 $\mathcal{O}(\log S)$ 的时间。
> - 空间复杂度：$\mathcal{O}(1)$。仅用到若干额外变量。
