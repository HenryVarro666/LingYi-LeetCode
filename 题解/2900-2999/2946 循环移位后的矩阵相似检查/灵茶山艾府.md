# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[2946. 循环移位后的矩阵相似检查](https://leetcode.cn/problems/matrix-similarity-after-cyclic-shifts/solutions/2542296/xian-qu-mo-zai-mo-ni-by-endlesscheng-iabk/) · Easy · 难度分 1406**

> **所属题单**
> - [贪心算法 · 八、其他](../../../刷题路径/灵神原版题单/贪心算法/八、其他.md)

> **题目描述**
> 给你一个**下标从 0 开始**且大小为 `m x n` 的整数矩阵 `mat` 和一个整数 `k` 。矩阵行的下标是从 0 开始的。
>
> 进行下面操作 `k` 次：
>
> - **偶数行**（0, 2, 4, ...）循环向左移动。
>
> ![](../../_assets/灵茶山艾府/eaee41f47dea7110.jpg)
>
> - **奇数行**（1, 3, 5, ...）循环向右移动。
>
> ![](../../_assets/灵茶山艾府/788a1087d1a014b1.jpg)
>
> 如果经过 `k` 步后的最终修改矩阵与原始矩阵相同，则返回 `true`，否则返回 `false`。
>
> **示例 1：**
>
> **输入：**`mat = [[1,2,3],[4,5,6],[7,8,9]], k = 4`
>
> **输出：**`false`
>
> **解释：**
>
> 在每一步中，行 0 和行 2（偶数下标）进行左移，行 1（奇数下标）进行右移。
>
> ![](../../_assets/灵茶山艾府/d9d11a190f8bb6ba.jpg)
>
> **示例 2：**
>
> **输入：**`mat = [[1,2,1,2],[5,5,5,5],[6,3,6,3]], k = 2`
>
> **输出：**`true`
>
> **解释：**
>
> ![](../../_assets/灵茶山艾府/a62f1a7cbe324583.jpg)
>
> **示例 3：**
>
> **输入：**`mat = [[2,2],[2,2]], k = 3`
>
> **输出：**`true`
>
> **解释：**
>
> 矩阵中的所有值都相等，即使进行循环移位，矩阵也会保持不变。
>
> **提示：**
>
> - `1 <= mat.length <= 25`
>
> - `1 <= mat[i].length <= 25`
>
> - `1 <= mat[i][j] <= 25`
>
> - `1 <= k <= 50`

> **题解**
> 实际上，只需把每行右移 $k$ 次。无需判断奇偶，无需考虑左移。
>
> 为什么？如果一行左移 $k$ 次等于自己，那么这个过程的逆过程，就是把自己右移 $k$ 次，得到自己。
>
> 判断 $\textit{row}$ 右移 $k$ 次是否等于 $\textit{row}$，可以比较 $\textit{row}[j]$ 与右移 $k$ 次后的位置 $\textit{row}[(j+k)\bmod n]$ 是否相等。
>
> ```python
> class Solution:
>     def areSimilar(self, mat: List[List[int]], k: int) -> bool:
>         k %= len(mat[0])  # 右移 n 次等价于右移 0 次，右移 n+1 次等价于右移 1 次，依此类推，先模个 n
>         return k == 0 or all(row == row[k:] + row[:k] for row in mat)
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def areSimilar(self, mat: List[List[int]], k: int) -> bool:
> >         n = len(mat[0])
> >         for row in mat:
> >             for j in range(n):
> >                 if row[j] != row[(j + k) % n]:
> >                     return False
> >         return True
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(mn)$，其中 $m$ 和 $n$ 分别是 $\textit{mat}$ 的行数和列数。
> - 空间复杂度：$\mathcal{O}(1)$。
>
> ## 详细解释
>
> 可能有同学脑筋没转过来，这里详细解释下。
>
> 如果给你两个数组 $a$ 和 $b$，要判断 $a$ 左移/右移后是否等于 $b$，那么 $a$ 左移 $k$ 次和右移 $k$ 次是不一样的。
>
> 但本题这两个数组都是 $a$，要判断 $a$ 左移/右移后是否等于 $a$ 自己。
>
> 由于 $a$ 左移 $k$ 次后和 $b$ 比较，等价于 $b$ 右移 $k$ 次后和 $a$ 比较。在 $b$ 就是 $a$ 的情况下，等价于 $a$ 自己右移 $k$ 次和 $a$ 比较。
