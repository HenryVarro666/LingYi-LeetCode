2912.在网格上移动到目的地的方法数

[力扣（LeetCode）官网 - 全球极客挚爱的技术成长平台](https://leetcode.cn/problems/number-of-ways-to-reach-destination-in-the-grid/)

题目只允许横向和纵向两种方式进行移动，那么在这里就可以先将横向和纵向分开来计数，也就是说，从0到k枚举横移的次数p，那么纵移的次数就是k - p，问题就被拆解成了在一维数组中移动若干次到指定位置的方案数，使用f[i]记录在一维数组中从起点行动i次最终走到目标位置的方案数，那么最后就是从0到k枚举p，计算C(k, p) \* f[p] \* f[k - p]并累加起来。

接下来就是f的计算方式。在这里直接记录落点肯定是不可取的，那么不妨设f[i]为行走i步之后落在目标位置的方案数，而g[i]则表示行走i步之后没有落在目标位置的方案数，那么对于f[i]和g[i]，就有

1、f[i] \= g[i - 1]：

这里表示只有当上一步没有走到目标点时，在这一步才能走到目标点，同时对于上一步没有在目标点的每种情况，都只有一种可行的走法走到目标点

2、g[i] \= f[i - 1] \* (length - 1) + g[i - 1] \* (length - 2)

前半部分表示的是从上一轮的目标点开始走，随便怎么走都会走到其他点上。由于不能待在原地，因此需要减去1。后半部分则表示从上一轮的其他点开始走，不能走到目标点，也不能待在原地，因此可以走的位置需要减去2。

得到这两个转移方程后，一趟遍历就可以计算出所有的f和g。

另外在计算时需要先处理好初始情况。对于当前处理的维度，若起点和目标点一开始就一样，那么就有f[0] \= 1，g[0] \= 0，反之就是f[0] \= 0，g[0] \= 1。

计算完f和g之后，接下来则还需要计算出C(k, 0)、C(k, 1)、...、C(k, k)。由于k的规模很大又涉及到了取模操作，那么免不了需要乘法逆元和快速幂出场。

到了这里，就不想再往下写了，因为感觉搞得太复杂了。虽然拆分横纵坐标将两个维度上的问题都转化成了线性的问题，但是多出了一步组合数学的计算，不妨回头去重新考虑在二维平面上建模。

---

不再对横纵坐标进行拆分，直接令f[i]表示i步操作后横纵坐标都不等于目标值的方案数，g[i]表示横坐标在目标值但纵坐标不在的方案数，h[i]与g[i]对称，表示横坐标不在目标值，纵坐标在的方案数，而t[i]则表示位于目标位置的方案数，那么对于f[i]、g[i]、h[i]与t[i]：

1、f[i] \= f[i - 1] \* (m + n - 4) + g[i - 1] \* (n - 1) + h[i - 1] \* (m - 1)

第一个部分是上一步位于两不沾的点，因为不能原地不动，因此其横纵方向上一共有m + n - 2可以走，但是其中某行某列会与目标点同行或者同列，因此最终可走的位置还需要额外减去2，也就是m + n - 4

第二个部分是上一步位于目标点同行的点，为了达到两不沾，此时就只能在纵向上行走，因此一共有n - 1种走法

第三个部分是上一步位于目标点同列的点，与第二个部分对称，此时的走发为m - 1种

2、g[i] \= f[i - 1] + g[i - 1] \* (m - 2) + t[i - 1] \* (m - 1)

第一个部分是上一步位于两不沾的点，只有一种走法可以使得本轮与目标点的行坐标相同

第二个部分是上一步就位于同行但不同列的点，为了继续保持同行，因此只能横向移动，同时还需要注意不能走到目标点所在的列，也不能原地不动，因此这里有m - 2种走法

第三个部分则是从目标点走到某个同行不同列的点，此时同样是只能横向移动且不能原地不动，因此这里有m - 1种走法

3、h[i] \= f[i - 1] + h[i - 1] \* (n - 2) + t[i - 1] \* (n - 1)

同列不同行的情况与情况2对称，三个部分的行列都变换一下就行了。

4、t[i] \= g[i - 1] + h[i - 1]

目标点只能从上一轮同行不同列或者同列不同行的位置出发朝唯一的目标行走，因此两项系数都是1

根据以上的转移方程，就可以一趟遍历计算出f[k]、g[k]、h[k]以及t[k]，而t[k]即为最终答案。初始化时，若行列都不同，那么就有f[0] \= 1，其他都为0；若同行不同列，那么就是g[0] \= 1，其他都为0；若同列不同行，则是h[0] \= 1，其他都为0；最后若起点和终点重合，那么就是t[0] \= 1，其他都为0。

另外，这里的递推计算可以使用矩阵乘法进行优化。尝试构造一个4 \* 4的矩阵base，使得

\[f\[i\], g\[i\], h\[i\], t\[i\]\] \* base \= \[f\[i + 1\], g\[i + 1\], h\[i + 1\], t\[i + 1\]\]

只需将上面四个转移方程的系数带入进来，就可以很方便的得到base，为

base \= \[\[m + n - 4, 1, 1, 0\],
[n - 1, m - 2, 0, 1],
[m - 1, 0, n - 2, 1],
\[0, m - 1, n - 1, 0\]\]

一种简单的理解是将转移方程中，第i个转移方程中的第j项系数填充到矩阵中的第j行第i列就行了，其中缺失项的系数默认为0。

得到base后，最终答案\[f\[k\], g\[k\], h\[k\], t\[k\]\]就可以认为是\[f\[0\], g\[0\], h\[0\], t\[0\]\] \* base \* base \* ... \* base得到，一共是k个base。由于矩阵乘法满足结合律，那么就将后面的部分写成base^k，此时就可以利用快速幂优化这个乘方，使得最终的时间复杂度降到O(logk \* l^3)，其中l^3为矩阵乘法的复杂度，l在这里为4。

最后附上python代码：

```python
class Solution(object):
    def numberOfWays(self, n, m, k, source, dest):
        """
        :type n: int
        :type m: int
        :type k: int
        :type source: List[int]
        :type dest: List[int]
        :rtype: int
        """

        '''
        f[0] = f[0] * (m + n - 4) + f[1] * (n - 1) + f[2] * (m - 1)
        f[1] = f[0] + f[1] * (m - 2) + f[4] * (n - 1)
        f[2] = f[0] + f[2] * (n - 2) + f[4] * (m - 1)
        f[3] = f[1] + f[2]
        '''

        mod = 10 ** 9 + 7

        base = [[m + n - 4, 1, 1, 0],
                [n - 1, m - 2, 0, 1],
                [m - 1, 0, n - 2, 1],
                [0, m - 1, n - 1, 0]]

        def mul(a, b):
            c = [[0] * len(b[0]) for _ in range(len(a))]
            for i in range(len(a)):
                for j in range(len(b[0])):
                    for k in range(len(a[0])):
                        c[i][j] += a[i][k] * b[k][j]
                        c[i][j] %= mod
            return c

        def quick_pow(p):
            if p == 1:
                return base[:]
            
            res = quick_pow(p / 2)
            
            res = mul(res, res)
            if p % 2 == 1:
                res = mul(res, base)
            
            return res
        

        if source[0] == dest[0]:
            if source[1] == dest[1]:
                ori = [[0, 0, 0, 1]]
            else:
                ori = [[0, 1, 0, 0]]
        elif source[1] == dest[1]:
            ori = [[0, 0, 1, 0]]
        else:
            ori = [[1, 0, 0, 0]]

        return mul(ori, quick_pow(k))[0][3]
```
