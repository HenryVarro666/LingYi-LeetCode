# 库函数简洁写法（Python/Java/C++/Go/JS/Rust）

> **[3280. 将日期转换为二进制表示](https://leetcode.cn/problems/convert-date-to-binary/solutions/2909000/ku-han-shu-jian-ji-xie-fa-pythonjavacgo-ohojk/) · Easy**

> **题目描述**
> 给你一个字符串 `date`，它的格式为 `yyyy-mm-dd`，表示一个公历日期。
>
> `date` 可以重写为二进制表示，只需要将年、月、日分别转换为对应的二进制表示（不带前导零）并遵循 `year-month-day` 的格式。
>
> 返回 `date` 的 **二进制** 表示。
>
> **示例 1：**
>
> **输入：** `date = "2080-02-29"`
>
> **输出：** `"100000100000-10-11101"`
>
> **解释：**
>
> `100000100000, 10 和 11101 分别是 2080, 02 和 29 的二进制表示。`
>
> **示例 2：**
>
> **输入：** `date = "1900-01-01"`
>
> **输出：** `"11101101100-1-1"`
>
> **解释：**
>
> `11101101100, 1 和 1 分别是 1900, 1 和 1 的二进制表示。`
>
> **提示：**
>
> - `date.length == 10`
>
> - `date[4] == date[7] == '-'`，其余的 `date[i]` 都是数字。
>
> - 输入保证 `date` 代表一个有效的公历日期，日期范围从 1900 年 1 月 1 日到 2100 年 12 月 31 日（包括这两天）。

> **题解**
> 算法：
>
> 1. 把字符串 $\textit{date}$ 按照 `-` 分割。
> 2. 对于每个字符串，首先转成数字。
> 3. 然后转成二进制字符串。
> 4. 最后，用 `-` 拼接每个二进制字符串。
>
> ```python
> class Solution:
>     def convertDateToBinary(self, date: str) -> str:
>         a = date.split('-')
>         for i in range(len(a)):
>             a[i] = bin(int(a[i]))[2:]
>         return '-'.join(a)
> ```
>
> > [!example]- Py3 一行
> > ```python
> > class Solution:
> >     def convertDateToBinary(self, date: str) -> str:
> >         return '-'.join(bin(int(s))[2:] for s in date.split('-'))
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{date}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
