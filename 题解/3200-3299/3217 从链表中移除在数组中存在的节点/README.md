## 题目描述

给你一个整数数组 `nums` 和一个链表的头节点 `head`。从链表中**移除**所有存在于 `nums` 中的节点后，返回修改后的链表的头节点。

**示例 1：**

**输入：** `nums = [1,2,3], head = [1,2,3,4,5]`

**输出：** `[4,5]`

**解释：**

![](../../_assets/灵茶山艾府/7e871a1ffc4921ec.png)

移除数值为 1, 2 和 3 的节点。

**示例 2：**

**输入：** `nums = [1], head = [1,2,1,2,1,2]`

**输出：** `[2,2,2]`

**解释：**

![](../../_assets/灵茶山艾府/22c16a29adc8fb66.png)

移除数值为 1 的节点。

**示例 3：**

**输入：** `nums = [5], head = [1,2,3,4]`

**输出：** `[1,2,3,4]`

**解释：**

![](../../_assets/灵茶山艾府/8071345ca0126f43.png)

链表中不存在值为 5 的节点。

**提示：**

- `1 <= nums.length <= 10⁵`

- `1 <= nums[i] <= 10⁵`

- `nums` 中的所有元素都是唯一的。

- 链表中的节点数在 `[1, 10⁵]` 的范围内。

- `1 <= Node.val <= 10⁵`

- 输入保证链表中至少有一个值没有在 `nums` 中出现过。
