## 题目描述

给你两个 **正整数** `n` 和 `k`。

如果整数 `x` 满足以下全部条件，则该整数是一个 **k 回文数**：

- `x` 是一个 回文数。

- `x` 可以被 `k` 整除。

以字符串形式返回 **最大的**  `n` 位 **k 回文数**。

**注意**，该整数 **不** 含前导零。

**示例 1：**

**输入：** `n = 3, k = 5`

**输出：** `"595"`

**解释：**

595 是最大的 3 位 k 回文数。

**示例 2：**

**输入：** `n = 1, k = 4`

**输出：** `"8"`

**解释：**

1 位 k 回文数只有 4 和 8。

**示例 3：**

**输入：** `n = 5, k = 6`

**输出：** `"89898"`

**提示：**

- `1 <= n <= 10⁵`

- `1 <= k <= 9`
