3260.找出最大的N位K回文数

[. - 力扣（LeetCode）](https://leetcode.cn/problems/find-the-largest-palindrome-divisible-by-k/)

题目给出两个正整数n和k。若某个整数x是回文数，且x是k的倍数，那么就称x为k回文数，现在要求计算最大的n位k回文数。

n的数据规模比较大，按理说应该使用数位动态规划来处理，不过k的取值范围在1到9之间，那么直接找规律也是可行的方法：

1、k为1、3、9三者之一时：

这种情况最简单，因为99..999既是回文数，又是k的倍数，因此答案就是n个9

2、k为2、4、8三者之一时：

这种情况下k是2的幂，对于2的幂的整除处理方法也比较简单。

2-1）当k \= 2时：

此时可以将x拆分成x \= 10 \* y + z，其中10 \* y的部分必然是2的倍数，那么就只需要z是2的倍数即可。为了使得x尽可能大，z就应该取8。这种情况下答案为899...9998。

2-2）当k \= 4时：

此时可以将x拆分成x \= 100 \* y + z，其中100 \* y的部分必然是4的倍数，那么就只需要z是4的倍数即可。需要注意的是，此时的z应该取88而不是96，因为x是回文数，也就是说z反过来才是x的高位，为了使得x的高位尽量大，z就必须按从低位到高位的顺序尽量大，因此z需要取88。这种情况下答案为8899...99988。

2-3）当k \= 8时：

与上面类似，这种情况下的答案为88899...999888。

3、k为5时：

这种情况下与k \= 2时的处理方法一样，按x \= 10 \* y + z拆分后可知z应该取5，因此答案为599...9995。

4、k为6时：

对于k为6的情况，可以将k拆分成2 \* 3来进行讨论。

对于因子2，需要满足最低位为偶数。对于因子3，则需要满足的是x中的每个数位相加之和为3的倍数。

那么：

当n \= 1时，x只能取6。

当n \= 2时，x \= 10 \* z + z \= 11 \* z，此时z只能取6，因此x只能取66。

当n >\= 3时，因为中间的数位可以用来配合处理因子3，因此最理想的情况还是应该让两侧填充8，其他位置填充9，即899...9998这种形式。如果按这样填充，x模3的余数为2，需要修改x中间的数位来平了这个2。

当n为奇数时，可以将正中间这一位改为8，此时x由3个8和若干个9组成，满足是3的倍数；当n为偶数时，可以将正中间的两位都修改成7，此时x由2个8、2个7以及若干个9组成，满足是3的倍数。

即，当n为奇数时，答案为899...989...998；当n为偶数时，答案为899...9779...998。

5、k为7时：

7的情况相对复杂，因为因子7的性质不太好利用。不过对于本题，有一个可用的点是1001 \= 7 \* 11 \* 13，那么999999 \= 999 \* 1001必然是7的倍数，此时只需尽量在x的两侧填充999999。首位填充999999每次都会消耗掉12个数位，那么问题就变成了n等于1到11时可用的最大的7的倍数。

对于这个问题与上面处理6时的处理方法类似：

当n \= 1时，x只能取7

当n \= 2时，x只能取77

当n >\= 3时，同样可以利用中间的数位来配合处理因子7，因此最理想的情况就是让两侧填充9，然后用正中间的数来处理模7的余数。由于n的数位只到11位，在这里就可以先假定外侧全都是9，然后暴力枚举中间的数，计算出对应的结果，分别是[959, 9779, 99799, 999999, 9994999, 99944999, 999969999, 9999449999, 99999499999]。

最后附上python代码：

```python
class Solution(object):
    def largestPalindrome(self, n, k):
        """
        :type n: int
        :type k: int
        :rtype: str
        """

        if k == 1:
            return '9' * n
        
        if k == 2:
            if n <= 2:
                return '8' * n
            else:
                return '8' + '9' * (n - 2) + '8'

        if k == 3:
            return '9' * n
        
        if k == 4:
            if n <= 3:
                return '8' * n
            else:
                return '88' + '9' * (n - 4) + '88'
        
        if k == 5:
            if n <= 2:
                return '5' * n
            else:
                return '5' + '9' * (n - 2) + '5'
        
        if k == 6:
            if n <= 2:
                return '6' * n
            elif n % 2 == 0:
                return '8' + '9' * ((n - 4) // 2) + '7' + '7' + '9' * ((n - 4) // 2) + '8'
            else:
                return '8' + '9' * ((n - 3) // 2) + '8' + '9' * ((n - 3) // 2) + '8'
        
        if k == 7:
            middle_list = ['', '7', '77', '959', '9779', '99799', '999999', 
                            '9994999', '99944999', '999969999', '9999449999', '99999499999']
            return '999999' * (n // 12) + middle_list[n % 12] + '999999' * (n // 12)

        if k == 8:
            if n <= 6:
                return '8' * n
            else:
                return '888' + '9' * (n - 6) + '888'
        
        if k == 9:
            return '9' * n
```
