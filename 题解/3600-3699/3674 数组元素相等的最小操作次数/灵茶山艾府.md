# 脑筋急转弯（Python/Java/C++/Go）

> **[3674. 数组元素相等的最小操作次数](https://leetcode.cn/problems/minimum-operations-to-equalize-array/solutions/3774504/nao-jin-ji-zhuan-wan-pythonjavacgo-by-en-lh9g/) · Easy · 难度分 1369**

> **所属题单**
> - [贪心算法 · 五、思维题](../../../刷题路径/灵神原版题单/贪心算法/五、思维题.md) · §5.2 脑筋急转弯

> **题目描述**
> 给你一个长度为 `n` 的整数数组 `nums`。
>
> 在一次操作中，可以选择任意子数组 `nums[l...r]` （`0 <= l <= r < n`），并将该子数组中的每个元素 **替换** 为所有元素的 **按位与（bitwise AND）**结果。
>
> 返回使数组 `nums` 中所有元素相等所需的最小操作次数。
>
> **子数组** 是数组中连续的、非空的元素序列。
>
> **示例 1：**
>
> **输入：** `nums = [1,2]`
>
> **输出：** `1`
>
> **解释：**
>
> 选择 `nums[0...1]`：`(1 AND 2) = 0`，因此数组变为 `[0, 0]`，所有元素在一次操作后相等。
>
> **示例 2：**
>
> **输入：** `nums = [5,5,5]`
>
> **输出：** `0`
>
> **解释：**
>
> `nums` 本身是 `[5, 5, 5]`，所有元素已经相等，因此不需要任何操作。
>
> **提示：**
>
> - `1 <= n == nums.length <= 100`
>
> - `1 <= nums[i] <= 10⁵`

> **题解**
> 如果 $\textit{nums}$ 所有元素都相等，无需操作，返回 $0$。
>
> 否则，由于操作后，子数组所有元素都相等，所以直接操作整个数组，就能让所有元素相等，返回 $1$。
>
> 具体请看 [视频讲解](https://www.bilibili.com/video/BV1heYGzWEUa/)，欢迎点赞关注~
>
> ```python
> class Solution:
>     def minOperations(self, nums: List[int]) -> int:
>         return int(any(x != nums[0] for x in nums))
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
