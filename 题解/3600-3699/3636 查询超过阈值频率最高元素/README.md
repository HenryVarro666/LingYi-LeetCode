## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个查询数组 `queries`，其中 `queries[i] = [l_i, r_i, threshold_i]`。

返回一个整数数组 `ans`，其中 `ans[i]` 等于子数组 `nums[l_i...r_i]` 中出现 **至少** `threshold_i` 次的元素，选择频率 **最高** 的元素（如果频率相同则选择 **最小** 的元素），如果不存在这样的元素则返回 -1。

**示例 1:**

**输入：** `nums = [1,1,2,2,1,1], queries = [[0,5,4],[0,3,3],[2,3,2]]`

**输出：** `[1,-1,2]`

**解释：**

			查询
			子数组
			阈值
			频率表
			答案

			[0, 5, 4]
			[1, 1, 2, 2, 1, 1]
			4
			1 → 4, 2 → 2
			1

			[0, 3, 3]
			[1, 1, 2, 2]
			3
			1 → 2, 2 → 2
			-1

			[2, 3, 2]
			[2, 2]
			2
			2 → 2
			2

**示例 2:**

**输入：**`nums = [3,2,3,2,3,2,3], queries = [[0,6,4],[1,5,2],[2,4,1],[3,3,1]]`

**输出：**`[3,2,3,2]`

**解释：**

			查询
			子数组
			阈值
			频率表
			答案

			[0, 6, 4]
			[3, 2, 3, 2, 3, 2, 3]
			4
			3 → 4, 2 → 3
			3

			[1, 5, 2]
			[2, 3, 2, 3, 2]
			2
			2 → 3, 3 → 2
			2

			[2, 4, 1]
			[3, 2, 3]
			1
			3 → 2, 2 → 1
			3

			[3, 3, 1]
			[2]
			1
			2 → 1
			2

**提示：**

- `1 <= nums.length == n <= 10⁴`

- `1 <= nums[i] <= 10⁹`

- `1 <= queries.length <= 5 * 10⁴`

- `queries[i] = [l_i, r_i, threshold_i]`

- `0 <= l_i <= r_i < n`

- `1 <= threshold_i <= r_i - l_i + 1`
