# 枚举上下边界，转化成 560 题（Python/Java/C++/Go/JS/Rust）

> **[1074. 元素和为目标值的子矩阵数量](https://leetcode.cn/problems/number-of-submatrices-that-sum-to-target/solutions/3704958/mei-ju-shang-xia-bian-jie-zhuan-hua-chen-h6i4/) · Hard · 难度分 2189**

> **所属题单**
> - [常用数据结构 · 一、前缀和](../../../刷题路径/灵神原版题单/常用数据结构/一、前缀和.md) · §1.2 前缀和与哈希表

> **题目描述**
> 给出矩阵 `matrix` 和目标值 `target`，返回元素总和等于目标值的非空子矩阵的数量。
>
> 子矩阵 `x1, y1, x2, y2` 是满足 `x1 <= x <= x2` 且 `y1 <= y <= y2` 的所有单元 `matrix[x][y]` 的集合。
>
> 如果 `(x1, y1, x2, y2)` 和 `(x1', y1', x2', y2')` 两个子矩阵中部分坐标不同（如：`x1 != x1'`），那么这两个子矩阵也不同。
>
> **示例 1：**
>
> ![](../../_assets/灵茶山艾府/13b5a9b6a58bebac.jpg)
>
> ```
>
> 输入：matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0
> 输出：4
> 解释：四个只含 0 的 1x1 子矩阵。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：matrix = [[1,-1],[-1,1]], target = 0
> 输出：5
> 解释：两个 1x2 子矩阵，加上两个 2x1 子矩阵，再加上一个 2x2 子矩阵。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：matrix = [[904]], target = 0
> 输出：0
> ```
>
> 提示：
>
> - `1 <= matrix.length <= 100`
>
> - `1 <= matrix[0].length <= 100`
>
> - `-1000 <= matrix[i][j] <= 1000`
>
> - `-10^8 <= target <= 10^8`

> **题解**
> 枚举子矩阵的上下边界，计算子矩阵每一列的元素和，我们可以得到一个一维数组，每一项表示子矩阵一列的元素和。
>
> 现在问题变成：
>
> - 在这个一维数组中，有多少个非空连续子数组，元素和等于 $\textit{target}$？
>
> 这题就是 [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)，做法见 [我的题解](../../0500-0599/0560%20和为%20K%20的子数组/灵茶山艾府.md)。
>
> ```python
> class Solution:
>     # 560. 和为 K 的子数组
>     def subarraySum(self, nums: List[int], k: int) -> int:
>         ans = s = 0
>         cnt = defaultdict(int)
>         for x in nums:
>             cnt[s] += 1
>             s += x
>             ans += cnt[s - k]
>         return ans
>
>     def numSubmatrixSumTarget(self, matrix: List[List[int]], target: int) -> int:
>         n = len(matrix[0])
>         ans = 0
>         for i in range(len(matrix)):  # 上边界
>             col_sum = [0] * n
>             for row in matrix[i:]:  # 下边界
>                 for j, x in enumerate(row):
>                     col_sum[j] += x
>                 ans += self.subarraySum(col_sum, target)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(m^2n)$，其中 $m$ 和 $n$ 分别为 $\textit{matrix}$ 的行数和列数。
> - 空间复杂度：$\mathcal{O}(n)$。
