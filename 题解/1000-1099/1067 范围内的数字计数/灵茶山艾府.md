# 做法同 233 题，贡献法（Python/Java/C++/Go）

> **[1067. 范围内的数字计数](https://leetcode.cn/problems/digit-count-in-range/solutions/3978787/zuo-fa-tong-233-ti-gong-xian-fa-pythonja-v6si/) · Hard**

> **所属题单**
> - [动态规划 · 十、数位 DP](../../../刷题路径/灵神原版题单/动态规划/十、数位%20DP.md) · §10.2 统计合法元素的价值总和

> **题解**
> 拆分成 $[1,\textit{high}]$ 中的数字 $d$ 的个数，以及 $[1,\textit{low}-1]$ 中的数字 $d$ 的个数，二者相减，即为答案。
>
> 做法和 [233. 数字 1 的个数](https://leetcode.cn/problems/number-of-digit-one/) 是一样的，请看 [我的题解](../../0200-0299/0233%20数字%201%20的个数/灵茶山艾府.md) 的**方法二**。
>
> 对于本题，需要特殊处理 $d=0$ 的情况。
>
> 如果 $\textit{prefix}=0$ 且 $m=0$，那么 $m$ 是前导零，不能计入。减去这种情况即可。
>
> ```python
> class Solution:
>     def calc(self, n: int, d: int) -> int:
>         ans = 0
>         pow10 = 1
>
>         while pow10 <= n:
>             max_prefix = n // (pow10 * 10)
>             M = n // pow10 % 10
>
>             # 1. prefix < max_prefix 时，低位不受约束
>             # m 填 d，suffix 随便填
>             # 如果 d = 0，需要注意 prefix = m = 0 的情况，m 是前导零，不能计入，减去
>             ans += (max_prefix - (d == 0)) * pow10
>
>             if M > d:
>                 # 2. prefix = max_prefix 且 M > d
>                 # m 填 1，suffix 随便填
>                 ans += pow10
>             elif M == d:
>                 # 3. prefix = max_prefix 且 M = d
>                 # m 填 d，suffix 可以填 [0, max_suffix] 中的任意整数
>                 max_suffix = n % pow10
>                 ans += max_suffix + 1
>
>             pow10 *= 10
>
>         return ans
>
>     def digitsCount(self, d: int, low: int, high: int) -> int:
>         return self.calc(high, d) - self.calc(low - 1, d)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(\log \textit{high})$。
> - 空间复杂度：$\mathcal{O}(1)$。
