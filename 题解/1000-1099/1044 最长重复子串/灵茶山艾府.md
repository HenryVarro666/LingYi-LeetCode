# O(N) 后缀数组做法

> **[1044. 最长重复子串](https://leetcode.cn/problems/longest-duplicate-substring/solutions/862743/on-hou-zhui-shu-zu-zuo-fa-by-endlesschen-rqkp/) · Hard · 难度分 2429**

> **题目描述**
> 给你一个字符串 `s` ，考虑其所有 <em>重复子串</em> ：即 `s` 的（连续）子串，在 `s` 中出现 2 次或更多次。这些出现之间可能存在重叠。
>
> 返回 **任意一个** 可能具有最长长度的重复子串。如果 `s` 不含重复子串，那么答案为 `""` 。
>
> **示例 1：**
>
> ```
>
> 输入：s = "banana"
> 输出："ana"
> ```
>
> **示例 2：**
>
> ```
>
> 输入：s = "abcd"
> 输出：""
> ```
>
> **提示：**
>
> - `2 <= s.length <= 3 * 10⁴`
>
> - `s` 由小写英文字母组成
