# 用栈记录未匹配的左括号（Python/Java/C++/Go）

> **[1249. 移除无效的括号](https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/solutions/4006546/yong-zhan-ji-lu-wei-pi-pei-de-zuo-gua-ha-ho52/) · Medium · 难度分 1657**

> **所属题单**
> - [常用数据结构 · 三、栈](../../../刷题路径/灵神原版题单/常用数据结构/三、栈.md) · §3.4 合法括号字符串（RBS）

> **题目描述**
> 给你一个由 `'('`、`')'` 和小写字母组成的字符串 `s`。
>
> 你需要从字符串中删除最少数目的 `'('` 或者 `')'` （可以删除任意位置的括号)，使得剩下的「括号字符串」有效。
>
> 请返回任意一个合法字符串。
>
> 有效「括号字符串」应当符合以下 **任意一条** 要求：
>
> - 空字符串或只包含小写字母的字符串
>
> - 可以被写作 `AB`（`A` 连接 `B`）的字符串，其中 `A` 和 `B` 都是有效「括号字符串」
>
> - 可以被写作 `(A)` 的字符串，其中 `A` 是一个有效的「括号字符串」
>
> **示例 1：**
>
> ```
>
> 输入：s = "lee(t(c)o)de)"
> 输出："lee(t(c)o)de"
> 解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：s = "a)b(c)d"
> 输出："ab(c)d"
> ```
>
> **示例 3：**
>
> ```
>
> 输入：s = "))(("
> 输出：""
> 解释：空字符串也是有效的
> ```
>
> **提示：**
>
> - `1 <= s.length <= 10⁵`
>
> - `s[i]` 可能是 `'('`、`')'` 或英文小写字母

> **题解**
> 对于一个右括号 $s[i]$，我们需要找到 $s[i]$ 左边最近未匹配的左括号，与之匹配。如果没有左括号，那么 $s[i]$ 无法匹配，必须删除。例如 $\texttt{())}$ 中的第二个右括号必须删除。
>
> 用栈记录未匹配的左括号的下标。遍历到右括号 $s[i]$ 时，如果栈非空，则弹出栈顶，否则标记 $s[i]$ 需要删除。
>
> 遍历完 $s$ 后，如果栈非空，那么栈中这些左括号都没有与之匹配的右括号，标记为待删除。
>
> 代码实现时，可以先把待删除的括号改成 $\texttt{-}$ 号（或者 `'\0'`），最后只保留非 $\texttt{-}$ 号字符，即为答案。Python 可以直接改成空。
>
> ```python
> class Solution:
>     def minRemoveToMakeValid(self, s: str) -> str:
>         t = list(s)
>         st = []
>
>         for i, ch in enumerate(t):
>             if ch == '(':
>                 st.append(i)  # 记录左括号的下标
>             elif ch == ')':
>                 if st:
>                     st.pop()  # 左右括号匹配
>                 else:
>                     t[i] = ''  # 右括号没有与之匹配的左括号，标记为移除
>
>         for i in st:
>             t[i] = ''  # 栈中剩下的左括号没有与之匹配的右括号，标记为移除
>
>         return ''.join(t)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
