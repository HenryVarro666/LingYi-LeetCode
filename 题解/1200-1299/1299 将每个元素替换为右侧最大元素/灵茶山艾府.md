# 倒序遍历，维护后缀最大值（Python/Java/C++/C/Go/JS/Rust）

> **[1299. 将每个元素替换为右侧最大元素](https://leetcode.cn/problems/replace-elements-with-greatest-element-on-right-side/solutions/3067568/dao-xu-bian-li-wei-hu-hou-zhui-zui-da-zh-jox3/) · Easy**

> **题目描述**
> 给你一个数组 `arr` ，请你将每个元素用它右边最大的元素替换，如果是最后一个元素，用 `-1` 替换。
>
> 完成所有替换操作后，请你返回这个数组。
>
> **示例 1：**
>
> ```
>
> 输入：arr = [17,18,5,4,6,1]
> 输出：[18,6,6,6,1,-1]
> 解释：
> - 下标 0 的元素 --> 右侧最大元素是下标 1 的元素 (18)
> - 下标 1 的元素 --> 右侧最大元素是下标 4 的元素 (6)
> - 下标 2 的元素 --> 右侧最大元素是下标 4 的元素 (6)
> - 下标 3 的元素 --> 右侧最大元素是下标 4 的元素 (6)
> - 下标 4 的元素 --> 右侧最大元素是下标 5 的元素 (1)
> - 下标 5 的元素 --> 右侧没有其他元素，替换为 -1
> ```
>
> **示例 2：**
>
> ```
>
> 输入：arr = [400]
> 输出：[-1]
> 解释：下标 0 的元素右侧没有其他元素。
> ```
>
> **提示：**
>
> - `1 <= arr.length <= 10⁴`
>
> - `1 <= arr[i] <= 10⁵`

> **题解**
> **题意**：把 $\textit{arr}[i]$ 替换成后缀 $[i+1,n-1]$ 中的最大值 $\max\limits_{j=i+1}^{n-1} \textit{arr}[j]$。
>
> 倒着遍历 $\textit{arr}$，这样可以 $\mathcal{O}(1)$ 维护最大值 $\textit{mx}$：
>
> 1. 设 $x = \textit{arr}[i]$。
> 2. 更新 $\textit{arr}[i] = \textit{mx}$。
> 3. 更新 $\textit{mx} = \max(\textit{mx}, x)$。
>
> 注意后两步不能反过来，因为要替换的最大值不能包含 $\textit{arr}[i]$。
>
> **小技巧**：初始化 $\textit{mx}=-1$，这样无需特判 $i=n-1$ 的情况。
>
> ```python
> class Solution:
>     def replaceElements(self, arr: List[int]) -> List[int]:
>         mx = -1
>         for i in range(len(arr) - 1, -1, -1):
>             x = arr[i]
>             arr[i] = mx
>             mx = max(mx, x)  # 维护后缀最大值
>         return arr
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{arr}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
