# 三种方法：库函数/手动计算/位运算（Python/Java/C++/C/Go/JS/Rust）

> **[709. 转换成小写字母](https://leetcode.cn/problems/to-lower-case/solutions/3979856/san-chong-fang-fa-ku-han-shu-shou-dong-j-3wfp/) · Easy**

> **题目描述**
> 给你一个字符串 `s` ，将该字符串中的大写字母转换成相同的小写字母，返回新的字符串。
>
> **示例 1：**
>
> ```
>
> 输入：s = "Hello"
> 输出："hello"
> ```
>
> **示例 2：**
>
> ```
>
> 输入：s = "here"
> 输出："here"
> ```
>
> **示例 3：**
>
> ```
>
> 输入：s = "LOVELY"
> 输出："lovely"
> ```
>
> **提示：**
>
> - `1 <= s.length <= 100`
>
> - `s` 由 ASCII 字符集中的可打印字符组成

> **题解**
> ## 方法一：库函数
>
> ```python
> class Solution:
>     def toLowerCase(self, s: str) -> str:
>         return s.lower()
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$ 或 $\mathcal{O}(1)$。
>
> ## 方法二：手动计算
>
> 如果 $s[i]$ 在 $\texttt{A}$ 到 $\texttt{Z}$ 的范围中，那么 $s[i]$ 是大写字母。
>
> 先计算 $s[i]$ 是第几个大写字母，即计算 $k = s[i] - \texttt{A}$。
>
> 然后把 $s[i]$ 更新成第 $k$ 个（$k$ 从 $0$ 开始）小写字母，即 $s[i]$ 更新成 $\texttt{a} + k$。
>
> ```python
> class Solution:
>     def toLowerCase(self, s: str) -> str:
>         t = list(s)
>         for i, ch in enumerate(t):
>             if 'A' <= ch <= 'Z':  # ch 是大写字母
>                 k = ord(ch) - ord('A')  # 计算 ch 是第 k 个大写字母（k 从 0 开始）
>                 t[i] = chr(ord('a') + k)  # 转成第 k 个小写字母（k 从 0 开始）
>         return ''.join(t)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$ 或 $\mathcal{O}(1)$。
>
> ## 方法三：位运算
>
> 根据 [ASCII 表](https://baike.baidu.com/item/ASCII/309296#3)，大写字母和小写字母的 ASCII 值的区别是：
>
> - 大写字母的二进制 ASCII 值，从低到高第六位是 $0$。
> - 小写字母的二进制 ASCII 值，从低到高第六位是 $1$。
> - 对于同一个字母的大小写，除了从低到高第六位不同，其余位均相同。
>
> 例如：
>
> - $\texttt{A}$ 的 ASCII 值是 $65 = 1000001_{(2)}$。
> - $\texttt{a}$ 的 ASCII 值是 $97 = 1100001_{(2)}$。
>
> > **注**：二进制的低五位正好表示该字母是第几个字母。例如 $\texttt{A}/\texttt{a}$ 是第一个字母。
>
> 把大写字母的 ASCII 值和 $32 = 100000_{(2)}$ 计算按位或（OR），这会把二进制数的从低到高第六位改成 $1$，从而把大写字母转成对应的小写字母。
>
> ```python
> class Solution:
>     def toLowerCase(self, s: str) -> str:
>         t = list(s)
>         for i, ch in enumerate(t):
>             if 'A' <= ch <= 'Z':
>                 t[i] = chr(ord(ch) | 32)
>         return ''.join(t)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$ 或 $\mathcal{O}(1)$。
