# 位运算综合应用，O(1) 写法（Python/Java/C++/C/Go/JS/Rust）

> **[面试题 05.01. 插入](https://leetcode.cn/problems/insert-into-bits-lcci/solutions/3799010/wei-yun-suan-zong-he-ying-yong-jian-ji-x-p3cm/) · Easy**

> **所属题单**
> - [位运算 · 一、基础题](../../../刷题路径/灵神原版题单/位运算/一、基础题.md)

> **题目描述**
> 给定两个整型数字 `N` 与 `M`，以及表示比特位置的 `i` 与 `j`（`i <= j`，且从 0 位开始计算）。
>
> 编写一种方法，使 `M` 对应的二进制数字插入 `N` 对应的二进制数字的第 `i ~ j` 位区域，不足之处用 `0` 补齐。具体插入过程如图所示。
>
> ![](../../_assets/灵茶山艾府/a75890aaa69cfee9.gif)
>
> 题目保证从 `i` 位到 `j` 位足以容纳 `M`， 例如： `M = 10011`，则 `i～j` 区域至少可容纳 5 位。
>
> **示例 1：**
>
> ```
>
>  输入：N = 1024(10000000000), M = 19(10011), i = 2, j = 6
>  输出：N = 1100(10001001100)
> ```
>
> **示例 2：**
>
> ```
>
>  输入：N = 0, M = 31(11111), i = 0, j = 4
>  输出：N = 31(11111)
> ```

> **题解**
> 首先，把 $n$ 的二进制从低到高第 $i$ 到 $j$ 位清除（置为 $0$），这里 $i$ 和 $j$ 都是从 $0$ 开始的。
>
> 如何清除二进制的比特位？
>
> 比如 $i=3$，$j=4$。
>
> 先构造一个二进制数 $11000$，然后将其取反，得到 $11\cdots1100111$。
>
> 然后计算 $n\ \operatorname{AND}\ 11\cdots1100111$。由于任何比特 $\operatorname{AND}\ 0$ 都等于 $0$，所以我们清除了第 $3$ 到 $4$ 位；由于任何比特 $\operatorname{AND}\ 1$ 都不变，所以其余比特不变。
>
> 如何构造 $11000$？
>
> 1. 构造 $100$，即 $1$ 左移 $j-i+1$。
> 2. 把 $100$ 减一，得到 $11$。
> 3. 把 $11$ 左移 $i$ 位，得到 $11000$。
>
> 然后把 $m$ 填入 $n$，$m$ 的最低位在第 $i$ 位。
>
> 做法是把 $m$ 左移 $i$ 后，与 $n$ 计算或。
>
> ```python
> class Solution:
>     def insertBits(self, n: int, m: int, i: int, j: int) -> int:
>         # 清除 n 的从低到高 i~j 位（i 从 0 开始）
>         n &= ~(((1 << (j - i + 1)) - 1) << i)
>         # 把 m 填入 n
>         return n | (m << i)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
