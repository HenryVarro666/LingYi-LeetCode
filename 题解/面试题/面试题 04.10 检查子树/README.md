## 题目描述

检查子树。你有两棵非常大的二叉树：T1，有几万个节点；T2，有几万个节点。设计一个算法，判断 T2 是否为 T1 的子树。

如果 T1 有这么一个节点 n，其子树与 T2 一模一样，则 T2 为 T1 的子树，也就是说，从节点 n 处把树砍断，得到的树与 T2 完全相同。

**注意：**此题相对书上原题略有改动。

**示例 1：**

```

 输入：t1 = [1, 2, 3], t2 = [2]
 输出：true
```

**示例 2：**

```

 输入：t1 = [1, null, 2, 4], t2 = [3, 2]
 输出：false
```

**提示：**

1. 树的节点数目范围为 `[0, 20000]`。
