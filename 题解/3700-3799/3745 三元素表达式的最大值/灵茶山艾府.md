# 贪心，前二大之和减去最小值（Python/Java/C++/Go）

> **[3745. 三元素表达式的最大值](https://leetcode.cn/problems/maximize-expression-of-three-elements/solutions/3832960/tan-xin-qian-er-da-zhi-he-jian-qu-zui-xi-6lja/) · Easy · 难度分 1218**

> **题目描述**
> 给你一个整数数组 `nums`。
>
> 从 `nums` 中选择三个元素 `a`、`b` 和 `c`，它们的下标需 **互不相同** ，使表达式 `a + b - c` 的值最大化。
>
> 返回该表达式可能的 **最大值** 。
>
> **示例 1：**
>
> **输入：** `nums = [1,4,2,5]`
>
> **输出：** `8`
>
> **解释：**
>
> 可以选择 `a = 4`，`b = 5`，`c = 1`。表达式的值为 `4 + 5 - 1 = 8`，这是可能的最大值。
>
> **示例 2：**
>
> **输入：** `nums = [-2,0,5,-2,4]`
>
> **输出：** `11`
>
> **解释：**
>
> 可以选择 `a = 5`，`b = 4`，`c = -2`。表达式的值为 `5 + 4 - (-2) = 11`，这是可能的最大值。
>
> **提示：**
>
> - `3 <= nums.length <= 100`
>
> - `-100 <= nums[i] <= 100`

> **题解**
> 要让 $a+b-c$ 尽量大，$a$ 和 $b$ 要尽量大，$c$ 要尽量小。
>
> 把 $\textit{nums}$ 从小到大排序，取 $a= \textit{nums}[n-1],b=\textit{nums}[n-2],c=\textit{nums}[0]$。
>

>
> ## 优化前
>
> ```python
> class Solution:
>     def maximizeExpressionOfThree(self, nums: List[int]) -> int:
>         nums.sort()
>         return nums[-1] + nums[-2] - nums[0]
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。忽略排序的栈开销。
>
> ## 优化
>
> 手动维护前二大（或者用堆），以及最小值。
>
> ```python
> class Solution:
>     def maximizeExpressionOfThree(self, nums: List[int]) -> int:
>         return sum(nlargest(2, nums)) - min(nums)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
