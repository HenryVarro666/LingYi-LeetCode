# O(n^2) 暴力

> **[3792. 递增乘积块之和](https://leetcode.cn/problems/sum-of-increasing-product-blocks/solutions/3868189/on2-bao-li-by-endlesscheng-duji/) · Medium**

> **题解**
> $n$ 很小，$\mathcal{O}(n^2)$ 暴力即可。
>
> 代码实现时，注意取模。为什么可以在**中途取模**？原理见 [模运算的世界：当加减乘除遇上取模](https://leetcode.cn/circle/discuss/mDfnkW/)。
>
> ```python
> class Solution:
>     def sumOfBlocks(self, n: int) -> int:
>         MOD = 1_000_000_007
>         ans = 0
>         begin = 1
>         for i in range(1, n + 1):
>             m = 1
>             for j in range(begin, begin + i):
>                 m = m * j % MOD
>             ans += m
>             begin += i
>         return ans % MOD
> ```
