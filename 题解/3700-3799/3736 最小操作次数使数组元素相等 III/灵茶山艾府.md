# 都变成数组最大值，附思考题（Python/Java/C++/Go）

> **[3736. 最小操作次数使数组元素相等 III](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-iii/solutions/3826971/du-bian-cheng-shu-zu-zui-da-zhi-pythonja-dc4g/) · Easy**

> **题目描述**
> 给你一个整数数组 `nums`。
>
> 在一步操作中，你可以将任意单个元素 `nums[i]` 的值 **增加** 1。
>
> 返回使数组中的所有元素都 **相等** 所需的 **最小总操作次数** 。
>
> **示例 1:**
>
> **输入:** `nums = [2,1,3]`
>
> **输出:** `3`
>
> **解释:**
>
> 使所有元素相等的操作如下:
>
> - 将 `nums[0] = 2` 增加 1, 变为 3。
>
> - 将 `nums[1] = 1` 增加 1, 变为 2。
>
> - 将 `nums[1] = 2` 增加 1, 变为 3。
>
> 现在，`nums` 中的所有元素都等于 3。最小总操作次数为 `3`。
>
> **示例 2:**
>
> **输入:** `nums = [4,4,5]`
>
> **输出:** `2`
>
> **解释:**
>
> 使所有元素相等的操作如下:
>
> - 将 `nums[0] = 4` 增加 1, 变为 5。
>
> - 将 `nums[1] = 4` 增加 1, 变为 5。
>
> 现在，`nums` 中的所有元素都等于 5。最小总操作次数为 `2`。
>
> **提示:**
>
> - `1 <= nums.length <= 100`
>
> - `1 <= nums[i] <= 100`

> **题解**
> 设 $m = \max(\textit{nums})$。
>
> 由于元素只能变大，所以必须都变成 $\ge m$ 的数，否则无法都相等。
>
> 都变成 $m$ 是最优的。
>
> 操作次数为 
>
> $$
> \begin{aligned}
>     & (m - \textit{nums}[0]) + (m - \textit{nums}[1]) + \cdots + (m - \textit{nums}[n-1])      \\
> ={} & mn - (\textit{nums}[0] + \textit{nums}[1] + \cdots + \textit{nums}[n-1])        \\
> \end{aligned}
> $$
>
> [本题视频讲解](https://www.bilibili.com/video/BV19bkQBkEhG/)，欢迎点赞关注~
>
> ```python
> class Solution:
>     def minMoves(self, nums: List[int]) -> int:
>         return max(nums) * len(nums) - sum(nums)
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(1)$。
>
