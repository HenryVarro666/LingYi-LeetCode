# O(n) 哈希集合（Python/Java/C++/Go）

> **[3718. 缺失的最小倍数](https://leetcode.cn/problems/smallest-missing-multiple-of-k/solutions/3809990/on-ha-xi-ji-he-pythonjavacgo-by-endlessc-62sw/) · Easy**

> **题目描述**
> 给你一个整数数组 `nums` 和一个整数 `k`，请返回从 `nums` 中**缺失的**、**最小的正整数** `k` 的**倍数**。
>
> **倍数** 指能被 `k` 整除的任意正整数。
>
> **示例 1：**
>
> **输入：** `nums = [8,2,3,4,6], k = 2`
>
> **输出：** `10`
>
> **解释：**
>
> 当 `k = 2` 时，其倍数为 2、4、6、8、10、12……，其中在 `nums` 中缺失的最小倍数是 10。
>
> **示例 2：**
>
> **输入：** `nums = [1,4,7,10,15], k = 5`
>
> **输出：** `5`
>
> **解释：**
>
> 当 `k = 5` 时，其倍数为 5、10、15、20……，其中在 `nums` 中缺失的最小倍数是 5。
>
> **提示：**
>
> - `1 <= nums.length <= 100`
>
> - `1 <= nums[i] <= 100`
>
> - `1 <= k <= 100`

> **题解**
> 为方便查找元素，把 $\textit{nums}$ 保存到一个哈希集合中。
>
> 然后枚举 $x = k,2k,3k,\ldots$ 如果 $x$ 不在哈希集合中，返回 $x$。
>
> [本题视频讲解](https://www.bilibili.com/video/BV18GsAzuE6W/)，欢迎点赞关注~
>
> ```python
> class Solution:
>     def missingMultiple(self, nums: List[int], k: int) -> int:
>         st = set(nums)
>         for x in count(k, k):  # 相当于 range(k, inf, k)
>             if x not in st:
>                 return x
> ```
>
> > [!example]- Python3 写法二
> > ```python
> > class Solution:
> >     def missingMultiple(self, nums: List[int], k: int) -> int:
> >         st = set(nums)
> >         return next(x for x in count(k, k) if x not in st)
> > ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
> - 空间复杂度：$\mathcal{O}(n)$。
