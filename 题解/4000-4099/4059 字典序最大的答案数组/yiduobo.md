4059.字典序最大的答案数组

<https://leetcode.cn/problems/lexicographically-largest-power-array/description/>

题目给出一个长度为n的整数数组nums，其长度不超过50000，其中元素的大小在0到2^15 - 1之间。现在要求将其重新排列，得到一个排列后的数组perm。

定义一个长度为15的数组power。对于0到14之间的每个index，考察perm的前缀第14 - index位，power[index]为满足这个前缀中的所有元素在第14 - index位都为1的最长前缀长度。

问可能得到的字典序最大的power数组是什么。

题目要求power的字典序最大，那么就应该让高位上的值尽量的大。对应到perm这边，那么就应该让最高位为1的元素先全部聚集起来。

但是本题的构造并没有这么简单，因为从接下来的位开始，就需要面临截断的问题了。

例如[7, 5, 2, 1]，对于最高位，将7和5先聚集到前两位，这是没有任何问题的。接下来对于中间这一位，则显然应该让7放在前面，5放在后面。需要注意的是，此时剩下的2和1中，虽然2在中间这一位上也位1，但是因为5在这里截断了，因此2和1的顺序对中间这一位实际上并没有影响。反过来，在考虑最后这一位时，由于7和5在这一位上都为1，因此向后顺延到2和1时，将1排到2的前面后，1还是可以给最低位做出贡献，因此最终排列的顺序就应该是[7, 5, 1, 2]，而不是单纯从大到小的[7, 5, 2, 1]。

基于上面的讨论，可以发现可以用一个分组的过程来概括上面的排列流程。

具体来说，一开始只有一个整的组，其中包含[7, 5, 2, 1]，需要注意，此时组中的元素是无序的。

接下来考虑最高位，其中7和5在这一位上为1，因此这个组被分裂成了两个组，分别是[7, 5]和[2, 1]。需要注意，这两个组间有先后顺序，但是组内的元素依然是无序的。

接下来是中间这一位。首先是[7, 5]这一组，其中7在这一位上为1，因此这个组需要进一步分裂，变为[7]和[5]，其中[7]在前[5]在后。接下来，由于5在这里截断掉了，因此最后的[2, 1]在这里不需要继续考虑了，而是应该依然维持在无序的状态。

最后到了最低位。首先是[7]这一组，发现7在这一位上为1，因此可以继续考虑下一组。接下来是[5]这一组，发现5在这一位上为1，因此还可以继续向后考虑。最后是[2, 1]这一组，其中只有1在这一位上为1，因此分裂成[1]和[2]两组，[1]在前[2]在后。

至此，就得到了最终的排列[7][5][1][2]。对于答案的计算，可以一趟遍历，也可以在上面逐位计算的过程中进行讨论。

更一般的说法，对于一个组中的元素，可能有三种情况：

1、组中所有元素在这一位上都为1，那么这一组内的顺序对答案无关紧要，可以将组内元素的数目累加到power对应的位置中，然后继续考虑下一组

2、组中所有元素在这一位上都为0，那么这一组内的顺序同样对答案无关紧要，因为组中元素都无法对答案做出贡献。对于这种情况，截断已经出现了，因此无需考虑后续的组

3、组中元素在这一位上有0有1，那么此时就需要让1的这些元素排在0的前面，因此需要将这一组分裂成两个部分，1的元素在前，0的元素在后，组间有序，但是组内依然保持无序。另外，这种情况同样出现了截断，因此无需考虑后续的组。

按照上面的做法，从高位到低位，从左到右依次检测各组，统计答案并在适当的时候进行分裂即可。这样一来，就得到了一种O(nlogU)的算法，其中U是值域。

接下来，由于这n个元素大小都不超过U，而相同的元素显然应该聚合在一起，因此在这里可以先一趟遍历，统计每种元素出现的次数，然后基于每种元素各一个的初始数组进行上面的分组操作，就可以得到一个O(n + UlogU)的算法。

最后，则可以利用二叉树来优化这个判断01的过程。

在上面的算法中，对于每个分组中的元素，需要遍历一遍检测当前位是否为1，但是实际上，每一组中的元素的部分前缀必然是相同的，同时这些元素的值域处于U之内，因此通过一颗满的二叉trie树就可以高效判断组内的元素在当前位上为1的元素数目，从而决定应该如何处理当前组。

直观来看，对于一颗满的二叉trie树，其中的节点p表示某个01的前缀，那么在这里可以规定其左孩子表示在这个前缀的基础上添加1，右孩子则表示在这个前缀的基础上添加0，那么只需判断p与左孩子的权重是否相同，就可以直到当前组内的元素在这一位上是否为全1了。同理，如果权重与右孩子相同，则说明在这一位上全0，否则就需要拆组。而组中元素的表达，则可以浓缩为一组树中的节点的list。

这样一来，相当于从根节点向下逐层遍历这颗二叉树，时间复杂度就来到了O(U)，再加上最开始哈希的复杂度，整体复杂度就是O(n + U)。

---

接下来详细说明一下具体的执行流程：

首先，大于等于数组中最大值的二的幂m，然后建立一颗有m个叶子节点的满二叉树，根节点为1号节点。这样做的好处是可以通过index \<\< 1以及index \<\< 1 | 1轻松定位到左右孩子。

接下来，将nums中的元素出现的次数填充进trie树的叶子节点中，需要注意顺序需要反过来，也就是值为v的节点更新的是树中编号为2m - v - 1的节点。

填充完毕后，自底向上完成树中所有节点值的初始化。

准备工作完成后，接下来就是逐位向下，拆分分组的过程。由于这个拆分过程相当于原始结构中凭空多出一个对象，而整个结构是从左到右依次执行的，因此在这里可以使用双端队列，或者干脆栈模拟队列来实现这个拆分分组的过程。

初始情况下，组中只有根节点，其高度为0，因此栈中仅记录一个组[(0, 1)]。

接下来开始逐位向下遍历。

对于当前位，从栈顶不断弹出组，直到栈为空或者拆分过程中被阻断。对于弹出的组，使用另一个栈tmp收集起来，然后再进行处理。对于当前组，需要遍历其中的所有节点以及对应的高度，然后计算，以这个节点为根节点，在当前这一层的所有节点的左孩子的权重之和。需要注意可能需要从高层的节点覆盖下来，因为之前位的出现阻断操作时，后续节点是处于无序状态的，因此还可能保留在一个较高的位置的。

依然还是上面[7, 5, 2, 1]的例子。

在最开始，队列中仅有1号节点。处理完最高位之后，队列中变成了2号节点和3号节点。

接下来，在处理2号节点拆分为了4号节点和5号节点，因此阻断了后续3号节点的处理，也就是说栈中的节点是按照4 5 3排列的。

最后，再处理最低位时，4和5都通过了，所以最后的3号节点还是需要考虑。需要注意的是，此时3号节点处于上一层，而这一层真正需要考察的是6和7的左孩子，这就就是上面说的从高层的节点覆盖下来的意思。另一方面，由于存在这种情况，因此一个组内可能需要储存多个不同的节点。

当栈弹空，或者出现阻断时，将tmp中的组逐个弹出，加回到stack中，然后继续考虑下一位即可。

最后附上python代码：

```python
class Solution(object):
    def largestPower(self, nums):
        """
        :type nums: List[int]
        :rtype: List[int]
        """
        
        ma = max(nums)
        m = 1
        h = 1
        while m <= ma:
            m <<= 1
            h += 1
        
        f = [0] * (m * 2)
        for v in nums:
            f[-v - 1] += 1
        
        now = m >> 1
        while now > 0:
            for index in range(now, now << 1):
                f[index] = f[index << 1] + f[index << 1 | 1]
            now >>= 1
            
        res = []
        stack = [[(1, 0)]]
        tmp = []
        for level in range(h - 1):
            res.append(0)
            while stack:
                interval = stack.pop()
                cnt = 0
                one = []
                zero = []
                for p_index, p_level in interval:
                    level_diff = level - p_level
                    start = p_index << level_diff
                    for index in range(start, start + (1 << level_diff), 1):
                        res[-1] += f[index << 1]
                        if f[index << 1] == f[index]:
                            one.append(index << 1)
                        elif f[index << 1] == 0:
                            zero.append(index << 1 | 1)
                        else:
                            one.append(index << 1)
                            zero.append(index << 1 | 1)
                
                if one:
                    tmp.append([(index, level + 1) for index in one])

                if zero:
                    tmp.append([(index, level + 1) for index in zero])
                    break
            
            while tmp:
                stack.append(tmp.pop())

        return [0] * (15 - len(res)) + res
```
