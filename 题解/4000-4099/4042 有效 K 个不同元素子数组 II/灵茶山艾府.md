# 滑动窗口 + 异或哈希（Python/Java/C++/Go）

> **[4042. 有效 K 个不同元素子数组 II](https://leetcode.cn/problems/valid-k-unique-subarrays-ii/solutions/4021291/hua-dong-chuang-kou-yi-huo-ha-xi-pythonj-egme/) · Hard**

> **题解**
> 本题强制在线（不允许使用离线算法）。
>
> 做法同 [4033. 有效 K 个不同元素子数组 I](https://leetcode.cn/problems/valid-k-unique-subarrays-i/)，请看 [我的题解](../4033%20有效%20K%20个不同元素子数组%20I/灵茶山艾府.md) 的方法一。
>
> ```python
> class Solution:
>     def validSubarrays(self, nums: list[int], k: int, l0: int, r0: int, q: int) -> list[bool]:
>         n = len(nums)
>         s = [0] * (n + 1)
>         # 把 nums[i] 映射成随机数
>         # 不要在 [0, 2**L) 内随机，见 https://codeforces.com/blog/entry/153335
>         mp = defaultdict(lambda: randrange(10 ** 18))
>         for i, x in enumerate(nums):
>             s[i + 1] = s[i] ^ mp[x]
>
>         def calc_left(k: int) -> list[int]:
>             lefts = [0] * n
>             cnt = defaultdict(int)
>             l = 0
>             for i, x in enumerate(nums):
>                 cnt[x] += 1
>                 while len(cnt) >= k:
>                     v = nums[l]
>                     if cnt[v] > 1:
>                         cnt[v] -= 1
>                     else:
>                         del cnt[v]  # 保证 len(cnt) 是窗口内的不同元素个数
>                     l += 1
>                 lefts[i] = l
>             return lefts
>
>         l1 = calc_left(k + 1)
>         l2 = calc_left(k)
>
>         ans = [False] * q
>         l, r = l0, r0
>         for i in range(q):
>             if i > 0:
>                 g = l + r if ans[i - 1] else r - l
>                 l = (l ^ g) % n
>                 r = (r ^ g) % n
>                 if l > r:
>                     l, r = r, l
>             ans[i] = s[r + 1] == s[l] and l1[r] <= l < l2[r]
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n+q)$，其中 $n$ 是 $\textit{nums}$ 的长度。对于滑动窗口，虽然写了个二重循环，但是内层循环中对 $\ell$ 加一的**总**执行次数不会超过 $n$ 次，所以二重循环的循环次数为 $\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(n)$。返回值不计入。
