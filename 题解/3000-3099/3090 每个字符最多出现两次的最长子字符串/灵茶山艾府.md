# 滑动窗口（Python/Java/C++/Go）

> **[3090. 每个字符最多出现两次的最长子字符串](https://leetcode.cn/problems/maximum-length-substring-with-two-occurrences/solutions/2704776/on-hua-dong-chuang-kou-pythonjavacgo-by-hl44d/) · Easy · 难度分 1329**

> **所属题单**
> - [滑动窗口与双指针 · 二、不定长滑动窗口](../../../刷题路径/灵神原版题单/滑动窗口与双指针/二、不定长滑动窗口.md) · §2.1 越短越合法/求最长/最大 · §2.1.1 基础

> **题目描述**
> 给你一个字符串 `s` ，请找出满足每个字符最多出现两次的最长子字符串，并返回该子字符串的 **最大** 长度。
>
> **示例 1：**
>
> **输入：** `s = "bcbbbcba"`
>
> **输出：** `4`
>
> **解释：**
>
> 以下子字符串长度为 4，并且每个字符最多出现两次：`"bcbbbcba"`。
>
> **示例 2：**
>
> **输入：** `s = "aaaa"`
>
> **输出：** `2`
>
> **解释：**
>
> 以下子字符串长度为 2，并且每个字符最多出现两次：`"aaaa"`。
>
> **提示：**
>
> - `2 <= s.length <= 100`
>
> - `s` 仅由小写英文字母组成。

> **题解**
> 本题相当于把 [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) 中的「出现次数不超过 $1$」改成「出现次数不超过 $2$」，做法请看视频 [滑动窗口【基础算法精讲 03】](https://www.bilibili.com/video/BV1hd4y1r7Gq/?t=12m)，把代码第 $8$ 行的 $1$ 改成 $2$ 即可。
>
> ```python
> class Solution:
>     def maximumLengthSubstring(self, s: str) -> int:
>         ans = left = 0
>         cnt = defaultdict(int)
>         for i, c in enumerate(s):
>             cnt[c] += 1
>             while cnt[c] > 2:
>                 cnt[s[left]] -= 1
>                 left += 1
>             ans = max(ans, i - left + 1)
>         return ans
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(n)$ 或 $\mathcal{O}(n+|\Sigma|)$，其中 $n$ 为 $s$ 的长度，$|\Sigma|$ 为字符集合的大小，本题字符均为小写字母，所以 $|\Sigma|=26$。虽然写了个二重循环，但是内层循环中对 $\textit{left}$ 加一的**总**执行次数不会超过 $n$ 次。用哈希表实现则为 $\mathcal{O}(n)$。
> - 空间复杂度：$\mathcal{O}(|\Sigma|)$。
