# 简单题，简单做（Python/Java/C++/C/Go/JS/Rust）

> **[1812. 判断国际象棋棋盘中一个格子的颜色](https://leetcode.cn/problems/determine-color-of-a-chessboard-square/solutions/3014691/jian-dan-ti-jian-dan-zuo-pythonjavaccgoj-jwdv/) · Easy**

> **题目描述**
> 给你一个坐标 `coordinates` ，它是一个字符串，表示国际象棋棋盘中一个格子的坐标。下图是国际象棋棋盘示意图。
>
> ![](../../_assets/灵茶山艾府/9eab4ba34194c9c8.png)
>
> 如果所给格子的颜色是白色，请你返回 `true`，如果是黑色，请返回 `false` 。
>
> 给定坐标一定代表国际象棋棋盘上一个存在的格子。坐标第一个字符是字母，第二个字符是数字。
>
> **示例 1：**
>
> ```
>
> 输入：coordinates = "a1"
> 输出：false
> 解释：如上图棋盘所示，"a1" 坐标的格子是黑色的，所以返回 false 。
> ```
>
> **示例 2：**
>
> ```
>
> 输入：coordinates = "h3"
> 输出：true
> 解释：如上图棋盘所示，"h3" 坐标的格子是白色的，所以返回 true 。
> ```
>
> **示例 3：**
>
> ```
>
> 输入：coordinates = "c7"
> 输出：false
> ```
>
> **提示：**
>
> - `coordinates.length == 2`
>
> - `'a' <= coordinates[0] <= 'h'`
>
> - `'1' <= coordinates[1] <= '8'`

> **题解**
> 把 $\textit{coordinates}$ 简记为 $s$。
>
> 根据题目中的图片，如果 $s[0]$ 和 $s[1]$ 的 ASCII 值的奇偶性不同，那么格子是白格，否则是黑格。
>
> ```python
> class Solution:
>     def squareIsWhite(self, s: str) -> bool:
>         return ord(s[0]) % 2 != ord(s[1]) % 2
> ```
>
>
> #### 复杂度分析
>
> - 时间复杂度：$\mathcal{O}(1)$。
> - 空间复杂度：$\mathcal{O}(1)$。
